# Adventure Stage, Relic & Endgame System

## 0. 문서 목적

이 문서는 **주산게임의 모험 탭 전체를 관통하는 공통 진행 규칙**을 정의한다.

개별 미니게임의 세부 구현 규칙보다 상위 개념의 설계 문서이며,
앞으로 용암계곡, 하늘섬, 오래된 유적지, 심해협곡, 얼음대륙을 계속 개발할 때
이 문서를 기준으로 Stage 구조, 보상, 유물, 최종 엔딩을 일관되게 유지한다.

핵심 목표는 다음과 같다.

- 주산 훈련만 반복하면서 생기는 지루함을 줄인다.
- 공룡 도감과 별개의 장기 수집축을 만든다.
- 각 미니게임을 Stage 1 → 2 → 3으로 확장한다.
- Stage가 올라갈수록 단순히 어려워지는 것이 아니라 게임 문법과 콘텐츠량이 확장되게 한다.
- Stage 3 반복 플레이를 통해 지역 유물조각을 수집한다.
- 지역 도감 완성과 유물조각 수집을 연결한다.
- 5개 지역 유물을 모두 완성하면 중앙 오벨리스크를 활성화한다.
- 오벨리스크 완성을 현재 게임의 최종 목표점으로 삼는다.

---

# 1. 전체 게임 진행 루프

```text
주산 훈련
↓
코인 / 성장 / 일반 보상
↓
공룡 성장 및 도감 해금
↓
모험 탭
↓
지역 미니게임 플레이
↓
Stage 1
↓
Stage 2
↓
Stage 3
↓
Stage 3 반복 플레이
↓
보물상자 오픈
↓
지역 유물조각 획득
↓
지역 유물조각 누적
+
해당 지역 도감 전체 해금
↓
지역 유물 완성
↓
5개 지역 유물 완성
↓
중앙 오벨리스크 활성화
↓
게임의 최종 엔딩
```

---

# 2. 5개 모험 지역

현재 모험 탭의 기본 지역은 다음 5개다.

1. 용암계곡
2. 하늘섬
3. 오래된 유적지
4. 심해협곡
5. 얼음대륙

각 지역은 서로 다른 미니게임 장르와 핵심 조작을 가진다.

각 지역은 동일하게 **Stage 1 / Stage 2 / Stage 3** 구조를 사용한다.

---

# 3. Stage 공통 철학

Stage 상승은 단순한 난이도 상승이 아니다.

공통 원칙:

```text
Stage 1 = Learn
Stage 2 = Expand
Stage 3 = Master
```

즉,

- Stage 1: 기본 규칙을 배운다.
- Stage 2: 새로운 게임 문법이 추가된다.
- Stage 3: 앞 단계의 요소를 결합한 완성형 플레이를 제공한다.

속도만 빨라지거나 장애물 개수만 늘어나는 방식으로 Stage를 구분하지 않는다.

---

# 4. Stage 1 - 기본 탐험

목표:

플레이어가 해당 미니게임의 기본 조작과 규칙을 쉽게 이해한다.

공통 원칙:

- 가장 단순한 맵/패턴
- 기본 조작만 사용
- 가장 짧은 플레이 시간
- 장애물 종류 최소
- 아이템 종류 최소
- 실패 부담 낮음
- 유물조각 획득 없음

Stage 1은 반드시 아이가 비교적 쉽게 성공 경험을 얻을 수 있어야 한다.

---

# 5. Stage 2 - 확장 탐험

목표:

Stage 1의 기본 게임 문법에 새로운 요소를 1~2개 추가한다.

공통 원칙:

- Stage 1보다 플레이 시간 증가
- 맵 길이 또는 콘텐츠량 증가
- 새로운 이동 구조 추가
- 새로운 장애물 또는 게임 요소 추가
- 아이템 Pool 증가
- 보상량 증가
- 단순한 속도 증가만으로 난이도를 만들지 않는다.

플레이어가 Stage 2를 처음 보았을 때:

> "똑같은 게임인데 더 어렵네."

보다

> "어? 새로운 길/기능/장애물이 생겼네."

라는 느낌이 나야 한다.

---

# 6. Stage 3 - 심층 탐험 / 완성형 플레이

목표:

Stage 1과 Stage 2의 게임 요소를 결합해 해당 미니게임의 완성형 플레이를 제공한다.

공통 원칙:

- 가장 긴 플레이 시간
- 가장 다양한 패턴
- 분기/랜덤 구간 사용 가능
- 아이템 Pool 최대
- 희귀 보상 증가
- Stage 3 클리어 시 보물상자 등장
- 유물조각 획득 가능
- 반복 플레이 중심 콘텐츠

Stage 3는 한 번 클리어하고 끝나는 콘텐츠가 아니라,
지역 유물을 완성할 때까지 반복 플레이하는 메인 엔드 콘텐츠다.

---

# 7. Stage 해금 규칙

초기 규칙은 최대한 단순하게 유지한다.

```text
Stage 1 최초 클리어
→ Stage 2 해금

Stage 2 최초 클리어
→ Stage 3 해금
```

Stage 1과 Stage 2는 장기 플레이를 억지로 늘리는 역할이 아니다.

장기 반복 플레이는 Stage 3와 유물 수집 시스템이 담당한다.

향후 필요하면 해금 조건을 튜닝할 수 있으나,
기본적으로 별점, 반복 횟수, 추가 재화 요구 등 복잡한 조건은 피한다.

---

# 8. Stage별 플레이 시간 증가

Stage가 올라갈수록 한 판의 콘텐츠량도 증가한다.

기본 권장 범위:

```text
Stage 1: 약 90~120초
Stage 2: 약 120~150초
Stage 3: 약 150~180초
```

현재 용암계곡처럼 이미 120초 구조가 있다면 다음처럼 적용 가능하다.

```text
Stage 1: 120초
Stage 2: 150초
Stage 3: 180초
```

단, 장르 특성에 따라 시간 대신 콘텐츠량으로 환산할 수 있다.

예: 오래된 유적지 퍼즐

```text
Stage 1: 퍼즐방 2개
Stage 2: 퍼즐방 3개
Stage 3: 퍼즐방 4개
```

핵심 원칙:

> Stage가 상승할 때 한 판의 콘텐츠량을 약 20~30% 확장한다.

---

# 9. Stage별 아이템 확장

Stage가 올라갈수록 단순히 아이템 수량만 증가시키는 것이 아니라
**등장 가능한 아이템 Pool 자체가 확장**된다.

## Stage 1

기본 아이템 중심.

예:

- 코인
- 기본 음식
- 기본 회복/보조 아이템

## Stage 2

Stage 1 Pool +

- 희귀조각
- 추가 음식/부화 아이템
- 지역 특수 아이템
- 더 높은 가치의 보상

## Stage 3

Stage 1 + Stage 2 Pool +

- 희귀 아이템
- 고급 보상
- 지역 특수 보상
- 유물조각 획득 기회

모든 아이템을 항상 지급하지 않는다.

Stage가 올라갈수록:

- 등장 가능한 종류가 늘어난다.
- 희귀 보상 확률이 증가한다.

---

# 10. 희귀조각 시스템

희귀조각은 **소비형 재화**다.

주 사용처는 희귀알 구매다.

현재 기본 방향:

```text
희귀알 구매
= 코인 사용 없음
= 희귀조각만 사용
```

초기 권장 희귀알 가격:

```text
희귀조각 15개
```

15개는 초기 밸런스 기준이며,
실제 플레이 테스트 후 조정 가능하다.

권장 조정 범위:

```text
12~18개
```

희귀조각은 미니게임 반복 플레이의 실용적인 보상으로 사용한다.

유물조각과 역할을 혼합하지 않는다.

---

# 11. 희귀조각 vs 유물조각

| 구분 | 희귀조각 | 유물조각 |
|---|---|---|
| 역할 | 소비형 재화 | 장기 진행/수집 |
| 사용 | 희귀알 구매 | 지역 유물 복원 |
| 소모 여부 | 소모됨 | 소비 개념 없음 |
| 획득 | 여러 모험 콘텐츠 | Stage 3 보물상자 |
| 반복 획득 | 가능 | 지역 유물 완성 전까지만 |
| 주요 목적 | 도감 확장 | 세계 복원 |

두 시스템은 명확하게 분리한다.

---

# 12. Stage 3 보물상자 시스템

Stage 3 클리어 시 즉시 숫자 보상을 지급하는 대신,
별도의 보물상자 팝업을 연다.

기본 흐름:

```text
Stage 3 Clear
↓
"보물상자를 발견했어요!"
↓
보물상자 팝업
↓
플레이어가 상자 클릭/터치
↓
짧은 상자 오픈 애니메이션
↓
보상 공개
↓
확인
```

목적:

- Stage 3 클리어를 특별하게 느끼게 한다.
- 반복 플레이 기대감을 만든다.
- 유물조각 획득 순간을 강조한다.

---

# 13. 보물상자 연출 원칙

과도한 가챠 시스템으로 만들지 않는다.

허용:

- 상자 흔들림
- 빛 효과
- 뚜껑 열림
- 1~2초 짧은 연출
- 보상 아이콘 공개

피해야 할 것:

- 별도 뽑기 재화
- 10연속 뽑기
- 지나치게 낮은 확률
- 긴 스킵 불가능 애니메이션
- 복잡한 등급 시스템

보물상자는 어디까지나:

> "Stage 3 클리어 보상을 재미있게 받는 장치"

다.

---

# 14. 보물상자 보상 구성

상자를 열면 최소 하나 이상의 보상을 항상 지급한다.

기본 보상 예:

- 코인
- 일반 아이템

추가 보상 예:

- 희귀조각
- 음식/부화 아이템
- 고급 상점 아이템
- 지역 유물조각

상자를 열었는데 아무것도 나오지 않는 결과는 허용하지 않는다.

---

# 15. 유물조각 획득

유물조각은 Stage 3 클리어 보물상자에서 획득한다.

중요:

- Stage 1에서는 획득 불가
- Stage 2에서는 획득 불가
- Stage 3에서만 획득 가능

유물조각은 지역별로 분리한다.

예:

- 용암계곡 유물조각
- 하늘섬 유물조각
- 오래된 유적지 유물조각
- 심해협곡 유물조각
- 얼음대륙 유물조각

UI에서는 별도 재화 5종처럼 복잡하게 표시하지 않고,
각 지역 카드 안에서 진행도로 보여준다.

예:

```text
유물 3 / 5
```

---

# 16. 유물조각 드롭 규칙

구체적인 확률은 MD에서 고정하지 않고 데이터 값으로 조정한다.

기본 철학:

> Stage 3를 여러 번 반복 플레이하면 자연스럽게 지역 유물을 완성할 수 있어야 한다.

권장 초기 컨셉:

- 확률 드롭
- 연속 미획득 시 보장 지급

예:

```text
Stage 3 클리어
→ 유물조각 획득 판정

3회 연속 미획득
→ 다음 Stage 3 보물상자에서 유물조각 확정
```

정확한 확률과 보장 횟수는 실제 플레이 시간과 반복 피로도를 보고 튜닝한다.

---

# 17. 지역 유물조각 필요량

초기 권장값:

```text
지역당 유물조각 5개
```

예:

```text
용암계곡 유물
● ● ● ○ ○
3 / 5
```

3개는 너무 짧고,
10개는 지나치게 길어질 가능성이 있으므로
5개를 기본값으로 사용한다.

필요하면 실제 테스트 후 조정한다.

---

# 18. 지역 유물 최종 해금 조건

지역 유물은 유물조각만 모았다고 바로 완성되지 않는다.

최종적으로 아래 두 조건을 모두 만족해야 한다.

```text
조건 A:
해당 지역 유물조각 필요량 충족

AND

조건 B:
해당 지역 도감 전체 해금
```

즉:

```text
Stage 3 반복 플레이
→ 유물조각 수집

공룡/생물 수집
→ 지역 도감 완성

두 조건 모두 만족
↓
지역 유물 완성
```

이 구조의 목적은
모험 콘텐츠와 공룡 도감 콘텐츠가 마지막에 하나로 연결되게 하는 것이다.

---

# 19. 지역 유물 완성 후

지역 유물이 완성되면:

- 해당 지역 유물조각은 더 이상 드롭하지 않는다.
- Stage 3는 계속 플레이 가능하다.
- Stage 3 보물상자에서는 코인/희귀조각/아이템 등 일반 보상만 지급한다.
- 지역 카드의 `유물 5/5` 표시는 완성된 유물 이미지로 변경할 수 있다.

예:

```text
🔥 용암계곡

화산왕의 석판
유물 완성!
```

---

# 20. 모험 탭의 유물 UI

유물조각을 코인처럼 상단 재화바에 표시하지 않는다.

유물은 일반 화폐가 아니라 장기 진행도이기 때문이다.

각 지역 카드 또는 지역 정보 화면에 표시한다.

예:

```text
🔥 용암계곡

Stage 3
화산 심장부

유물
● ● ● ○ ○
3 / 5
```

Stage 3 미해금 상태:

```text
유물 🔒
Stage 3에서 발견 가능
```

지역 유물 완성 상태:

```text
🏺 화산왕의 석판
유물 완성!
```

---

# 21. 고대의 오벨리스크

모험 탭 안에 별도의 하단 탭을 추가하지 않는다.

대신 모험 지도 안에 하나의 특별한 장소 또는 버튼으로
**고대의 오벨리스크**를 배치한다.

초기 상태:

```text
고대의 오벨리스크

○ ○ ○ ○ ○

아직 잠들어 있어요
```

지역 유물이 하나 완성될 때마다 하나씩 활성화된다.

```text
● ○ ○ ○ ○
● ● ○ ○ ○
...
● ● ● ● ●
```

오벨리스크를 클릭하면 전체 유물 컬렉션/세계 복원 화면으로 진입한다.

---

# 22. 세계 복원 화면

공룡 도감과는 다른 수집 경험을 제공한다.

개념:

- 공룡 도감 = 생물 수집
- 세계 유물 = 세계 복원

예시 구조:

```text
             [하늘 유물]

[화산 유물]   [오벨리스크]   [심해 유물]

        [고대 유물]   [빙결 유물]
```

유물을 획득하기 전에는:

- 실루엣
- 깨진 석판
- 비활성 문양

등으로 표시한다.

유물이 완성되면 해당 부분이 복원되고 빛난다.

---

# 23. 5개 지역 유물과 대표 유물

초기 대표 유물 방향 예시:

| 지역 | 대표 유물 예시 |
|---|---|
| 용암계곡 | 화산왕의 석판 |
| 하늘섬 | 천공의 나침반 |
| 오래된 유적지 | 고대 태양문 |
| 심해협곡 | 심해의 삼지창 |
| 얼음대륙 | 얼어붙은 왕관 |

실제 명칭과 디자인은 추후 변경 가능하다.

---

# 24. 오벨리스크 활성화 조건

아래 조건을 모두 만족하면 오벨리스크가 완전히 활성화된다.

```text
용암계곡 지역 유물 완성
+
하늘섬 지역 유물 완성
+
오래된 유적지 지역 유물 완성
+
심해협곡 지역 유물 완성
+
얼음대륙 지역 유물 완성
```

즉 5개 지역 모두:

- Stage 3 플레이
- 유물조각 수집
- 해당 지역 도감 전체 해금

을 완료해야 한다.

---

# 25. 최종 엔딩

오벨리스크 완성을 현재 게임의 최종 목표점으로 본다.

5개 유물이 모두 모이면:

```text
5개의 유물이 모두 모였습니다!
↓
오벨리스크 활성화
↓
빛 / 문양 / 포털 연출
↓
새로운 세계 발견
```

마지막 메시지는 가족용 게임의 성격을 살린다.

권장 문구 방향:

```text
새로운 세계가 발견되었어요!

새로운 모험은 아직 만들어지고 있어요.

아빠가 새로운 게임을 개발할게요!
```

이 엔딩은 단순한 "준비 중" 화면보다
현재 게임을 하나의 완결된 경험으로 마무리하는 역할을 한다.

---

# 26. 게임 수명 목표

현재 게임은 무한 확장을 목표로 하지 않는다.

목표:

- 현재 5개 지역 완성
- Stage 1/2/3 구조 완성
- 지역 도감 완성
- 유물 수집 완성
- 오벨리스크 엔딩 완성

이 구조를 통해 현재 게임을 하나의 완결된 시즌/작품으로 마무리한다.

향후 새로운 학습 게임 또는 차기작은 별도 프로젝트/세계로 확장하는 것을 우선 고려한다.

# 28. 개발 우선순위

이 문서를 기준으로 다음 순서로 개발한다.

## Phase 1
공통 시스템 기반 정리

- Stage 데이터 구조
- Stage 해금 상태
- Stage별 플레이 시간
- Stage별 아이템 Pool
- Stage 3 보물상자
- 유물조각 데이터 구조
- 지역 유물 진행도
- 오벨리스크 진행도

## Phase 2
기존 미니게임 확장

- 용암계곡 Stage 2
- 용암계곡 Stage 3
- 하늘섬 Stage 2
- 하늘섬 Stage 3

## Phase 3
신규 지역 미니게임

- 오래된 유적지
- 심해협곡
- 얼음대륙

## Phase 4
메타 시스템 마무리

- 오벨리스크 화면
- 최종 엔딩

# 29. 개발 시 반드시 유지할 원칙

1. 시스템을 너무 복잡하게 만들지 않는다.
2. Stage 2/3는 단순 속도 증가가 아니라 게임 문법 확장이다.
3. 유물조각은 Stage 3에서만 획득한다.
4. 유물조각은 소비 재화가 아니다.
5. 희귀조각은 희귀알 구매용 소비 재화다.
6. 유물 완성은 `유물조각 + 지역 도감 완성` 두 축을 모두 요구한다.
7. 유물은 모험 탭 안에서 보여준다.
8. 별도 유물 하단 탭을 새로 만들지 않는다.
9. 오벨리스크는 게임의 최종 장기 목표다.
10. 오벨리스크 완성 후 현재 게임을 따뜻하게 마무리한다.
11. 후속 콘텐츠는 무한 확장보다 차기작으로 분리하는 것을 우선 고려한다.

# 30. 이 문서의 역할

앞으로 새로운 미니게임 또는 Stage를 개발할 때 반드시 이 문서를 먼저 확인한다.

개별 구현에서는 이 문서의 공통 규칙을 유지하면서
각 지역의 세부 장르와 재미 요소만 별도로 확장한다.

세부 수치:

- Stage 시간
- 희귀조각 드롭량
- 유물조각 드롭 확률
- 보장 횟수
- 희귀알 가격
- 아이템 등장 확률

등은 코드/config에서 조정 가능한 값으로 유지하고,
이 문서에는 구조와 철학만 고정한다.
