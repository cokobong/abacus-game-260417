# Lava Valley Relic Flow

이 문서는 `ADVENTURE_STAGE_RELIC_SYSTEM.md`의 공통 규칙을 바탕으로 용암계곡 Stage 3 이후의 보물상자, 유물조각, 지역 유물 복원 흐름을 구현 가능한 수준으로 정의한다.

표기 기준:

- **FIXED**: 구현 시 유지할 확정 규칙
- **TUNABLE**: 플레이 테스트와 경제 밸런스에 따라 조정할 값
- **TODO**: 구현 전에 추가 결정이 필요한 항목

## 1. 전체 진행 흐름

**FIXED**

1. Stage 3 `화산 심장부` 정상 클리어
2. 최종 구간에 Stage 3 전용 특별 보물상자 등장
3. 플레이어가 보물상자를 직접 터치
4. 짧은 개봉 연출 재생
5. 보상 결정 및 저장
6. 보상 공개
7. 결과 UI 표시
8. 유물조각과 화산지대 도감 조건을 모두 충족하면 지역 유물 복원 이벤트 활성화
9. 완성된 지역 유물을 향후 중앙 오벨리스크 진행도에 반영

Stage 1과 Stage 2에서는 특별 보물상자와 유물조각을 지급하지 않는다.

## 2. Stage 3 특별 보물상자

**FIXED**

- 보물상자는 Stage 3를 정상 클리어한 경우에만 최종 위치에 생성한다.
- 상자를 터치하기 전에는 보상을 지급하거나 결과 UI로 넘어가지 않는다.
- 터치 후에는 중복 입력을 잠그고 한 상자당 보상을 정확히 한 번만 결정하고 저장한다.
- 보상은 최소 한 종류 이상 지급하며 빈 상자는 만들지 않는다.
- 상자 개봉이 끝난 뒤 일반 보상과 유물조각 획득 여부를 한 화면에서 알기 쉽게 보여준다.
- Stage 3 클리어와 상자 개봉은 서로 다른 이벤트로 구분하되, 재실행이나 중복 터치로 보상이 중복 지급되지 않아야 한다.

**TUNABLE**

- 개봉 연출 시간: 초기 권장 `1.0~1.5초`이며 공통 설계의 `1~2초` 범위 안에서 조정
- 상자 등장 위치와 플레이어가 터치할 수 있는 거리
- 보상 공개 순서와 연출 속도

**TODO**

- 클리어 후 상자를 열기 전에 앱을 종료한 경우 미개봉 상자를 복원할지, 다음 진입에서 다시 획득하게 할지 결정한다.
- 위 정책에 따라 `pendingChest` 또는 실행별 `chestId` 저장이 필요한지 확정한다.

## 3. 보상 구성

한 번의 상자에서 아래 보상 중 하나 이상을 조합해 지급할 수 있다.

- 코인
- 현재 인벤토리에서 안전하게 재사용 가능한 일반 아이템 또는 음식
- 희귀조각
- 용암계곡 유물조각

**FIXED**

- 일반 보상과 유물조각 판정은 분리할 수 있다. 유물조각이 나오지 않아도 일반 보상은 반드시 지급한다.
- 유물조각은 용암계곡 Stage 3 특별 보물상자에서만 획득한다.
- 유물조각은 최대 `5 / 5`까지만 저장한다. 5개를 모은 뒤에는 유물조각 판정을 중단하고 일반 보상만 지급한다.
- 보상 지급과 저장은 한 번의 확정 처리로 묶어 중복 지급을 막는다.

**TUNABLE**

- 코인, 음식, 일반 아이템, 희귀조각의 수량과 가중치
- 한 상자에서 여러 일반 보상을 함께 지급할지 여부
- 유물조각 획득 시 지급량: 초기값 `1개`

## 4. 유물조각과 pity 규칙

용암계곡 지역 유물조각 필요량은 `5개`이다.

**FIXED**

- 용암계곡에 귀속된 진행도이며 다른 지역과 공유하지 않는다.
- 상점 화폐가 아니며 어떤 구매에도 소모하지 않는다.
- 획득한 수량은 감소하지 않는다.
- UI에는 `용암계곡 유물조각 2 / 5`처럼 표시한다.
- 유물조각 획득에 성공하면 연속 실패 횟수를 `0`으로 초기화한다.

초기 pity 판정안은 다음과 같다.

| 상자 개봉 전 연속 실패 횟수 | 이번 상자 판정 |
|---:|---|
| 0~1회 | 기본 확률 |
| 2회 | 상승 확률 |
| 3회 이상 | 유물조각 확정 |

따라서 세 번 연속 실패했다면 네 번째 Stage 3 보물상자에서 유물조각을 확정 지급한다. 화면에는 확률이나 가챠 용어를 강조하지 않고, 반복 플레이가 지나치게 길어지지 않게 하는 내부 보호 규칙으로 사용한다.

**TUNABLE**

- 기본 획득 확률: `35~40%`, 초기 권장값 `37.5%`
- 2회 연속 실패 후 상승 확률: 초기 권장값 `70%`
- 확정 지급 기준: 초기값 `3회 연속 실패 후 다음 상자`

유료 뽑기, 10연차, 극저확률 등급표 같은 구조는 추가하지 않는다.

## 5. 지역 유물 완성

화산지대 지역 유물은 아래 두 조건을 모두 만족할 때만 완성할 수 있다.

1. 용암계곡 유물조각 `5 / 5`
2. 화산지대 도감 해금률 `100%`

**FIXED**

- 한 조건만 만족하면 유물은 완성되지 않는다.
- 조건 판정은 유물조각 수가 바뀔 때와 화산지대 도감 해금률이 바뀔 때 모두 수행한다.
- 두 조건을 만족하면 지역 유물 복원 상태를 영구 완료로 저장한다.
- 복원 완료 상태는 이후 도감이나 보상 데이터가 조정되더라도 되돌리지 않는다.
- 복원 이벤트는 한 번만 전체 연출하고, 이후에는 완성된 유물과 완료 상태를 보여준다.

복원 연출은 유물 슬롯 또는 실루엣, 다섯 조각의 결합, 완성 유물 공개, `화산지대의 유물이 복원되었어요!` 메시지 순서로 짧고 명확하게 구성한다.

**TUNABLE**

- 조각 결합 및 축하 연출 시간
- 복원 이벤트를 도감 화면과 모험 지역 화면 중 어디에서 먼저 보여줄지

## 6. 희귀조각과의 구분

| 구분 | 희귀조각 | 용암계곡 유물조각 |
|---|---|---|
| 역할 | 상점 화폐 | 지역 메타 진행도 |
| 사용처 | 희귀알 등 구매 | 지역 유물 복원 조건 |
| 소비 여부 | 구매 시 소모 | 소모되지 않음 |
| 지역 귀속 | 공용 | 용암계곡 귀속 |
| 획득처 | 기존 게임 보상 구조 | 용암계곡 Stage 3 특별 보물상자 |

두 값을 같은 재화 필드나 같은 차감 로직으로 처리하지 않는다.

## 7. 전설알 조건과 순환 의존성 방지

용암계곡 전설알 구매 조건은 다음 기존 설계를 유지한다.

- 같은 지역 Stage 3 해금
- 용암계곡 유물조각 `2 / 5` 이상
- 희귀조각 `20개`
- 코인 사용 없음

**FIXED**

- 전설알 구매 시 유물조각은 소모하지 않는다.
- 화산지대 도감 `100%`를 전설알 구매 조건으로 사용하지 않는다.
- 도감 `100%`는 지역 유물의 최종 복원 조건에만 사용한다.

이 구분으로 전설 공룡을 얻어야 도감을 완성할 수 있는데 도감을 먼저 완성해야 전설알을 살 수 있는 순환 의존성을 막는다.

## 8. 저장 데이터 개념

현재 저장 구조의 `adventureStageProgress`와 기존 정규화 방식을 유지하면서 지역 유물 진행도를 확장한다. 아래 이름은 개념 예시이며 실제 변수명은 구현 시 현재 타입과 마이그레이션 규칙에 맞춰 확정한다.

```ts
type LavaValleyRelicProgress = {
  fragments: number;              // 0~5
  completed: boolean;             // 지역 유물 복원 완료
  consecutiveMisses: number;      // 유물조각 연속 미획득 횟수
  stage3FirstCleared: boolean;     // Stage 3 최초 클리어 여부
  chestOpenedCount: number;       // 정상 개봉 완료 횟수
  restorationSeen?: boolean;      // 복원 연출 확인 여부
};
```

**FIXED**

- 기존 사용자 데이터에 필드가 없어도 기본값으로 안전하게 정규화한다.
- 기존 저장 데이터 전체를 초기화하지 않는다.
- `fragments`는 `0~5`로 제한하고 잘못된 값은 정규화한다.
- `completed`는 두 완성 조건을 만족한 뒤 영구적으로 유지한다.
- 상자 보상, 실패 횟수, 개봉 횟수 갱신은 가능한 한 원자적으로 저장한다.

- 이 상태를 `adventureStageProgress` 안에 둘지 별도의 지역 메타 진행 객체에 둘지 현재 저장 타입 확장 시 확정한다.
- 미개봉 상자 복원 정책에 필요한 추가 필드를 확정한다.
- `stage3FirstCleared`와 `chestOpenedCount`를 UI에 사용할지 분석용으로만 보관할지 결정한다.

## 9. 전체 게임 메타 연결

용암계곡 유물 복원 완료는 향후 중앙 오벨리스크의 `completedRegionRelics`에 반영한다.

대상 지역은 용암계곡, 하늘섬, 오래된 유적지, 심해협곡, 얼음대륙의 다섯 곳이다. 다섯 지역 유물을 모두 복원하면 중앙 오벨리스크를 활성화하고 최종 엔딩으로 연결한다. 이 문서에서는 용암계곡의 완료 상태와 연결 지점만 정의하며 오벨리스크와 엔딩은 구현 범위에 포함하지 않는다.

## 10. 추천 구현 순서

1. **Phase 1** — Stage 3 정상 클리어 후 최종 보물상자 생성
2. **Phase 2** — 터치 입력 잠금과 개봉 연출
3. **Phase 3** — 일반 보상 결정, 공개, 중복 지급 방지
4. **Phase 4** — 유물조각 확률, pity 판정, 저장 및 마이그레이션
5. **Phase 5** — `5 / 5` 진행 UI
6. **Phase 6** — 화산지대 도감 `100%` 조건과 양방향 재판정 연결
7. **Phase 7** — 지역 유물 복원 이벤트와 완료 상태 저장
8. **후속 작업** — 완성된 지역 유물을 중앙 오벨리스크 진행도에 연결

각 Phase는 Stage 1/2 보상과 기존 희귀조각 경제에 영향을 주지 않는 작은 변경 단위로 구현한다.
