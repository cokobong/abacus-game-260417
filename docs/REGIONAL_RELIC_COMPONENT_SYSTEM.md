# Regional Relic Component System

이 문서는 지역 유물과 유물 부품 시스템의 source of truth다. Stage 구조와 일반 보상은 `ADVENTURE_STAGE_RELIC_SYSTEM.md`, 용암계곡 최종 상자 흐름은 `LAVA_VALLEY_RELIC_FLOW.md`, 월드맵 표시는 `WORLD_MAP_RELIC_SYSTEM.md`를 함께 따른다.

## 핵심 원칙

- 유물은 하나의 그림을 퍼즐처럼 5등분하지 않는다.
- 각 부품은 고유 ID, 이름, 역할과 향후 독립 이미지 에셋을 갖는 RPG형 전리품이다.
- 서로 다른 부품 5종이 기능적·시각적으로 조립되어 하나의 완성 유물이 된다.
- 지역별 완성 유물의 형태와 실루엣은 서로 달라야 한다.
- 획득 상태의 source of truth는 숫자가 아니라 저장된 `ownedPartIds`다. `0/5` 표시는 유효한 ID 개수로 계산한다.
- 도감 진행도는 유물 획득 및 복원 조건에 포함하지 않는다.

## 저장과 마이그레이션

지역별 진행은 `ownedPartIds`, `completed`, pity용 `consecutiveMisses`, Stage 3 및 상자 기록을 저장한다. 과거 `fragments: N`만 있는 저장은 최초 정규화 시 해당 지역 config의 앞 `N`개 부품 ID로 변환한다. `ownedPartIds`가 존재하면 숫자 값은 무시하며, 유효하지 않은 ID와 중복 ID는 제거한다. 정규화 결과에는 `fragments`를 다시 기록하지 않는다.

기존 완료 저장은 완료 상태와 진행도를 잃지 않도록 해당 지역 5종을 모두 보유한 상태로 보완한다.

## Stage 3 최종 보물상자

기존 드롭 확률, 상승 확률, pity와 연속 실패 횟수를 유지한다.

```text
final chest
→ relic roll
→ 성공 시 missing parts 계산
→ 미보유 부품 중 하나 획득
→ ownedPartIds 저장
```

성공 결과는 항상 새 부품이다. 이미 획득한 부품은 후보에서 제외하고, 5종을 모두 보유하면 추가 부품 판정 없이 일반 상자 보상만 지급한다. 결과 화면은 `유물조각 +1` 대신 실제 부품 이름을 표시한다.

## 복원과 세계의 문

유효한 고유 부품 5종을 모두 보유하면 `복원 가능` 상태가 된다. `유물 복원하기`를 누르면 `completed: true`를 영구 저장하고 세계의 문 완료 수가 1 증가한다. 이미 완료된 유물은 다시 복원할 수 없다.

## UI와 향후 에셋

보관소 메인 카드는 지역별 완성 유물 이름과 독립 실루엣을 받을 수 있는 자리를 유지한다. 상세 화면은 완성 유물 전시 영역과 config의 실제 부품 5종에 연결된 슬롯을 사용한다. 미획득 슬롯은 `???`, 획득 슬롯은 임시 아이콘과 실제 이름을 표시한다.

향후 필요한 에셋은 지역마다 다음 6개다.

- 완성 유물 또는 조립 상태를 표현할 대표 이미지 1개
- 독립 부품 이미지 5개

필요하면 대표 이미지에 `silhouette / assembling / completed` 상태 변형을 추가한다. 기존 토템 형태 이미지는 최종 디자인으로 간주하지 않으며 새 검, 날개 나침반, 태양기계 석판, 진주 성배, 수정 왕관 디자인에 강하게 연결하지 않는다.
