# World Map Relic System

이 문서는 모험 월드맵에서 Stage 진행, 지역 도감, 지역 유물, 최종 메타 목표인 **세계의 문**을 연결하는 공통 규칙을 정의한다. 세부 보상은 `ADVENTURE_STAGE_RELIC_SYSTEM.md`, 용암계곡 보물상자와 유물조각 흐름은 `LAVA_VALLEY_RELIC_FLOW.md`를 따른다.

## 1. 지역 진행 모델

전체 지역은 용암계곡, 하늘섬, 오래된 유적지, 심해협곡, 얼음대륙의 다섯 곳이다. 각 지역은 다음 네 가지 진행 정보를 가진다.

1. Stage 1/2/3 해금 및 완료 진행
2. 해당 지역 도감 해금 수와 전체 수
3. 해당 지역의 서로 다른 유물 부품 `0 / 5`
4. 해당 지역 유물 완성 여부

지역 유물은 고유 유물 부품 5종을 모은 뒤 유물 보관소에서 `유물 복원하기`를 누르면 완성된다. 도감 진행도는 유물 복원 조건이 아니며, 지역 전설알 구매 조건으로 별도 사용한다. 유물 부품은 지역 귀속 진행도이며 소모되지 않는다.

## 2. 월드맵 표시 규칙

지역 버튼에는 모바일 화면에서 겹침을 줄이기 위해 아래 정보만 표시한다.

```text
용암계곡
도감 6/8 · 유물 2/5
입장하기
```

- 지역명
- 도감 `발견 수 / 지역 전체 수`
- 유물 부품 `보유 종류 수 / 5`
- `입장하기`, `준비 중`, `잠김`, `완료` 상태

Stage 상세 정보는 기존 지역 선택 팝업에서만 보여준다. 지역의 기존 위치, 이미지, 입장 및 Stage 선택 동작은 유지한다.

잠긴 지역도 진행 정보는 안전한 값으로 표시한다.

```text
도감 0/8 · 유물 0/5
잠김
```

## 3. 세계의 문

**세계의 문**은 다섯 지역 유물을 연결하는 최종 메타 목표다. 기존 설계 문서의 오벨리스크와 같은 시스템이지만 사용자에게 보이는 모든 문구는 `세계의 문`을 사용한다. 기존 코드와 저장 구조의 변경 비용이 큰 경우 내부의 `obelisk` 계열 이름은 유지할 수 있다.

각 지역 유물이 완성될 때마다 슬롯 하나가 활성화된다.

```text
세계의 문
◆ ◇ ◇ ◇ ◇
1 / 5
```

다섯 지역 유물이 모두 완성되어 `5 / 5`가 되면 세계의 문이 활성화되고 최종 엔딩에 진입할 수 있다. 엔딩 구현은 별도 작업으로 둔다.

## 4. 세계의 문 팝업

지도 위의 세계의 문 패널을 누르면 다음 정보를 표시한다.

```text
세계의 문

지역 유물을 모두 모으면
새로운 세계로 가는 문이 열려요!

용암계곡       완료/미완료
하늘섬         완료/미완료
오래된 유적지  완료/미완료
심해협곡       완료/미완료
얼음대륙       완료/미완료

현재: 1 / 5
```

팝업은 진행 현황만 보여주며 지역 이동이나 보상 지급을 수행하지 않는다.

## 5. 데이터 연결

월드맵의 도감 수치는 저장된 `discoveredSpeciesIds`와 각 공룡의 `habitat`을 대조해 계산한다. 지역 상태와 Stage 선택은 기존 `ADVENTURE_REGIONS`와 `adventureStageProgress`를 그대로 사용한다.

지역 유물 저장 구조는 `regionRelicProgress`에 지역별로 저장되며, 기본값은 다음과 같다.

```ts
{ ownedPartIds: [], completed: false }
```

로드 시 조각 수는 `0~5`로 제한하고 누락된 지역은 기본값으로 보완한다. `completed`는 복원 버튼으로 확정된 영구 완료 상태이며, 완료 지역 수가 세계의 문 진행도다.

## 6. 상태 변화

```text
Stage 3 보물상자에서 미보유 지역 유물 부품 획득
→ `ownedPartIds` 갱신
→ 조각 5/5이면 유물 보관소에서 복원 가능
→ 복원 버튼 입력 시 지역 유물 완료 저장
→ 세계의 문 완료 슬롯 수 재계산
→ 5/5이면 세계의 문 활성화
→ 향후 최종 엔딩 연결
```

지역 유물 완료는 영구 상태이며 이미 완성된 슬롯을 다시 비활성화하지 않는다.

## 7. 구현 범위와 후속 작업

이번 구현은 기존 지도에 지역별 최소 진행 정보, 세계의 문 정적 슬롯 패널, 현황 팝업을 추가한다. 새로운 지도 및 세계의 문 이미지, 연속 애니메이션, 엔딩은 추가하지 않는다.

후속 작업:

- 완성/조립 중 지역별 유물 이미지와 부품 이미지
- 세계의 문 최종 이미지와 `5 / 5` 활성화 상태
- 세계의 문 활성화 및 엔딩 연출
- 모바일 실기기 확인 후 지역 라벨과 패널 위치 조정
