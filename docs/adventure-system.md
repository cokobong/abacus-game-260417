# 모험 시스템

## 모험탭의 목적

- 모험은 플레이어가 탐험을 통해 보상을 얻는 콘텐츠이다.
- 현재 activeDinosaur는 감정적 동행자이자 리액션 역할을 한다.
- 모험은 도감 힌트, 조각 아이템, 부화 아이템, 먹이, 코인을 얻는 확장 루프이다.
- 모험은 훈련장/부화장/도감과 연결된다.

## 모험탭의 역할

- 훈련장: 학습과 기본 보상
- 우리 공룡: 공룡 육성/먹이/코스튬
- 알 부화장: 새 공룡 획득
- 상점: 준비물 구매
- 도감: 수집 성과 감상
- 모험: 도감 힌트와 희귀 재료 발견

## 모험 주체

- 모험의 주체는 플레이어이다.
- activeDinosaur는 함께하는 동행자처럼 표시한다.
- 별도 공룡 선택 UI는 만들지 않는다.
- 공룡 파견/대기/잠금/성공률 시스템은 MVP에서 제외한다.

## 모험 비용

초기 MVP에서는 아래 중 하나를 사용할 수 있다.

- 모험 티켓
- 코인
- 훈련 세트 완료 조건

추천 구조:

- 훈련 1세트 완료 -> 모험 티켓 1개 획득
- 모험 티켓 1개 -> 모험 1회

최종 정책:

- 훈련 1세트 완료 시 모험 티켓 1개를 얻는 구조가 최종 방향이다.
- 모험 티켓은 모험 입장 기회이다.
- 코인은 상점 구매에 주로 사용한다.
- 모험 티켓과 코인을 분리하면 아이가 재화의 역할을 더 쉽게 이해할 수 있다.
- MVP에서는 티켓 지급/소모 로직이 완성되기 전까지 일부 지역을 무료 테스트로 둘 수 있다.

현재 1차 구현에서는 티켓 상태를 새로 만들지 않고, 숲길 산책과 반짝 강가를 무료 테스트로 실행한다. 반짝 강가는 UI에서 "모험 티켓 1개 필요"를 표시하되, 실제 티켓 소모는 TODO로 남긴다.

## 모험 보상

모험 보상 후보:

- 코인
- 먹이
- 부화 아이템
- 공룡 조각 / 알 조각
- 도감 힌트

조각 아이템 정책:

- `egg_fragment` / `dinosaur_fragment` 계열은 모험 보상으로 사용한다.
- 상점에서 기본 구매 가능한 아이템이 아니다.
- MVP에서는 fragment를 `희귀알 조각` 하나로 일반화한다.
- 희귀알 조각은 공통 재화이며 각 희귀알 카드에 따로 누적되지 않는다.
- 사용자가 원하는 서식지 희귀알을 선택해 열 때만 `rare-egg-fragment`가 소비된다.
- 희귀알 조각은 공룡을 직접 해금하는 아이템이 아니다.
- 희귀알마다 필요한 희귀알 조각 수가 다르다.
  - 초록 숲 희귀알: 희귀알 조각 5개
  - 반짝 동굴 희귀알: 희귀알 조각 10개
  - 화산섬 희귀알: 희귀알 조각 15개
  - 비밀의 땅 희귀알: 희귀알 조각 20개
- 모든 서식지 희귀알을 1개씩 열려면 총 50개의 희귀알 조각이 필요하다.
- 희귀알은 알 부화장에서 부화할 수 있다.
- 최종 흐름은 "모험 -> 조각 -> 희귀 알 -> 알 부화장 -> 새 공룡 -> 도감 등록"이다.
- 특정 공룡별 조각 시스템은 MVP에서 만들지 않는다.
- MVP에서는 조각 종류를 늘리지 않고 `rare-egg-fragment` 하나만 사용한다.
- 데이터 구조는 나중에 서식지별 희귀 조각으로 확장할 수 있게 알별 `requiredFragments` 배열을 사용한다.

## 도감 연동

- 모험에서 도감 힌트를 얻을 수 있다.
- 미발견 공룡의 `discoveryHint`가 조금씩 열리는 구조로 확장 가능하다.
- 이번 MVP에서는 힌트 획득 메시지만 표시한다.
- 추후 `discoveredDexHints` 또는 `unlockedHintIds` 같은 저장 필드를 추가할 수 있다.

## 애니메이션 TODO

- 나중에 탐험하기 클릭 후 3초 내외의 짧은 애니메이션을 추가할 수 있다.
- 예: 숲길 배경, 발자국, 반짝 효과, 결과 등장
- MVP에서는 애니메이션 없이 즉시 결과 팝업을 표시한다.
- 현재는 구조와 보상 흐름을 우선한다.

## 알 카테고리 정책

알 카테고리는 아래 3개로 제한한다.

- 일반알: 초반 기본 알이다. 기본 공룡을 만나는 알이며, 상점에서 코인으로 구매할 수 있다.
- 특수알: 테마/서식지 확장용 알이다. 일반알보다 조금 더 특별한 공룡을 기대할 수 있고, 상점/훈련 보상/이벤트성 보상과 연결할 수 있다.
- 희귀알: 모험 조각, 모험 티켓, 도감 힌트와 연결되는 장기 목표 알이다.

상점은 구매 가능한 아이템만 보여준다. fragment 계열 아이템은 상점에서 팔지 않고 모험 보상으로 얻는다. 희귀알은 상점의 알 탭에서 장기 목표로 보여줄 수 있지만, 코인으로 바로 구매하지 않는다.

희귀알 조각은 공룡을 직접 얻는 아이템이 아니라 희귀알 해금 재료로 사용한다.

예상 흐름:

- 모험에서 희귀알 조각 획득
- 원하는 서식지 희귀알의 필요 수량만큼 조각 보유
- 서식지별 희귀알 1개 열기
- 알 부화장에서 부화
- 새 공룡 획득
- 도감 등록

MVP에서는 `rare-egg-fragment` 하나로 서식지별 희귀알을 여는 단순 교환만 사용한다. 희귀알 조각은 각 희귀알에 자동 누적되지 않고, 선택한 서식지 희귀알을 열 때 필요한 수량만큼 차감된다. 복잡한 조각 합성 시스템, 공룡별 조각 시스템, 서식지별 희귀 조각은 만들지 않는다.

## 도감 24종 목표 구조

- 도감의 1차 목표는 24종이다.
- 기본 구조는 4개 서식지 x 6종이다.
- 서식지는 `green-forest`, `sparkle-cave`, `volcano-island`, `secret-land`를 기준으로 한다.
- 서식지는 초록 숲 -> 반짝 동굴 -> 화산섬 -> 비밀의 땅 순서로 채워진다.
- 각 서식지는 일반 공룡 3종, 특수 공룡 2종, 희귀 공룡 1종으로 구성한다.
- 총합은 일반 공룡 12종, 특수 공룡 8종, 희귀 공룡 4종이다.
- placeholder species는 도감에서 미발견/잠금/준비 중 카드로 표시되지만, 실제 부화나 획득 후보에는 포함하지 않는다.
- 장기적으로는 36종까지 확장할 수 있지만, 현재 UI 기준은 24종이다.
- 일반알/특수알/희귀알과 모험 조각 시스템은 이 24종 도감 구조와 연결된다.

## 부화 순서 정책

- 첫 공룡 선택 후보는 티라노사우르스, 브라키오, 트리케라, 알로사우루스 4종이다.
- 이 4종은 기본 공룡 12종에 포함된다.
- 일반알 부화 후보는 첫 선택 후보 4종을 포함한 기본 공룡 12종 전체다.
- 특수알 부화 후보는 특수 공룡 8종이다.
- 희귀알 부화 후보는 희귀 공룡 4종이다.
- 알 부화는 랜덤이 아니라 `collectionOrder` 기준으로 아직 보유하지 않은 다음 공룡을 선택한다.
- 벨로시랩터는 기존 “랩터”의 명확한 이름으로 사용한다.
