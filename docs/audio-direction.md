# 오디오 방향성

이 문서는 주산 훈련 공룡 게임의 BGM, 효과음, 오디오 설정, 초기 구현 범위를 정리한다.
오디오는 학습 몰입을 돕는 보조 장치이며, 문제풀이 집중을 방해하거나 반복 피로를 높이면 안 된다.

## 1. 전체 톤

- 밝고 귀여운 키즈 게임 톤을 유지한다.
- 7~8세 아이가 반복해서 들어도 피곤하지 않은 짧고 부드러운 사운드를 우선한다.
- 문제풀이 화면에서는 숫자 인지와 입력 흐름을 방해하지 않는다.
- 보상음은 성취감을 주되, 너무 길거나 과하게 자극적이지 않게 한다.
- 오답음은 실망감보다 “다시 해보자” 느낌이 나도록 낮은 강도로 둔다.
- 블루투스 주판 입력음은 아이가 물리 입력이 앱에 들어왔음을 알 수 있을 정도로만 짧게 재생한다.

## 2. 화면별 BGM

| 화면 | BGM 방향 | 강도 | 메모 |
| --- | --- | --- | --- |
| 우리 공룡 | 따뜻하고 안정적인 메인 홈 느낌 | 낮음~중간 | 공룡 성장과 애착을 느끼는 화면 |
| 훈련장 | 리듬감은 있지만 단순한 집중용 루프 | 낮음 | 문제풀이 중 BGM 끄기 옵션을 우선 고려 |
| 부화장 | 조용하고 기대감 있는 반짝임 | 낮음~중간 | 알 흔들림/힌트 효과음이 묻히지 않게 함 |
| 놀이터 | 밝고 통통 튀는 놀이 분위기 | 중간 | 먹이주기, 쓰다듬기, 코스튬 반응과 어울리게 함 |
| 모험 | 가벼운 탐험, 숲길, 설렘 | 중간 | 출발/완료 효과음과 함께 기대감 형성 |
| 상점 | 짧고 산뜻한 쇼핑/메뉴 루프 | 낮음 | 구매 결정을 방해하지 않게 반복 피로 낮게 |
| 도감 | 발견 기록을 보는 차분한 탐색감 | 낮음 | 해금 효과음이 돋보이도록 배경은 얌전하게 |

## 3. 효과음 목록

| 이벤트 | 사운드 방향 | 보상 강도 | 메모 |
| --- | --- | --- | --- |
| 버튼 클릭 | 짧고 둥근 탭 소리 | 낮음 | 모든 UI 기본 입력 |
| 숫자 입력 | 가볍고 명확한 톡 소리 | 낮음 | 연속 입력해도 피곤하지 않게 |
| 블루투스 주판 입력 | 물리 장치 확인 느낌의 짧은 삑/딸깍 | 낮음 | 설정에서 끌 수 있어야 함 |
| 정답 | 밝은 성공음 | 중간 | 빠른 문제풀이 흐름을 끊지 않게 짧게 |
| 오답 | 부드러운 재시도음 | 낮음 | 경고음처럼 들리지 않게 |
| 코인 획득 | 짧은 반짝/찰랑 소리 | 중간 | 여러 개 획득 시 겹침 제한 필요 |
| EXP 획득 | 작게 차오르는 상승음 | 낮음~중간 | 코인보다 덜 자극적으로 |
| 레벨업 | 상승감 있는 팡파르 | 높음 | 성장 보상 핵심 이벤트 |
| 아이템 구매 | 산뜻한 구매 완료음 | 중간 | 코인 차감과 함께 명확히 전달 |
| 먹이주기 | 부드럽고 귀여운 먹는 소리 | 중간 | 공룡 반응음과 함께 사용 가능 |
| 코스튬 착용 | 반짝이는 착용 완료음 | 중간 | 외형 변화의 만족감 |
| 알 흔들림 | 작고 둥근 흔들림 소리 | 중간 | 부화 진행률 힌트 |
| 알 깨짐 | 바삭하고 기대감 있는 균열 소리 | 높음 | 75% 이후 단계에서 사용 |
| 부화 완료 | 짧은 축하 팡파르 | 최고 | 새 공룡 등장 핵심 보상 |
| 도감 해금 | 반짝이는 등록음 | 높음 | 부화 완료 후 도감 등록 시 |
| 모험 출발 | 가벼운 출발 신호음 | 중간 | 모험이 시작되었음을 명확히 표시 |
| 모험 완료 | 작은 승리/귀환음 | 높음 | 보상 받기 버튼과 연결 |

## 4. 보상 강도 기준

| 강도 | 사용 상황 | 길이 방향 | 예시 |
| --- | --- | --- | --- |
| 낮음 | 반복 입력, 일반 UI 피드백 | 매우 짧음 | 버튼 클릭, 숫자 입력, 주판 입력 |
| 중간 | 작은 성취, 일반 보상 | 짧음 | 정답, 코인, 구매, 먹이주기 |
| 높음 | 성장/진행 단계 변화 | 중간 | 레벨업, 알 깨짐, 도감 해금, 모험 완료 |
| 최고 | 희귀하거나 큰 보상 | 중간~짧은 연출 | 부화 완료, 특별 공룡 등장 |

- 낮음/중간 강도 사운드는 자주 반복되므로 음량과 길이를 보수적으로 잡는다.
- 높음/최고 강도 사운드는 자주 나오지 않는 이벤트에만 사용한다.
- 문제풀이 중에는 최고 강도 사운드를 남발하지 않는다.

## 5. 설정탭 옵션

설정탭에는 다음 오디오 옵션을 둔다.

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| 전체 소리 | 켜짐 | 모든 BGM/SFX의 마스터 스위치 |
| BGM | 켜짐 | 배경음만 켜고 끄기 |
| 효과음 | 켜짐 | 버튼, 정답, 보상 등 효과음 켜고 끄기 |
| 볼륨 | 70% | 전체 볼륨 슬라이더 |
| 문제풀이 중 BGM 끄기 | 꺼짐 | 훈련장 집중을 위해 문제풀이 중 배경음만 끄기 |
| 주판 입력 확인음 | 켜짐 | 블루투스 주판 입력 수신 확인음 |

- 설정값은 GameState 또는 사용자 설정 저장 영역에 포함한다.
- 앱 재실행 후에도 설정이 복원되어야 한다.
- 블루투스 주판 입력 확인음은 효과음 전체 설정과 별도로 끌 수 있게 둔다.

## 6. 향후 파일 구조

오디오 파일을 추가할 때는 다음 구조를 우선 고려한다.

```text
src/assets/audio/bgm/
src/assets/audio/sfx/
```

예상 파일 예시:

```text
src/assets/audio/bgm/home.mp3
src/assets/audio/bgm/training.mp3
src/assets/audio/bgm/hatchery.mp3
src/assets/audio/sfx/click.wav
src/assets/audio/sfx/correct.wav
src/assets/audio/sfx/wrong.wav
src/assets/audio/sfx/coin.wav
src/assets/audio/sfx/level-up.wav
src/assets/audio/sfx/hatch-complete.wav
src/assets/audio/sfx/pokedex-unlock.wav
```

파일명은 영어 소문자와 하이픈을 사용한다.
루프 BGM은 파일 크기를 과하게 키우지 않고, 짧은 루프가 자연스럽게 이어지는 형태를 우선한다.

## 7. 초기 구현 우선순위

1차 구현에서는 모든 사운드를 다 만들기보다, 학습 피드백과 핵심 보상에 필요한 소리부터 연결한다.

우선순위:

1. 버튼 클릭
2. 정답
3. 오답
4. 코인 획득
5. 레벨업
6. 부화 완료
7. 도감 해금

초기에는 BGM 없이 효과음만 먼저 연결해도 된다.
문제풀이 집중과 반복 피로를 확인한 뒤 화면별 BGM을 추가한다.

## 8. Fallback 원칙

- 오디오 파일이 없어도 앱이 깨지면 안 된다.
- 특정 파일 로드에 실패하면 해당 사운드만 조용히 생략한다.
- 사운드 재생 실패가 문제풀이, 정답 제출, 보상 지급을 막으면 안 된다.
- 브라우저 자동 재생 정책 때문에 BGM이 바로 재생되지 않을 수 있으므로, 첫 사용자 입력 이후 재생을 시도한다.
- 오디오 로딩 상태는 게임 진행의 필수 조건이 아니다.
- 개발 중에는 파일이 비어 있거나 TODO 상태여도 AudioManager가 안전하게 no-op 처리할 수 있어야 한다.

## 9. 구현 메모

- 화면 컴포넌트가 직접 오디오 파일 경로를 많이 알지 않도록 AudioManager 같은 계층을 둔다.
- 게임 이벤트는 `playSfx("correct")`, `playSfx("coin")`, `playBgm("hatchery")`처럼 의미 기반 이름으로 호출한다.
- 같은 효과음이 아주 짧은 시간에 여러 번 겹치면 음량이 커지므로, 코인/EXP 같은 반복음은 재생 간격 제한을 둔다.
- 설정탭의 볼륨과 on/off 값은 모든 오디오 재생 함수에서 공통 적용한다.
- 문제풀이 화면에서는 BGM보다 입력음, 정답/오답음의 명확성을 우선한다.
