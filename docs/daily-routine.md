# 하루 학습 루틴과 과몰입 방지

이 문서는 아이가 매일 부담 없이 반복 학습할 수 있도록 하루 루틴, 보상 빈도, 과몰입 방지 원칙을 정리한다.
목표는 오래 붙잡는 게임이 아니라, 짧고 꾸준한 주판 훈련 습관을 만드는 것이다.

## 1. 기본 철학

- 매일 작은 성취감을 준다.
- 큰 보상은 며칠~몇 주 단위 목표로 둔다.
- 하루 학습량은 짧고 명확하게 잡는다.
- 보상은 반복학습을 더 하고 싶게 만들되, 과도한 반복을 강요하지 않는다.
- 부모가 하루 목표와 제한을 조정할 수 있어야 한다.

## 2. 권장 하루 루틴

기본 루틴:

```text
앱 실행
→ 블루투스 주판 연결 확인
→ 오늘의 목표 확인
→ 20문제 1세트 풀이
→ 결과와 보상 확인
→ 알/공룡 변화 확인
→ 종료 또는 추가 1세트
```

권장 플레이량:

| 플레이량 | 의미 |
| --- | --- |
| 1세트 | 기본 하루 목표 |
| 2세트 | 컨디션 좋은 날 |
| 3세트 | 최대 권장량 |
| 4세트 이상 | 쉬기 안내 우선 |

대상 연령이 7~8세이므로, 1회 세션은 3~10분 안에 끝나는 것을 목표로 한다.

## 3. 오늘의 목표

오늘의 목표는 단순하고 달성 가능해야 한다.

예시:

- 20문제 1세트 완료
- 정답 15개 이상
- 5문제 연속 정답
- 알 부화 진행 1칸 올리기
- 공룡에게 먹이 1번 주기

목표는 하루에 1~3개 정도만 보여준다.
너무 많은 체크리스트는 학습 부담을 높인다.

## 4. 과몰입 방지 원칙

- 하루 3세트 이후에는 보상 증가를 제한한다.
- 4세트 이상부터는 `쉬기` 안내를 보여준다.
- 최고 보상은 하루 반복 횟수보다 정확도와 꾸준함에 연결한다.
- 연속 플레이보다 다음 날 다시 오는 것을 칭찬한다.
- 시간 제한, 손실 회피, 기간 한정 압박을 초기 버전에서는 쓰지 않는다.

쉬기 안내 문구:

```text
오늘 훈련을 많이 했어요.
공룡도 잠깐 쉬고 싶대요.
```

## 5. 보상 제한

하루 보상은 완전히 막기보다 점점 완만하게 만든다.

예시:

| 하루 세트 | 보상 처리 |
| ---: | --- |
| 1세트 | 정상 보상 + 오늘 목표 보상 |
| 2세트 | 정상 보상 |
| 3세트 | 정상 보상, 쉬기 안내 |
| 4세트 이상 | 코인/EXP는 지급하되 일일 보너스 없음 |

부화 진행도도 하루에 너무 많이 밀리지 않도록 알 종류별 일일 상한을 둘 수 있다.
단, 초기 구현에서는 경고 문구와 일일 보너스 제한만으로 시작해도 충분하다.

## 6. 출석과 연속 학습

출석은 압박보다 환영의 느낌으로 둔다.

좋은 방향:

- 오늘 첫 접속 보너스
- 3일 연속 학습 축하
- 주간 목표 완료 축하

피해야 할 방향:

- 하루 빠지면 큰 손해
- 연속 출석 끊김을 강하게 표시
- 보상을 받지 못하면 불안하게 만드는 문구

문구 예시:

```text
오늘도 공룡이 기다리고 있었어요!
```

## 7. 부모 설정과 연결

부모가 조정할 수 있는 항목:

- 하루 권장 세트 수
- 하루 최대 세트 안내 기준
- 오늘의 목표 표시 여부
- 출석 보상 켜기/끄기
- 문제풀이 중 BGM 끄기
- 쉬기 안내 강도

기본값:

```text
하루 권장 세트 수: 1세트
쉬기 안내 시작: 3세트 완료 후
일일 보너스 지급: 하루 첫 1~2세트 중심
```

## 8. 저장 데이터

저장할 값 예시:

```ts
dailyRoutine: {
  date: "YYYY-MM-DD",
  completedSetCount: number,
  dailyQuestIds: string[],
  claimedDailyRewardIds: string[],
  streakDays: number,
  lastPlayedAt: number
}
```

날짜 기준은 로컬 날짜를 사용한다.
추후 서버 동기화가 생기면 날짜 처리 기준을 다시 정한다.

## 9. 초기 구현 범위

1차 구현:

- 오늘 완료 세트 수 저장
- 하루 첫 세트 완료 보너스
- 3세트 이후 쉬기 안내
- 간단한 오늘 목표 1개

후속 구현:

- 일일 퀘스트 3개
- 주간 목표
- 출석 보상
- 부모 설정 기반 제한
- 일일 보상 상한
