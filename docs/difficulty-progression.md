# 문제 난이도 Progression

이 문서는 7~8세 아이가 주판 훈련을 반복하면서 무리 없이 난이도를 올릴 수 있도록 문제 progression 기준을 정리한다.
정확도를 우선하고, 속도는 충분히 안정된 뒤 보너스로만 사용한다.

## 1. 기본 원칙

- 처음에는 쉬운 덧셈으로 성공 경험을 만든다.
- 난이도 상승은 정확도와 세트 완료 경험을 기준으로 한다.
- 속도가 빠르다는 이유만으로 난이도를 올리지 않는다.
- 아이가 실패를 반복하면 자동으로 난이도를 낮추거나 유지한다.
- 부모가 수동으로 난이도를 고정할 수 있어야 한다.
- 문제풀이 보상은 난이도에 따라 조정할 수 있지만, 어려운 문제를 강요하지 않는다.

## 2. 난이도 단계

| 단계 | 문제 유형 | 예시 | 목표 |
| --- | --- | --- | --- |
| 1단계 | 한 자리 수 3개 덧셈 | `4 + 2 + 3` | 첫 성공 경험 |
| 2단계 | 한 자리 수 4개 덧셈 | `3 + 5 + 1 + 2` | 집중 유지 |
| 3단계 | 한 자리 수 5~6개 덧셈 | `1 + 4 + 2 + 7 + 3` | 짧은 기억 확장 |
| 4단계 | 두 자리 수 3개 덧셈 | `12 + 24 + 31` | 자릿수 감각 |
| 5단계 | 한 자리 수 덧셈/뺄셈 | `8 + 5 - 3` | 연산 전환 |
| 6단계 | 두 자리 수 덧셈/뺄셈 | `23 + 14 - 12` | 중급 훈련 |
| 7단계 | 받아올림 포함 | `18 + 27 + 6` | 후속 확장 |
| 8단계 | 받아내림 포함 | `42 - 18 + 7` | 후속 확장 |

1차 버전에서는 1~6단계를 중심으로 설계한다.
받아올림/받아내림은 문서에는 남기되 초기 구현 필수 범위에서 제외할 수 있다.

## 3. 승급 조건

난이도 승급은 최근 플레이 기록을 기준으로 판단한다.

권장 기준:

| 조건 | 의미 |
| --- | --- |
| 최근 3세트 평균 정확도 85% 이상 | 다음 단계 후보 |
| 최근 3세트 모두 완료 | 집중 유지 가능 |
| 오답률 급증 없음 | 난이도 상승 가능 |
| 부모 설정에서 자동 승급 허용 | 자동 적용 가능 |

승급 안내 예시:

```text
이제 조금 더 어려운 문제에 도전할 수 있어요!
```

자동으로 바로 바꾸기보다, 부모 또는 아이가 선택할 수 있게 한다.

```text
[지금 도전] [다음에 할래요]
```

## 4. 유지와 하향 조건

난이도를 낮추는 것은 실패가 아니라 부담을 줄이는 조정으로 표현한다.

하향 또는 유지 기준:

| 조건 | 처리 |
| --- | --- |
| 최근 2세트 정확도 60% 미만 | 현재 단계 유지 또는 한 단계 낮춤 제안 |
| 세트 중 중단이 잦음 | 문제 수를 줄이는 안내 |
| 오답이 연속으로 많음 | 집중 모드 또는 쉬운 문제 추천 |
| 부모가 난이도 고정 | 자동 조절 비활성 |

문구 예시:

```text
오늘은 쉬운 문제로 다시 힘을 모아볼까요?
```

## 5. 문제 수와 난이도

기본 세트는 20문제지만, 상황에 따라 10문제/15문제도 허용한다.

| 문제 수 | 사용 상황 |
| ---: | --- |
| 10문제 | 첫 실행, 짧은 복습, 피곤한 날 |
| 15문제 | 중간 길이 훈련 |
| 20문제 | 기본 학습 세트 |

- 보상과 부화 진행은 20문제 기준을 기본으로 하되, 짧은 세트는 비례 보상으로 처리한다.
- 10문제 세트를 선택했다고 아이가 손해 본다고 느끼지 않게 작은 완료 보상을 둔다.

## 6. 속도 기준 조정

속도는 정확도가 충분할 때만 보너스로 쓴다.

- 난이도가 올라가면 문제당 평균 시간 기준도 느슨하게 조정할 수 있다.
- 두 자리 수와 뺄셈 포함 문제는 한 자리 덧셈보다 더 긴 평균 시간을 허용한다.
- 속도 보너스는 학습 압박보다 “집중해서 잘 풀었다”는 칭찬으로 표현한다.

예시:

| 난이도 | S 속도 기준 예시 |
| --- | --- |
| 1~2단계 | 문제당 6초 이하 |
| 3~4단계 | 문제당 8초 이하 |
| 5~6단계 | 문제당 10초 이하 |

정확한 수치는 실제 플레이 데이터를 보고 조정한다.

## 7. 부모/관리자 설정과 연결

부모 설정에서 제공할 수 있는 항목:

- 자동 난이도 조절 켜기/끄기
- 최대 난이도 제한
- 뺄셈 포함 허용 여부
- 두 자리 수 허용 여부
- 하루 권장 세트 수
- 문제 수 기본값

부모가 난이도를 고정한 경우 앱은 자동 승급을 제안하지 않는다.

## 8. 초기 구현 범위

1차 구현:

- 1~4단계 수동 선택
- 기본값 1단계
- 최근 정확도 기록 저장
- 승급 제안 문구만 표시

2차 구현:

- 5~6단계 추가
- 자동 난이도 추천
- 부모 설정의 최대 난이도 제한

후속:

- 받아올림/받아내림
- 개인별 속도 기준 자동 보정
- 약한 유형 복습 추천
