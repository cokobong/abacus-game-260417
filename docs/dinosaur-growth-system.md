# 공룡 성장 시스템

이 문서는 공룡의 경험치, 레벨업, 성장 단계, 체력, 행복, 먹이, 놀이터, 도감 연계를 정리하는 기준 문서다. 구현 세부 수치와 함수명은 이후 조정할 수 있지만, MVP의 정책 방향은 이 문서를 우선한다.

## 1. 핵심 루프

공룡은 아이가 훈련 문제를 풀 때 함께 성장한다.

```text
훈련 문제 풀이
-> 경험치 획득
-> 레벨 상승
-> 성장 단계 변화
-> 말풍선/뱃지/도감 상태 변화
```

경험치는 단순 숫자가 아니라 아이가 "내 공룡이 나와 함께 자란다"는 느낌을 받게 하는 핵심 보상이다. 문제 난이도 자체는 공룡 레벨과 분리하고, 실제 학습 진도는 `docs/problem-difficulty.md`를 기준으로 관리한다.

## 2. 상태 수치 정책

MVP에서 크게 다루는 공룡 상태는 아래로 제한한다.

| 수치 | 역할 |
| --- | --- |
| `level` | 성장 레벨 |
| `exp` | 현재 레벨에서 쌓은 경험치 |
| `expToNextLevel` | 다음 레벨까지 필요한 경험치 |
| `growthStage` | `baby`, `child`, `teen`, `adult` 성장 단계 |
| `stamina` 또는 `health` | 훈련/모험에 쓰는 행동 자원 |
| `happiness` | 감정 상태와 회복 효율 보너스 |

사용하지 않거나 deprecated 처리할 수치:

- `fullness`
- `satiety`
- `hunger`
- 포만감

정책:

- 포만감은 별도 수치로 유지하지 않는다.
- 먹이는 체력 회복 아이템이다.
- 놀이터/상호작용은 행복 회복 기능이다.
- 행복이 높으면 먹이/휴식의 체력 회복량이 소폭 증가한다.
- 행복이 낮아도 훈련을 막지 않는다.
- 체력이 낮아도 훈련을 완전히 막지 않고, 안내 문구를 보여주는 정도로 둔다.

## 3. 경험치 획득 초안

MVP의 경험치 지급은 단순하게 시작한다. 아래 값은 초기값이며, 실제 플레이 데이터에 따라 `docs/balance-config.md`에서 조정한다.

| 조건 | EXP |
| --- | ---: |
| 정답 1개 | +1 |
| 훈련 세트 완료 | +5 |
| 완벽 완료 또는 높은 정확도 보너스 | +5 |

예: 20문제 세트에서 20개를 모두 맞히면 정답 EXP 20 + 세트 완료 보너스 5 + 완벽 보너스 5로 총 30 EXP를 줄 수 있다.

오답이 있어도 세트 완료 보너스는 줄 수 있다. 완벽 완료 보너스는 오답이 없을 때만 지급하는 방향이 자연스럽다.

경험치에 적용하지 않는 것:

- 먹이 사용
- 코스튬 착용
- 알 부화 아이템 사용
- 희귀알 조각 획득

## 4. 레벨업 구조 초안

공룡은 `exp >= expToNextLevel`이 되면 레벨이 오른다.

추천 초안:

```text
expToNextLevel = 20 + level * 5
```

정책:

- 공룡은 Lv.1부터 시작한다.
- 레벨업 시 남은 EXP는 다음 레벨로 이월할 수 있다.
- 수식은 구현 단계에서 조정 가능하다.
- 레벨업은 성능 강화보다 성장감과 애착을 주는 이벤트로 다룬다.

레벨업 시 확인할 변화:

- 레벨 숫자 증가
- 말풍선 변화
- 성장 단계 조건 체크
- 최대 체력 소폭 증가 가능
- 도감 성장 상태 갱신 가능

## 5. 성장 단계

성장 단계는 레벨 구간으로 나눈다.

| growthStage | 한국어 표시 | 레벨 구간 |
| --- | --- | --- |
| `baby` | 아기 | Lv.1~4 |
| `child` | 어린이 | Lv.5~9 |
| `teen` | 청소년 | Lv.10~19 |
| `adult` | 어른 | Lv.20+ |

MVP에서는 성장 단계별 실제 이미지가 없어도 된다. 초기에는 문구, 뱃지, 도감 상태, 말풍선 변화만으로도 충분하다. 나중에 이미지가 준비되면 `growthStage`에 따라 공룡 외형을 다르게 보여줄 수 있다.

## 6. 성장 단계별 리액션

성장 단계 변화는 큰 보상처럼 보여야 한다.

| 조건 | 변화 | 예시 문구 |
| --- | --- | --- |
| Lv.5 | 아기 -> 어린이 | "나 조금 더 컸어요!" |
| Lv.10 | 어린이 -> 청소년 | "이제 더 멀리 모험 갈 수 있어요!" |
| Lv.20 | 청소년 -> 어른 | "멋진 공룡으로 자랐어요!" |

주의:

- 성장 단계별 복잡한 능력치를 많이 추가하지 않는다.
- MVP에서는 문구, 뱃지, 도감 상태 중심으로 정리한다.
- 성장 완료 공룡도 계속 훈련할 수 있다.

## 7. 체력과 행복

체력은 실제 운영 수치이고, 행복은 감정 상태와 회복 보너스 수치다.

체력 사용처:

- 훈련 세트 완료 또는 정답 처리 시 소량 감소
- 모험 실행 시 소량 감소
- 먹이 사용 시 회복
- 휴식 기능이 있다면 회복

행복 사용처:

- 우리 공룡 탭 말풍선
- 공룡 상태 문구
- 놀이터/상호작용 결과
- 먹이/휴식의 체력 회복량 보너스

행복 보정 초안:

| happiness | 회복 배율 |
| ---: | ---: |
| 0~39 | x1.0 |
| 40~69 | x1.1 |
| 70~89 | x1.2 |
| 90~100 | x1.3 |

적용 대상:

- 먹이 사용 시 체력 회복
- 휴식 기능이 있다면 휴식 체력 회복

적용하지 않을 대상:

- 훈련 경험치
- 코인 보상
- 알 부화 에너지
- 희귀알 조각
- 상점 구매

## 8. 먹이와 놀이터

먹이는 체력 회복 아이템이다. 포만감 증가 아이템이 아니며, 경험치 아이템도 아니다.

먹이 예시:

- 작은 열매: 체력 +10
- 든든한 잎사귀: 체력 +20
- 특별 간식: 체력 +30

놀이터/상호작용은 행복 회복 기능이다.

상호작용 예시:

- 쓰다듬기: 행복 +5
- 놀아주기: 행복 +10, 체력 -5
- 쉬기: 체력 회복 + 행복 소폭 증가

놀이터 기능이 단순한 단계라면 아래만 지킨다.

- 놀이터/상호작용은 행복을 올린다.
- 먹이는 체력을 올린다.
- 행복이 높으면 먹이/휴식 체력 회복량이 조금 증가한다.
- 포만감은 사용하지 않는다.

## 9. 도감 연계

도감은 단순 발견 여부뿐 아니라 성장 상태를 나중에 표시할 수 있다.

도감 상태 예:

- 미발견
- 발견함
- 함께 훈련 중
- 성장 완료

공룡 상세 예:

- 트리케라
- 발견 완료
- 성장 단계: 어린이
- 레벨: 7

MVP에서 도감 UI에 모두 반영하지 않아도 된다. 다만 데이터 구조는 레벨과 성장 단계가 도감 상세에 표시될 수 있도록 열어둔다.

## 10. 성장 완료 이후

`adult` 또는 Lv.20 이상 공룡은 성장 완료 상태를 줄 수 있다.

정책:

- 성장 완료 공룡도 계속 훈련 가능하다.
- 다만 새로운 공룡도 키워보도록 자연스럽게 유도한다.
- 도감에 성장 완료 뱃지를 표시할 수 있다.

문구 예:

- "이 공룡은 멋지게 성장했어요!"
- "다른 공룡 친구도 키워볼까요?"

## 11. 데이터 구조 초안

현재 코드의 `OwnedDinosaur`는 `level`, `exp`, `mood`, `stamina`를 사용한다. 문서상 의도는 아래처럼 매핑한다.

| 의도 | 현재 코드 필드 | 향후 문서 필드 |
| --- | --- | --- |
| 별명/이름 | `name` | `nickname` 또는 `name` |
| 행복 | `mood` | `happiness` |
| 체력 | `stamina` | `stamina` 또는 `health` |
| 성장 단계 | 없음 | `growthStage` |
| 다음 레벨 EXP | 없음 | `expToNextLevel` |
| 최대 체력 | 없음 | `maxStamina` |

### DinosaurInstance 초안

```ts
interface DinosaurInstance {
  id: string;
  speciesId: string;
  nickname: string;
  level: number;
  exp: number;
  expToNextLevel: number;
  growthStage: 'baby' | 'child' | 'teen' | 'adult';
  stamina: number;
  maxStamina: number;
  happiness: number;
  equippedCostumeIds: string[];
  createdAt: number;
  updatedAt: number;
}
```

### Species 초안

```ts
interface Species {
  speciesId: string;
  name: string;
  habitat: string;
  rarity: string;
  eggCategory: 'normal' | 'special' | 'rare';
  collectionOrder: number;
  starterSelectable: boolean;
  availableGrowthStages: Array<'baby' | 'child' | 'teen' | 'adult'>;
  dexDescription: string;
  discoveryHint: string;
}
```

- 성장/EXP의 기준 정책은 이 문서를 따른다.
- 수치 밸런스는 `docs/balance-config.md`에서 조정한다.
- 저장 데이터 구조는 `docs/data-model.md`에서 관리한다.
- 결과 화면과 우리 공룡 탭의 표현은 `docs/game-ui-redesign.md`에서 요약만 관리한다.
- 먹이 가격과 아이템 역할은 `docs/shop-items.md`에서 관리한다.
