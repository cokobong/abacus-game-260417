# 오답/실패 피드백과 결과 화면

이 문서는 문제풀이 중 정답/오답 피드백과 20문제 완료 후 결과 화면의 설계를 정리한다.
핵심은 아이가 틀려도 위축되지 않고, 세트 완료와 정확한 반복을 계속하고 싶게 만드는 것이다.

## 1. 피드백 원칙

- 정답은 즉시, 짧고 기분 좋게 알려준다.
- 오답은 부드럽게 알려주고, 실패처럼 과장하지 않는다.
- 빠른 풀이보다 정확한 풀이를 칭찬한다.
- 보상은 문제풀이를 대체하지 않고 반복 학습을 돕는 장치로 둔다.
- 부모가 봐도 학습 결과가 명확해야 한다.

## 2. 정답 피드백

정답 시 표현:

- 짧은 성공 효과음
- 코인 획득 예정 표시
- 공룡의 작은 기쁨 반응
- 입력칸 또는 문제 카드의 부드러운 강조

문구 예시:

```text
좋아요!
정확해요!
잘했어요!
```

정답 피드백은 다음 문제로 넘어가는 흐름을 방해하지 않을 정도로 짧게 유지한다.

## 3. 오답 피드백

오답 시 표현:

- 부드러운 재시도 효과음
- 강한 빨강 대신 주황/핑크 계열의 약한 강조
- 입력칸의 짧은 흔들림
- 공룡의 응원 표정

문구 예시:

```text
다시 생각해보자.
천천히 해도 괜찮아요.
한 번 더 확인해볼까요?
```

피해야 할 표현:

- 큰 실패음
- 체력 감소처럼 벌을 주는 연출
- `틀렸어요!` 같은 강한 부정 문구
- 보상을 모두 빼앗는 구조

## 4. 연속 오답 처리

연속 오답이 발생하면 아이가 당황하지 않도록 속도를 낮춘다.

| 상황 | 처리 |
| --- | --- |
| 2문제 연속 오답 | 응원 문구 표시 |
| 3문제 연속 오답 | 다음 문제 전 짧은 호흡 안내 |
| 5문제 이상 오답 많음 | 결과 화면에서 쉬운 문제 추천 |

문구 예시:

```text
잠깐 쉬고 천천히 다시 해볼까요?
```

힌트를 바로 정답처럼 주지는 않는다.
1차 버전에서는 힌트보다 난이도 유지/하향 추천을 우선한다.

## 5. 세트 중 이탈

아이가 세트 중 나가려 할 때는 확인을 둔다.

```text
아직 훈련이 끝나지 않았어요.
나가면 이번 세트 보상은 저장되지 않을 수 있어요.
```

버튼:

```text
[계속 풀기] [나가기]
```

- 실수로 나가는 것을 막되, 억지로 붙잡지 않는다.
- 중간 저장 여부는 구현 범위에 따라 정한다.
- 1차 버전에서는 세트 완료 후 보상 정산을 기본으로 둔다.

## 6. 20문제 결과 화면

결과 화면은 한 세트를 끝낸 성취감을 주는 화면이다.

표시 항목:

- 총 문제 수
- 정답 수
- 정확도
- 걸린 시간
- 속도 등급
- 연속 성공 기록
- 획득 코인
- 획득 EXP
- 현재 공룡 성장 변화
- 부화 진행 변화
- 다음 추천 행동

예시:

```text
20문제 세트 완료!
정답 17 / 20
정확도 85%
획득 코인 125
공룡 EXP +40
알 부화 진행 +1
```

## 7. 결과 화면 우선순위

가장 크게 보여줄 것:

1. 세트 완료 축하
2. 정답 수와 정확도
3. 획득 코인/EXP
4. 공룡 또는 알의 변화

보조로 보여줄 것:

- 속도 등급
- 평균 문제당 시간
- 연속 정답
- 다음 추천 버튼

아이에게는 성취와 보상을 먼저 보여주고, 부모에게는 정확도와 시간 정보를 명확히 보여준다.

## 8. 결과 후 행동

결과 화면 버튼:

| 버튼 | 목적 |
| --- | --- |
| 다시 훈련 | 바로 다음 세트 |
| 알 보러 가기 | 부화 진행 확인 |
| 공룡 보기 | 성장 확인 |
| 상점 가기 | 코인 사용 |
| 쉬기 | 홈으로 이동 |

하루 권장 세트를 초과한 경우에는 `다시 훈련`보다 `쉬기`, `공룡 보기`를 더 부드럽게 강조할 수 있다.

## 9. 낮은 성과 결과

정확도가 낮아도 결과 화면은 실패 화면이 아니다.

표현 예시:

```text
끝까지 풀었어요!
이번에는 천천히 다시 해보면 더 잘할 수 있어요.
```

처리:

- 참여 보상 지급
- 속도 보너스 없음
- 쉬운 문제 추천
- 공룡의 응원 반응

## 10. 초기 구현 범위

1차 구현:

- 정답/오답 시각 피드백
- 정답/오답 효과음 연결
- 20문제 결과 화면
- 코인/EXP/정확도/시간 표시
- 결과 후 이동 버튼

후속 구현:

- 연속 오답 대응
- 난이도 추천
- 부모용 상세 결과 보기
- 약한 유형 리포트
