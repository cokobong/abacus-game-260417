# 게임 규칙 초안

이 문서는 학습 보상, 부화, 성장, 모험, 상점이 서로 어떻게 연결되는지 정리한다.

## 1. 학습 보상

- 주산 문제를 풀면 코인 또는 보상 진행도를 얻는다.
- 문제 풀이 중에는 획득 예정 보상으로 보여주고, 세트 완료 후 정산할 수 있다.
- 보상은 부화방, 놀이터, 상점에서 사용된다.
- 학습 자체가 중심이고, 성장 요소는 반복 플레이를 돕는 보조 장치로 둔다.
- 문제 난이도는 공룡 레벨과 분리하며, 보수/받아올림/항의 개수 같은 실제 주산 학습 개념 기준은 `problem-difficulty.md`에서 관리한다.

## 2. 20문제 기준 속도/정확도/보상 판정 규칙

20문제 1세트를 기본 단위로 하며, 보상 판정은 정확도를 우선한다.
속도는 정답을 충분히 맞힌 뒤에 붙는 보너스로만 사용하고, 빠르게 풀었지만 오답이 많은 플레이가 높은 보상을 받지 않도록 한다.

### 정확도 판정

| 정답 수 | 정확도 | 판정 | 보상 방향 |
| ---: | ---: | --- | --- |
| 20개 | 100% | S | 최고 정확도 보상 |
| 18~19개 | 90~95% | A | 높은 정확도 보상 |
| 15~17개 | 75~85% | B | 기본 성공 보상 |
| 12~14개 | 60~70% | C | 낮은 성공 보상 |
| 0~11개 | 0~55% | D | 참여 보상 중심 |

- 정확도 판정이 최종 보상의 기본 등급이 된다.
- D 판정이어도 세트를 끝까지 완료했다면 소량의 참여 보상은 지급한다.
- 속도 등급은 정확도 판정을 넘어서지 않고, 같은 정확도 판정 안에서 보너스만 더한다.

### 속도 등급

20문제 전체 풀이 시간을 기준으로 속도 등급을 계산한다.

| 등급 | 20문제 총 시간 | 문제당 평균 시간 | 보너스 방향 |
| --- | ---: | ---: | --- |
| S | 2분 00초 이하 | 6초 이하 | 큰 속도 보너스 |
| A | 2분 01초~3분 00초 | 6.1~9초 | 속도 보너스 |
| B | 3분 01초~4분 30초 | 9.1~13.5초 | 작은 속도 보너스 |
| C | 4분 31초~6분 00초 | 13.6~18초 | 기본 보상 |
| D | 6분 01초 이상 | 18초 초과 | 속도 보너스 없음 |

- 문제당 평균 시간은 `총 풀이 시간 / 20`으로 계산한다.
- 속도 보너스는 정답 처리된 문제 또는 정확도 기본 보상에만 적용한다.
- 오답을 빠르게 입력하는 행동이 유리해지지 않도록, 일정 정확도 이상일 때만 속도 보너스를 적용할 수 있다.

### 보상 적용 예시

```text
최종 보상 = 정확도 기준 기본 보상 + 속도 보너스
```

- 정확도 S/A는 속도 보너스를 받을 수 있다.
- 정확도 B는 작은 속도 보너스까지만 받을 수 있다.
- 정확도 C/D는 속도보다 복습과 완료 보상에 초점을 둔다.
- 1차 버전에서는 복잡한 공식보다 등급별 보상 테이블로 관리한다.

### 20문제 1세트 코인 보상

코인 보상은 20문제 1세트를 끝까지 완료했을 때 결과 화면에서 정산한다.
문제를 푸는 중에는 획득 예정 코인으로 보여주고, 실제 보유 코인은 세트 완료 후 반영한다.

기본 보상 기준:

| 항목 | 기준 | 코인 |
| --- | --- | ---: |
| 정답 기본 보상 | 정답 1개당 | 5코인 |
| 세트 완료 보상 | 20문제 완료 | 10코인 |
| 정확도 S 보너스 | 20개 정답 | 40코인 |
| 정확도 A 보너스 | 18~19개 정답 | 25코인 |
| 정확도 B 보너스 | 15~17개 정답 | 10코인 |
| 정확도 C 보너스 | 12~14개 정답 | 0코인 |
| 정확도 D 보너스 | 0~11개 정답 | 0코인 |

속도 보너스 기준:

| 속도 등급 | 적용 조건 | 코인 |
| --- | --- | ---: |
| S | 정확도 A 이상 | 25코인 |
| A | 정확도 A 이상 | 15코인 |
| B | 정확도 B 이상 | 8코인 |
| C | 제한 없음 | 0코인 |
| D | 제한 없음 | 0코인 |

연속 성공 보너스 기준:

| 조건 | 코인 |
| --- | ---: |
| 5문제 연속 정답 | 5코인 |
| 10문제 연속 정답 | 12코인 |
| 15문제 연속 정답 | 20코인 |
| 20문제 연속 정답 | 35코인 |

- 연속 성공 보너스는 한 세트에서 달성한 가장 높은 단계 하나만 지급한다.
- 예를 들어 12문제 연속 정답이면 10문제 연속 정답 보너스 12코인만 지급한다.
- 연속 성공 보너스는 빠른 입력보다 정확한 반복 성공을 칭찬하는 용도다.
- 속도 보너스와 연속 성공 보너스가 있어도 정확도 보상을 넘어서지 않도록 상한을 둘 수 있다.

정산 예시:

```text
정답 17개, 정확도 B, 속도 B, 10문제 연속 정답
= 정답 기본 85코인 + 완료 10코인 + 정확도 10코인 + 속도 8코인 + 연속 성공 12코인
= 총 125코인
```

```text
정답 20개, 정확도 S, 속도 S, 20문제 연속 정답
= 정답 기본 100코인 + 완료 10코인 + 정확도 40코인 + 속도 25코인 + 연속 성공 35코인
= 총 210코인
```

### 하루 예상 코인 수입

대상 연령은 7~8세이며, 보상 반응이 강한 아이를 기준으로 너무 빠른 성취가 일어나지 않도록 잡는다.
하루에 1~3세트를 플레이하는 상황을 기본 예상치로 둔다.

| 플레이량 | 예상 실력 | 하루 예상 코인 |
| --- | --- | ---: |
| 1세트 | 15~17개 정답 | 100~130코인 |
| 2세트 | 15~18개 정답 | 200~300코인 |
| 3세트 | 16~20개 정답 | 330~520코인 |

- 하루 1세트만 해도 기본 먹이 1~3개는 살 수 있어야 한다.
- 하루 2~3세트를 해도 공룡 알이나 희귀 해금이 바로 끝나지 않아야 한다.
- 최고 성과 보상은 기분 좋게 크게 보이되, 장기 수집품의 가격은 며칠 이상 모으는 구조로 둔다.
- 실제 플레이 데이터가 쌓이면 평균 정답 수, 평균 세트 수, 아이템 구매 속도를 보고 보상량을 조정한다.

### 조정 메모

- 위 기준은 20문제 기본 세트의 초기 기준이다.
- 난이도, 문제 유형, 자리수, 제한 시간 설정에 따라 속도 기준은 달라질 수 있다.
- 아이의 나이, 숙련도, 개인별 학습 기록에 따라 개인화된 기준을 적용할 수 있다.
- 향후에는 최근 평균 풀이 시간과 정확도를 참고해 속도 등급 기준을 자동 조정할 수 있다.

## 3. 부화 규칙

- 알은 부화방에서 관리한다.
- 부화 게이지의 핵심 진행 수단은 20문제 세트 성공이다.
- 부화 보조 아이템, 미션 달성, 모험 보상은 부화 진행을 돕거나 다음 문제풀이 보상을 강화하는 보조 수단으로 둔다.
- 먹이 주기와 쓰다듬기는 부화 전 알 진행이 아니라, 부화 후 놀이터에서 공룡의 배고픔, 행복, 친밀도, 성장 보조에 사용한다.
- 시간 경과만으로 자동 부화가 완료되지 않는다. 앱을 껐다 켜도 부화 진행도는 저장되지만, progress 증가는 문제풀이 성공 또는 명시된 보조 효과를 통해서만 일어난다.
- 부화가 완료되면 캐릭터가 생성되고 도감에 등록된다.
- 알 종류에 따라 부화 조건이나 결과 캐릭터가 달라질 수 있다.

## 4. 놀이터 규칙

- 부화한 캐릭터와 상호작용하는 공간이다.
- 먹이, 장난감, 쓰다듬기 같은 행동으로 기분이나 친밀도가 오를 수 있다.
- 캐릭터별로 좋아하는 아이템과 반응 차이를 줄 수 있다.
- 1차 버전에서는 복잡한 능력치보다 간단한 반응과 성장감에 집중한다.

## 5. 도감 규칙

- 발견한 알, 캐릭터, 진화형, 아이템을 기록한다.
- 미발견 항목은 실루엣이나 힌트로 표시한다.
- 희귀도, 발견 조건, 진화 조건은 도감에서 확인 가능하게 한다.
- 도감은 목표 제시용이며, 모든 정보를 처음부터 공개하지 않는다.

## 6. 모험 규칙

- 캐릭터를 특정 지역으로 보내 일정 시간 뒤 보상을 얻는다.
- 지역에 따라 보상 종류가 다르다.
- 캐릭터 특성에 따라 성공률이나 보상 차이가 생길 수 있다.
- 보상 예시는 코인, 먹이, 장난감, 희귀 알 조각이다.

## 7. 상점 규칙

- 초기에는 아이템을 3~5개 정도만 제공한다.
- 아이템은 먹이, 장난감, 꾸미기 아이템처럼 카테고리로 나눈다.
- 상점은 아이템 방향성과 밸런스 원칙을 문서화하고, 실제 아이템 데이터는 나중에 TypeScript 파일에서 관리한다.
- 구매 아이템이 학습 난이도 자체를 대신 해결해주는 구조는 피한다.

## 8. 밸런스 원칙

- 보상은 아이가 성취감을 느낄 만큼 자주 보여준다.
- 희귀 보상은 너무 빨리 소진되지 않도록 장기 목표로 둔다.
- 아이템 효과는 단순하고 이해하기 쉬워야 한다.
- 처음부터 수치와 확률을 많이 만들지 않는다.
- 계산 훈련의 목적을 흐리지 않는 선에서 성장과 수집 요소를 붙인다.
