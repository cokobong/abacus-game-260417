# 게임 설정 규칙

## 1. 설정 화면의 목적

기존 게임은 처음 시작할 때 옵션이 다소 복잡하게 느껴졌다.

새 버전에서는 문제 설정을 별도의 **옵션 탭** 또는 **설정 화면**으로 분리한다.

사용자는 한 번 설정한 값을 계속 유지할 수 있어야 한다.
즉, 매번 게임을 시작할 때마다 설정을 다시 고르지 않아도 된다.

설정값은 1차 버전에서는 브라우저의 `localStorage`에 저장한다.

---

## 2. 기본 설정 원칙

설정은 아이가 직접 하기보다, 부모가 한 번 맞춰두는 구조를 가정한다.

따라서 설정 화면은 너무 화려한 게임 화면처럼 만들기보다, 명확하고 단순해야 한다.

핵심 원칙:

* 옵션 수를 최소화한다.
* 어려운 용어를 쓰지 않는다.
* 기본값을 제공한다.
* 한 번 설정하면 다음 플레이에도 유지된다.
* 설정 변경 후 바로 저장된다.
* 설정값은 문제 생성 로직에 반영된다.

---

## 3. 설정 항목 요약

새 게임에서 사용할 설정 항목은 다음 4가지다.

1. 한 문제에 나오는 숫자 개수
2. 숫자의 자릿수
3. 한 세트의 총 문제 수
4. 뺄셈 포함 여부

---

## 4. 한 문제에 나오는 숫자 개수

### 설명

한 문제 안에 총 몇 개의 숫자가 나올지를 결정한다.

예를 들어 숫자 개수를 3개로 설정하면 다음과 같은 문제가 나온다.

```text
4 + 6 + 2
```

숫자 개수를 4개로 설정하면 다음과 같은 문제가 나온다.

```text
3 + 5 + 1 + 7
```

### 설정 가능 값

```text
3개 / 4개 / 5개 / 6개
```

### 기본값

```text
3개
```

### UI 표현

옵션 화면에서는 다음처럼 표시한다.

```text
한 문제에 나오는 숫자 개수
[3개] [4개] [5개] [6개]
```

### 구현 규칙

* 최소값은 3개다.
* 최대값은 6개다.
* 이 값은 문제 생성 시 숫자 배열의 길이로 사용한다.
* 아이가 너무 긴 문제로 부담을 느끼지 않도록 기본값은 3개로 둔다.

---

## 5. 숫자의 자릿수 설정

### 설명

문제에 나오는 숫자의 자릿수를 결정한다.

처음 버전에서는 복잡한 설정을 없애고, 아래 두 가지 모드만 제공한다.

### 설정 가능 값

```text
한 자리 수
두 자리 수
```

### 기본값

```text
한 자리 수
```

### UI 표현

```text
숫자 크기
[한 자리 수] [두 자리 수]
```

### 구현 규칙

#### 한 자리 수

* 1부터 9까지의 숫자를 사용한다.
* 예시:

```text
4 + 6 + 2
```

#### 두 자리 수

* 10부터 99까지의 숫자를 사용한다.
* 예시:

```text
14 + 26 + 12
```

### 주의사항

* 1차 버전에서는 세 자리 수 이상은 제공하지 않는다.
* 한 자리 수와 두 자리 수를 섞는 옵션은 제공하지 않는다.
* 설정을 단순하게 유지한다.

---

## 6. 한 세트의 총 문제 수

### 설명

한 번의 게임 세트에서 총 몇 문제를 풀지 결정한다.

기본은 20문제다.
다만 아이의 집중 시간이나 상황에 따라 짧게 플레이할 수 있도록 10문제, 15문제 옵션도 제공한다.

### 설정 가능 값

```text
10문제 / 15문제 / 20문제
```

### 기본값

```text
20문제
```

### UI 표현

```text
한 세트 문제 수
[10문제] [15문제] [20문제]
```

### 구현 규칙

* 게임은 설정된 문제 수만큼 진행된다.
* 세트가 끝나야 코인이 최종 지급된다.
* 기본 보상 구조는 20문제를 기준으로 하되, 10문제/15문제 선택 시에도 비례해서 보상을 지급한다.
* 결과 화면에서는 실제 풀이 문제 수를 표시한다.

예시:

```text
10문제 세트 완료!
정답 8개 / 10개
획득 코인 42개
```

```text
20문제 세트 완료!
정답 17개 / 20개
획득 코인 102개
```

---

## 7. 뺄셈 포함 여부

### 설명

문제에 뺄셈을 포함할지 결정한다.

초기 학습 단계에서는 덧셈만 연습할 수 있어야 한다.
조금 익숙해지면 덧셈과 뺄셈을 섞을 수 있다.

### 설정 가능 값

```text
덧셈만
덧셈 + 뺄셈
```

### 기본값

```text
덧셈만
```

### UI 표현

```text
연산 방식
[덧셈만] [덧셈 + 뺄셈]
```

### 구현 규칙

#### 덧셈만

* 모든 연산자는 `+`만 사용한다.
* 예시:

```text
4 + 6 + 2
```

#### 덧셈 + 뺄셈

* `+`와 `-`를 함께 사용할 수 있다.
* 예시:

```text
8 + 5 - 3
```

### 중요한 제한

뺄셈이 포함되더라도 결과값이 음수가 나오면 안 된다.

예를 들어 아래 문제는 허용하지 않는다.

```text
3 - 8 + 2 = -3
```

결과가 음수가 되지 않도록 문제 생성 시 검증해야 한다.

---

## 8. 음수 방지 규칙

뺄셈 포함 모드에서는 최종 정답이 반드시 0 이상이어야 한다.

### 기본 규칙

* 문제를 생성한 뒤 최종 결과값을 계산한다.
* 결과값이 0보다 작으면 해당 문제는 버린다.
* 다시 새로운 문제를 생성한다.
* 결과값이 0 이상인 문제만 출제한다.

### 허용 예시

```text
9 - 3 + 2 = 8
```

```text
15 + 4 - 7 = 12
```

```text
20 - 10 - 5 = 5
```

### 금지 예시

```text
4 - 9 + 1 = -4
```

```text
10 - 15 + 2 = -3
```

### 추가 고려사항

1차 버전에서는 중간 계산값이 음수가 되는 것까지 엄격하게 막을지는 추후 결정한다.

우선은 최종 정답이 음수가 되지 않는 것을 기본 규칙으로 한다.

---

## 9. 기본 설정값

처음 실행 시 기본 설정은 다음과 같다.

```text
한 문제에 나오는 숫자 개수: 3개
숫자 자릿수: 한 자리 수
한 세트 문제 수: 20문제
연산 방식: 덧셈만
```

이 기본값은 어린아이가 가장 부담 없이 시작할 수 있는 구성이다.

---

## 10. 설정값 저장 방식

설정값은 1차 버전에서 `localStorage`에 저장한다.

저장할 설정 데이터 예시:

```text
numberCount: 3
digitMode: "single"
questionCount: 20
operationMode: "addition"
```

또는 덧셈 + 뺄셈 모드일 경우:

```text
numberCount: 4
digitMode: "double"
questionCount: 15
operationMode: "addition-subtraction"
```

### 저장 원칙

* 사용자가 설정을 바꾸면 즉시 저장한다.
* 앱을 새로고침해도 설정값이 유지된다.
* 다음에 게임을 시작할 때 마지막 설정값을 사용한다.
* 저장값이 없으면 기본 설정값을 사용한다.

---

## 11. 설정 화면의 위치

설정은 게임 시작 화면에서 바로 복잡하게 노출하지 않는다.

시작 화면에는 단순히 다음 버튼만 둔다.

```text
[훈련 시작]
[공룡 보기]
[상점]
[설정]
```

사용자가 `[설정]` 버튼을 누르면 별도의 설정 화면 또는 옵션 탭으로 이동한다.

설정 화면에는 다음 항목이 표시된다.

```text
1. 한 문제에 나오는 숫자 개수
2. 숫자 크기
3. 한 세트 문제 수
4. 연산 방식
```

---

## 12. 문제 생성 로직 요약

설정값을 기준으로 문제를 생성한다.

### 입력값

```text
numberCount
digitMode
questionCount
operationMode
```

### 생성 과정

1. 설정값을 불러온다.
2. 한 세트에 필요한 문제 수만큼 문제를 만든다.
3. 각 문제마다 설정된 숫자 개수만큼 숫자를 생성한다.
4. 자릿수 설정에 따라 한 자리 수 또는 두 자리 수를 생성한다.
5. 연산 방식에 따라 덧셈만 또는 덧셈/뺄셈 혼합 문제를 만든다.
6. 뺄셈이 포함된 경우 정답이 음수인지 확인한다.
7. 음수 결과가 나오면 문제를 다시 생성한다.
8. 유효한 문제만 화면에 출제한다.

---

## 13. 1차 구현 범위

1차 구현에서는 아래까지만 구현한다.

* 설정 화면 만들기
* 숫자 개수 설정: 3~6개
* 자릿수 설정: 한 자리 수 / 두 자리 수
* 문제 수 설정: 10 / 15 / 20문제
* 연산 방식 설정: 덧셈만 / 덧셈 + 뺄셈
* 설정값 localStorage 저장
* 설정값을 문제 생성 로직에 반영
* 뺄셈 포함 시 최종 결과가 음수가 되지 않도록 처리

1차에서는 너무 많은 세부 옵션을 넣지 않는다.

---

## 14. 향후 확장 가능성

나중에 추가할 수 있는 설정:

* 시간 제한 여부
* 난이도 자동 조절
* 받아올림 포함 여부
* 받아내림 포함 여부
* 세 자리 수
* 특정 숫자 제외
* 하루 목표 세트 수
* 부모용 잠금 설정

하지만 1차 버전에서는 위 기능을 넣지 않는다.
