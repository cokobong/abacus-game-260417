# MVP 단계별 구현 로드맵

이 문서는 키즈 주판 학습 게임을 실제 구현할 때의 단계별 MVP 범위를 정리한다.
처음부터 모든 공룡/상점/부화/모험/PWA 기능을 완성하지 않고, 학습 루프와 저장 안정성을 먼저 만든다.

## 1. MVP 원칙

- 주판 문제풀이가 항상 중심이다.
- 1단계부터 앱을 실행하고 한 세트를 끝낼 수 있어야 한다.
- 보상/성장/수집은 문제풀이를 반복하고 싶게 만드는 보조 구조다.
- 터치 노트북에서 아이가 직접 누르기 쉬워야 한다.
- `localStorage` 기반 GameState 저장과 복원은 초반부터 넣는다.
- 블루투스 주판은 핵심 입력이지만, 터치 키패드 fallback을 항상 유지한다.

## 2. 단계 요약

| 단계 | 목표 | 핵심 산출물 |
| ---: | --- | --- |
| 1단계 | 기본 학습 루프 | 20문제 풀이, 정답 제출, 결과 화면 |
| 2단계 | GameState 저장 | 코인/EXP/설정/진행 상태 저장과 복원 |
| 3단계 | 입력 컨트롤러 | 블루투스/키패드 입력을 공통 submit 흐름으로 통합 |
| 4단계 | 보상과 상점 | 코인/EXP, 음식/코스튬/알 조각 구매 |
| 5단계 | 부화와 도감 | 알 등록, 문제풀이 기반 부화, 도감 해금 |
| 6단계 | 부모 설정과 안전장치 | 난이도 체크박스, 하루 루틴, 백업/초기화 |
| 7단계 | 모험과 확장 | 시간형 모험, 퀘스트/업적, PWA 검토 |

## 3. 1단계: 기본 학습 루프

목표:

- 아이가 앱을 열고 20문제를 풀 수 있다.
- 정답/오답 피드백을 받는다.
- 세트 완료 후 결과 화면을 본다.

포함:

- 20문제 세트 생성
- 정답 입력칸
- 터치 숫자 키패드
- `입력` 버튼
- 정답/오답 처리
- 문제 번호 표시
- 결과 화면

제외:

- 블루투스 주판 실제 연결
- 상점 구매
- 부화장
- 복잡한 난이도 자동 조절

참조 문서:

- `feedback-and-result.md`
- `screen-flow.md`
- `problem-difficulty.md`

## 4. 2단계: GameState 저장

목표:

- 앱을 껐다 켜도 기본 진행 상태가 유지된다.
- 저장 구조가 화면 컴포넌트에 흩어지지 않는다.

포함:

- `GameState` 중앙 구조
- `localStorage` 저장/복원
- 저장 데이터 version
- 기본 migration 함수
- 코인, EXP, 설정, 대표 공룡, 인벤토리 기본값

제외:

- IndexedDB
- 클라우드 동기화
- 복잡한 백업 UI

참조 문서:

- `data-model.md`
- `app-runtime-plan.md`
- `save-backup-recovery.md`

## 5. 3단계: 입력 컨트롤러

목표:

- 블루투스 주판과 터치 키패드가 같은 정답 제출 로직을 사용한다.
- 늦게 도착한 블루투스 입력이나 중복 제출을 막는다.

포함:

- `InputController` 개념 구현
- `setAnswer(value)`
- `appendDigit(digit)`
- `clearAnswer()`
- `submitAnswer(source)`
- `isSubmitting`
- `currentQuestionIndex` 기반 이벤트 검증
- 블루투스 연결 실패 시 키패드 유지

참조 문서:

- `bluetooth-abacus.md`
- `app-runtime-plan.md`
- `state-empty-error-loading.md`

## 6. 4단계: 보상과 상점

목표:

- 문제풀이 결과가 코인/EXP로 이어진다.
- 코인을 사용해 기본 아이템을 살 수 있다.

포함:

- 20문제 기준 코인 보상
- 정확도/속도/연속 성공 보너스
- EXP 획득
- 음식 탭
- 코스튬 탭
- 알 조각 또는 기본 알 구매
- 코인 부족 상태

제외:

- 모든 아이템 완성
- 복잡한 할인/이벤트
- 공룡 직접 구매

참조 문서:

- `game-rule.md`
- `shop-items.md`
- `feedback-and-result.md`

## 7. 5단계: 부화와 도감

목표:

- 상점/보상으로 얻은 알을 부화장에 등록한다.
- 문제풀이 세트 성공으로 부화가 진행된다.
- 부화 완료 시 공룡이 도감에 등록된다.

포함:

- 기본 알 1종
- 일반 알 후보 일부
- 부화 progress 저장
- hintStage
- 부화 완료 연출
- 도감 카드 해금
- 중복 시 기본 처리

제외:

- 전설 알
- 이벤트 알
- 복잡한 확률 보정
- 모든 공룡 아트 완성

참조 문서:

- `pokedex-adventure.md`
- `visual-direction.md`
- `audio-direction.md`

## 8. 6단계: 부모 설정과 안전장치

목표:

- 부모가 학습 범위와 하루 루틴을 조정할 수 있다.
- 로컬 저장 데이터를 백업하거나 초기화할 수 있다.

포함:

- 문제 유형 체크박스
- 하루 권장 세트 수
- 쉬기 안내
- 소리 설정
- 블루투스 연결 테스트
- 데이터 백업 내보내기
- 데이터 복원
- 전체 초기화/설정 초기화

참조 문서:

- `parent-controls.md`
- `daily-routine.md`
- `problem-difficulty.md`
- `save-backup-recovery.md`

## 9. 7단계: 모험과 확장

목표:

- 성장한 공룡을 활용하는 장기 루프를 붙인다.
- PWA 전환 가능성을 검토한다.

포함:

- 시간형 모험
- 모험 보상 수령
- 오늘의 퀘스트
- 장기 업적
- PWA manifest 검토
- 오프라인 시작 화면 검토

후속 문서 후보:

- `quests-achievements.md`
- `pwa-plan.md`
- `accessibility-touch.md`

## 10. MVP 완료 기준

MVP 완료 기준:

- 터치 노트북에서 20문제 1세트를 문제없이 완료할 수 있다.
- 결과 화면에서 코인/EXP/정확도/시간을 확인할 수 있다.
- 앱 재실행 후 코인, 공룡, 설정, 부화 상태가 복원된다.
- 블루투스 주판을 연결하지 못해도 터치 키패드로 학습 가능하다.
- 부모가 현재 학습 개념을 제한할 수 있다.
- 저장 데이터 초기화와 백업 정책이 문서와 UI에 반영되어 있다.

MVP 이후에 확장할 것:

- 더 많은 공룡과 알
- 모험 지역
- 퀘스트/업적
- PWA 설치
- 클라우드 동기화
