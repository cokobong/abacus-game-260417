# 새 주산게임 기획

## 1. 만들고 싶은 방향

기존 주산게임을 아이들이 더 재미있게 반복 연습할 수 있는 게임으로 바꾼다.

단순히 문제를 맞히는 앱이 아니라, 짧은 시간 안에 몰입해서 주산 감각을 훈련하는 교육용 게임으로 만든다.

## 2. 대상 사용자

- 6~8세 아이
- 주산을 막 배우기 시작한 아이
- 숫자 감각과 암산 감각을 키우는 단계의 아이
- 부모가 옆에서 짧게 시켜볼 수 있는 아이

## 3. 게임 플레이 기본 방향

- 한 판은 3~5분 안에 끝난다.
- 문제는 너무 빠르게 쏟아지지 않는다.
- 정답을 맞히면 시각적으로 기분 좋은 피드백이 나온다.
- 오답이 나와도 스트레스가 크지 않게 한다.
- 경쟁보다는 정확도와 몰입감을 중시한다.
- 아이가 “한 번 더” 하고 싶게 만드는 구조를 목표로 한다.

## 4. 게임 방식 아이디어

- 문제를 맞히면 캐릭터가 앞으로 이동한다.
- 연속 정답을 맞히면 콤보가 생긴다.
- 일정 개수 이상 맞히면 스테이지 클리어가 된다.
- 난이도는 단계별로 올라간다.
- 처음에는 한 자리 수 덧셈/뺄셈부터 시작한다.
- 이후 두 자리 수, 받아올림, 받아내림 등으로 확장한다.

## 5. 화면 구성 방향

### 시작 화면

- 아이가 바로 이해할 수 있어야 한다.
- “시작하기” 버튼이 명확해야 한다.
- 레벨 선택은 너무 복잡하지 않게 한다.

### 게임 화면

- 현재 문제가 중앙에 크게 보여야 한다.
- 주산판 또는 숫자 입력 영역이 잘 보여야 한다.
- 점수, 남은 문제 수, 콤보 상태가 직관적으로 보여야 한다.

### 결과 화면

- 맞힌 개수
- 정확도
- 걸린 시간
- 격려 메시지
- 다시 하기 버튼

## 6. 그래픽 방향

- 과하게 유아틱하지 않게 한다.
- 밝고 깔끔한 색감을 사용한다.
- 숫자와 버튼이 가장 잘 보여야 한다.
- 모바일에서도 잘 보여야 한다.
- 캐릭터가 있다면 보조 역할로만 사용한다.
- 주산판이 너무 복잡해 보이지 않게 한다.

## 7. 유지하고 싶은 것

- 브라우저에서 바로 실행되는 구조
- Netlify 배포 구조
- 기존 주산/계산 문제의 기본 구조
- 너무 무거운 그래픽을 쓰지 않는 방향
- 가상의 주판이 아닌 실제 주판 연결이 되어야 함. 기존 코드 참고.

## 8. 바꾸고 싶은 것

- 전체 화면 디자인
- 시작 화면
- 게임 진행 방식
- 정답/오답 피드백
- 결과 화면
- 난이도 구조
- 아이가 느끼는 게임성



## 10. 1차 리뉴얼 목표

1차 리뉴얼에서는 게임 로직을 크게 바꾸기보다, 먼저 전체 구조와 화면을 정리한다.

우선순위는 다음과 같다.

1. 기존 코드 구조 이해
2. 시작 화면 개선
3. 게임 화면 레이아웃 개선
4. 결과 화면 개선
5. 그 다음 문제 생성 방식과 난이도 조정

## 11. 참고하고 싶은 게임 느낌

- 포켓몬처럼 수집형은 아니지만, 작은 성장감은 있었으면 좋겠다.
- 너무 화려한 애니메이션보다 명확하고 빠른 피드백.

구체적으로는 아래의 게임 방식을 따른다.
## 공룡 키우기 + 코인 보상 구조

### 1. 기본 게임 구조

게임은 20문제를 1세트로 구성한다.

* 한 세트는 총 20문제다.
* 아이는 20문제를 순서대로 푼다.
* 20문제를 모두 풀면 세트가 종료된다.
* 세트가 끝나면 결과 화면에서 획득 코인과 보상을 정산한다.
* 이후 다시 20문제 세트를 반복해서 플레이할 수 있다.

핵심은 “짧은 반복 훈련”이다.
한 번의 플레이가 너무 길면 아이가 지치므로, 20문제를 하나의 완결된 단위로 둔다.

---

### 2. 문제 풀이와 코인 획득

각 문제를 맞히면 코인을 얻는 그래픽 피드백을 보여준다.

예시:

* 정답을 맞히면 코인 아이콘이 튀어나온다.
* 공룡이 기뻐하거나 점프한다.
* “+3 코인”, “+5 코인”처럼 획득 예정 코인이 표시된다.
* 코인이 화면 상단의 코인 지갑으로 빨려 들어가는 연출을 넣을 수 있다.

다만 실제 코인은 문제를 맞히는 즉시 최종 지급하지 않고, **20문제를 모두 푼 뒤 결과 화면에서 최종 정산**한다.

즉, 문제를 푸는 중에는 “획득 예정 코인”으로 보여주고, 세트 완료 후 실제 보유 코인에 반영한다.

---

### 3. 속도 보너스 구조

문제를 빠르게 풀수록 코인 보너스를 받을 수 있다.

기본 방향:

* 정답을 맞히면 기본 코인을 얻는다.
* 빠르게 풀면 보너스 배율이 붙는다.
* 너무 느리게 풀어도 기본 코인은 받을 수 있다.
* 속도 보너스는 아이에게 압박이 되지 않도록 부드럽게 표현한다.

예시 배율:

| 풀이 속도 | 보너스 배율 | 표시        |
| ----- | -----: | --------- |
| 매우 빠름 |   x1.5 | 번개 보너스    |
| 빠름    |   x1.3 | 빠른 계산 보너스 |
| 보통    |   x1.2 | 집중 보너스    |
| 느림    |   x1.0 | 기본 보상     |

예시:

* 기본 코인: 5코인
* 빠르게 풀어서 x1.2 보너스 적용
* 획득 예정 코인: 6코인

계산식 예시:

```text
획득 코인 = 기본 코인 × 속도 보너스 배율
```

1차 버전에서는 너무 복잡한 공식보다 단순한 배율 구조를 사용한다.

---

### 4. 20문제 세트 완료 후 보상 정산

코인은 20문제를 모두 풀어야 최종 획득한다.

이 구조의 이유:

* 아이가 중간에 나가지 않고 한 세트를 끝까지 풀게 만든다.
* 20문제 단위의 집중 훈련을 유도한다.
* 결과 화면에서 성취감을 줄 수 있다.
* 부모가 “오늘 한 세트 했다”라고 확인하기 쉽다.

결과 화면에서 보여줄 정보:

* 총 문제 수: 20문제
* 맞힌 문제 수
* 정확도
* 걸린 시간
* 기본 획득 코인
* 속도 보너스
* 최종 획득 코인
* 누적 보유 코인
* 공룡 성장 변화

예시 문구:

```text
20문제 세트 완료!
정답 17개 / 20개
정확도 85%
빠른 계산 보너스 x1.2
획득 코인 102개
```

---

### 5. 코인의 사용처

아이가 획득한 코인은 공룡을 키우거나 꾸미는 데 사용한다.

코인의 주요 사용처:

1. 공룡 먹이 구매
2. 공룡 업그레이드
3. 공룡 옷 구매
4. 공룡 코스튬 구매
5. 농장 장식 아이템 구매
6. 새로운 공룡 구매

---

### 6. 먹이 구매와 공룡 성장

코인으로 먹이를 구매할 수 있다.

먹이를 공룡에게 주면 공룡의 경험치가 오른다.

기본 구조:

* 코인으로 먹이를 산다.
* 먹이를 주면 공룡 경험치가 오른다.
* 경험치가 일정 수준에 도달하면 공룡이 레벨업한다.
* 레벨업하면 공룡의 모습이나 반응이 조금 바뀔 수 있다.

예시:

| 아이템    |   가격 | 효과      |
| ------ | ---: | ------- |
| 작은 나뭇잎 | 10코인 | 경험치 +5  |
| 맛있는 열매 | 30코인 | 경험치 +20 |
| 특별한 고기 | 50코인 | 경험치 +40 |

1차 버전에서는 먹이 종류를 많이 만들지 않는다.
처음에는 1~3개 정도로 충분하다.

---

### 7. 공룡 업그레이드

코인으로 공룡을 업그레이드할 수 있다.

업그레이드는 게임 성능을 크게 바꾸기보다, 아이가 성장감을 느끼는 장치로 둔다.

가능한 업그레이드:

* 공룡 레벨업
* 공룡 크기 변화
* 공룡 표정 변화
* 공룡 움직임 추가
* 공룡 이름표 변경
* 특별한 효과 추가

주의할 점:

* 업그레이드가 계산 난이도를 대신해주면 안 된다.
* 공룡 능력치가 너무 강해지는 게임으로 만들지 않는다.
* 학습 보상은 유지하되, 계산 훈련의 중심성을 잃지 않는다.

---

### 8. 옷과 코스튬

코인으로 공룡 옷이나 코스튬을 살 수 있다.

예시 코스튬:

* 탐험가 모자
* 작은 왕관
* 빨간 목도리
* 우주 헬멧
* 농장 작업복
* 숫자 마법사 망토

코스튬은 공룡의 능력을 크게 바꾸기보다, 외형 꾸미기 중심으로 둔다.

목표는 아이가 “내 공룡”이라는 애착을 느끼게 하는 것이다.

---

### 9. 새로운 공룡 구매

일정 금액 이상의 코인을 모으면 새로운 공룡을 구매할 수 있다.

기본 구조:

* 처음에는 기본 공룡 1마리로 시작한다.
* 코인을 모으면 상점에서 새 공룡을 구매할 수 있다.
* 구매한 공룡은 도감에 등록된다.
* 아이는 보유한 공룡 중 하나를 선택해 대표 공룡으로 사용할 수 있다.

초기 공룡 후보:

| 공룡       |     가격 | 특징           |
| -------- | -----: | ------------ |
| 아기 티라노   |  기본 지급 | 용감한 기본 공룡    |
| 트리케라톱스   |  300코인 | 든든하고 차분한 공룡  |
| 스테고사우루스  |  500코인 | 귀엽고 안정적인 공룡  |
| 브라키오사우루스 |  700코인 | 느긋하고 큰 공룡    |
| 프테라노돈    | 1000코인 | 하늘을 나는 특별 공룡 |

1차 버전에서는 새 공룡 구매 기능을 완성하지 않아도 된다.
우선 상점 화면의 틀과 공룡 목록만 만들어도 충분하다.

---

### 10. 저장 방식

보유 코인, 공룡 상태, 구매한 아이템은 저장되어야 한다.

1차 버전에서는 브라우저의 localStorage를 사용한다.

저장할 데이터 예시:

```text
보유 코인
현재 선택한 공룡
공룡 레벨
공룡 경험치
보유 먹이
구매한 코스튬
구매한 공룡 목록
누적 풀이 문제 수
누적 정답 수
```

처음에는 로그인이나 서버 저장을 사용하지 않는다.

이유:

* 구현이 쉽다.
* Netlify 배포 환경에서도 바로 작동한다.
* 초기 프로토타입에 적합하다.
* 아이가 한 기기에서 사용하는 용도라면 충분하다.

단점:

* 브라우저를 바꾸면 데이터가 이어지지 않는다.
* 캐시를 삭제하면 저장 데이터가 사라질 수 있다.
* 여러 기기 동기화는 되지 않는다.

장기적으로는 필요할 경우 Supabase나 Firebase 같은 클라우드 저장 방식으로 확장할 수 있다.

---

### 11. 1차 구현 범위

처음부터 완성형 농장 게임을 만들지 않는다.

1차 구현 범위는 다음 정도로 제한한다.

* 20문제 1세트 구조
* 문제별 정답 피드백
* 정답 시 코인 획득 예정 그래픽
* 풀이 속도에 따른 코인 보너스
* 20문제 완료 후 코인 최종 정산
* 보유 코인 저장
* 기본 공룡 1마리 표시
* 먹이 구매 또는 먹이 주기 중 하나만 간단히 구현
* 공룡 경험치와 레벨 표시
* localStorage 저장

1차 목표는 “주산 문제를 풀면 코인을 얻고, 그 코인으로 공룡을 키운다”는 핵심 재미를 구현하는 것이다.

---

### 12. 이후 확장 방향

2차 이후에 추가할 수 있는 기능:

* 상점 화면 고도화
* 공룡 여러 마리 구매
* 공룡 도감
* 코스튬 구매
* 농장 배경 꾸미기
* 일일 보상
* 난이도별 보상 차등
* 부모용 학습 기록 화면
* 여러 기기 저장을 위한 클라우드 DB 연동

최종 목표는 단순 주산 문제풀이 앱이 아니라, 아이가 반복해서 접속하고 싶어지는 “공룡 성장형 주산 훈련 게임”이다.
