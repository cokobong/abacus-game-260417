# 첫 실행 온보딩 흐름

이 문서는 아이가 앱을 처음 실행했을 때부터 첫 20문제 세트, 첫 보상, 첫 알 등록까지 이어지는 초기 경험을 정리한다.
초기 사용 환경은 터치 노트북에서 실행하는 로컬 웹앱이며, 블루투스 주판 연결을 기본 입력으로 둔다.

## 1. 온보딩 목표

- 아이가 무엇을 해야 하는지 1분 안에 이해하게 한다.
- 부모가 초기 설정과 블루투스 주판 연결을 도와줄 수 있게 한다.
- 첫 문제풀이를 너무 복잡하게 만들지 않는다.
- 첫 보상과 첫 알 등록까지 경험하게 하여 다음 플레이 이유를 만든다.
- 블루투스 연결이 실패해도 터치 키패드로 바로 시작할 수 있게 한다.

## 2. 첫 실행 전체 흐름

```text
앱 첫 실행
→ 기본 안내
→ 부모/보호자 설정 확인
→ 블루투스 주판 연결 시도
→ 연결 성공 또는 키패드 대체 안내
→ 첫 20문제 세트 시작
→ 결과 화면
→ 첫 보상 지급
→ 첫 기본 알 등록
→ 홈/부화장 안내
```

첫 실행에서는 모든 탭과 기능을 한꺼번에 설명하지 않는다.
아이에게는 `훈련하기`, `보상 받기`, `알 확인하기`만 명확히 보여준다.

## 3. 첫 화면

첫 화면에서 보여줄 정보:

- 게임 이름
- 대표 공룡 또는 기본 알
- `훈련 시작` 버튼
- `설정` 버튼
- 블루투스 주판 연결 상태

첫 실행 문구 예시:

```text
주판으로 문제를 풀고 공룡 알을 깨워요!
```

부모용 작은 안내:

```text
처음에는 설정에서 주판 연결과 문제 난이도를 확인해 주세요.
```

## 4. 초기 설정 흐름

첫 실행 시 부모가 확인할 항목:

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 문제 수 | 20문제 | 기본 학습 세트 |
| 숫자 개수 | 3개 | 첫 난이도 |
| 자릿수 | 한 자리 수 | 초기 학습 |
| 연산 | 덧셈만 | 부담 낮게 시작 |
| 소리 | 켜짐 | 이후 설정에서 조정 |
| 문제풀이 중 BGM | 꺼짐 또는 낮음 | 집중 우선 |

- 설정을 건너뛰어도 기본값으로 시작할 수 있다.
- 설정은 `localStorage` 기반 GameState 또는 userSettings에 저장한다.
- 아이가 직접 바꾸기 어려운 설정은 부모/관리자 설정 문서 기준을 따른다.

## 5. 블루투스 주판 연결 안내

연결 흐름:

```text
설정 탭
→ "주판 연결" 버튼
→ 브라우저 기기 선택 창
→ 주판 선택
→ 연결 상태 표시
→ 테스트 입력 확인
```

연결 성공 시:

```text
주판이 연결됐어요.
주판에서 값을 만들고 확인 버튼을 눌러 보세요.
```

연결 실패 시:

```text
주판을 찾지 못했어요.
지금은 화면 키패드로 시작할 수 있어요.
```

- 블루투스 연결은 필수 조건이 아니다.
- 연결 실패가 첫 학습 시작을 막으면 안 된다.
- Web Bluetooth 제약과 상세 연결 처리는 `bluetooth-abacus.md`를 따른다.

## 6. 첫 문제풀이 세트

첫 세트는 성공 경험을 우선한다.

권장 기본값:

- 20문제
- 한 자리 수
- 숫자 3개
- 덧셈만
- 시간 압박 없음
- 속도는 결과 화면에서 작은 보너스로만 표시

첫 세트 중 표시:

- 현재 문제 번호
- 정답 입력칸
- 블루투스 연결 상태
- 터치 키패드
- 획득 예정 코인

첫 세트 중 숨기거나 줄일 것:

- 복잡한 상점 안내
- 도감 전체 설명
- 희귀 알/전설 알 광고
- 과한 애니메이션

## 7. 첫 결과 화면

첫 결과 화면은 학습 결과와 보상을 함께 보여준다.

표시 항목:

- 정답 수
- 정확도
- 걸린 시간
- 획득 코인
- 획득 EXP
- 공룡 성장 변화
- 부화 진행 변화

첫 완료 문구 예시:

```text
첫 훈련 완료!
공룡 알이 조금 따뜻해졌어요.
```

오답이 많아도 실패 화면으로 만들지 않는다.
세트를 끝까지 완료한 것 자체를 칭찬한다.

## 8. 첫 알 등록

첫 세트 이후에는 기본 알 또는 튜토리얼 알을 부화장에 등록하게 한다.

흐름:

```text
결과 화면
→ "알 보러 가기"
→ 부화장
→ 기본 알 등록
→ 부화 게이지 0% 또는 첫 진행도 표시
→ 다음 훈련으로 이어지는 버튼 표시
```

첫 알은 공룡 이름을 공개하지 않는다.
표시는 `기본 알`, `미확인 알` 정도로 둔다.

## 9. 온보딩 종료 조건

온보딩은 다음 조건을 만족하면 완료로 본다.

- 첫 설정 확인 완료
- 블루투스 연결 시도 또는 키패드 대체 선택
- 첫 문제풀이 세트 완료
- 첫 결과 화면 확인
- 첫 알 등록 또는 부화장 확인

저장값 예시:

```ts
onboarding: {
  completed: true,
  firstSetCompleted: true,
  bluetoothTried: true,
  firstEggRegistered: true
}
```

## 10. 초기 구현 범위

1차 구현:

- 첫 실행 여부 저장
- 기본 설정 확인 화면
- 블루투스 연결 안내 또는 건너뛰기
- 첫 문제풀이 세트
- 첫 결과 화면
- 첫 기본 알 등록 안내

후속 구현:

- 보호자용 상세 튜토리얼
- 음성 안내
- 첫 공룡 성격 선택
- 아이 이름 또는 별명 설정
- 온보딩 다시 보기
