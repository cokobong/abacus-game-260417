# 부모/관리자 설정

이 문서는 부모 또는 보호자가 아이의 학습 환경, 난이도, 소리, 저장 데이터, 블루투스 주판 연결을 관리하는 설정 영역을 정리한다.
아이용 화면과 달리 부모 설정은 명확하고 실용적인 UI를 우선한다.

## 1. 목적

- 아이가 학습에 집중할 수 있도록 기본 환경을 맞춘다.
- 문제 난이도와 하루 학습량을 부모가 조절할 수 있게 한다.
- 블루투스 주판, 저장 데이터, 오디오 설정을 관리한다.
- 실수로 데이터가 초기화되거나 어려운 설정이 바뀌지 않도록 보호한다.

## 2. 설정 진입

설정 화면은 홈 또는 하단 탭에서 진입할 수 있다.
부모 전용 항목은 간단한 보호 장치를 둔다.

보호 방식 예시:

- 길게 누르기
- 간단한 숫자 확인
- `부모 설정으로 이동` 확인 모달

1차 버전에서는 복잡한 비밀번호보다 실수 방지 수준의 잠금을 둔다.

## 3. 설정 카테고리

| 카테고리 | 포함 항목 |
| --- | --- |
| 학습 설정 | 문제 수, 숫자 개수, 자릿수, 연산 방식, 난이도 제한 |
| 하루 루틴 | 권장 세트 수, 쉬기 안내, 오늘 목표 |
| 입력 장치 | 블루투스 주판 연결, 터치 키패드 사용 |
| 소리 | 전체 소리, BGM, 효과음, 볼륨, 주판 입력 확인음 |
| 저장 데이터 | 백업, 복원, 초기화 |
| 화면/접근성 | 글자 크기, 효과 줄이기, 집중 모드 |

## 4. 학습 설정

기본 항목:

- 한 문제에 나오는 숫자 개수
- 숫자 자릿수
- 한 세트 문제 수
- 덧셈/뺄셈 포함 여부
- 자동 난이도 조절 여부
- 최대 난이도 제한
- 현재 아이가 배운 주산 개념 체크박스

원칙:

- 기본값은 쉬운 방향으로 둔다.
- 아이가 너무 어려운 문제를 오래 풀지 않도록 최대 난이도를 설정할 수 있다.
- 자동 난이도 조절은 부모가 켜고 끌 수 있다.
- 문제 난이도는 공룡 레벨과 분리하고, 부모가 허용한 개념 범위 안에서만 출제한다.

주산 개념 기반 난이도 설정은 `problem-difficulty.md`에서 관리한다.
부모 설정에서는 Stage 하나만 고르는 방식이 아니라, 다음처럼 아이가 배운 개념을 체크할 수 있어야 한다.

- 1자리 덧셈
- 1자리 뺄셈
- 5의 보수 덧셈/뺄셈
- 10의 보수 덧셈/뺄셈
- 2자리 + 1자리
- 2자리 - 1자리
- 2자리 + 2자리
- 2자리 - 2자리
- 세 수 연산

체크한 항목 안에서만 문제가 생성되며, 자동 추천이 있더라도 부모 승인 없이 새 개념을 열지 않는다.

## 5. 하루 루틴 설정

항목:

| 설정 | 기본값 |
| --- | --- |
| 하루 권장 세트 수 | 1세트 |
| 쉬기 안내 시작 | 3세트 후 |
| 오늘의 목표 표시 | 켜짐 |
| 출석 보상 | 후속 |
| 일일 보너스 제한 | 후속 |

문구 예시:

```text
오늘은 1세트만 해도 충분해요.
```

## 6. 입력 장치 설정

블루투스 주판:

- 연결하기
- 연결 해제
- 입력 테스트
- 마지막 연결 상태 표시
- 연결 실패 안내

터치 키패드:

- 항상 표시
- 블루투스 연결 시에도 예비 입력 수단으로 유지

키보드 입력:

- 개발/보조용
- 아이 기본 흐름에서는 강조하지 않음

## 7. 소리 설정

항목:

- 전체 소리
- BGM
- 효과음
- 볼륨
- 문제풀이 중 BGM 끄기
- 주판 입력 확인음

자세한 오디오 방향은 `audio-direction.md`를 따른다.

## 8. 저장 데이터 관리

초기 버전은 로컬 저장을 사용하므로 부모 설정에서 데이터 관리가 필요하다.

항목:

- 저장 데이터 확인
- 백업 내보내기
- 백업 불러오기
- 데이터 초기화
- 설정만 초기화
- 블루투스 연결 정보 초기화

초기화는 위험 동작이므로 확인 단계를 둔다.

```text
정말 모든 게임 데이터를 초기화할까요?
공룡, 코인, 알, 도감 기록이 사라집니다.
```

## 9. 화면/접근성 설정

후속 확장 후보:

- 글자 크게 보기
- 애니메이션 줄이기
- 색 대비 높이기
- 문제풀이 집중 모드
- 소리 없이 피드백 강화

터치 노트북 기준에서 작은 링크보다 큰 버튼을 우선한다.

## 10. 저장 구조

설정값은 `GameState.userSettings` 또는 별도 settings state에 저장한다.

예시:

```ts
parentSettings: {
  maxDifficultyLevel: number;
  autoDifficulty: boolean;
  dailyRecommendedSets: number;
  restReminderAfterSets: number;
  focusModeEnabled: boolean;
  allowSubtraction: boolean;
  allowDoubleDigit: boolean;
}
```

## 11. 초기 구현 범위

1차 구현:

- 문제 설정
- 소리 설정
- 블루투스 연결/해제/테스트
- 하루 권장 세트 수
- 데이터 초기화

2차 구현:

- 백업 내보내기/불러오기
- 부모 잠금
- 자동 난이도 제한
- 접근성 설정
- 집중 모드
