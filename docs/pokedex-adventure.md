# 도감과 모험

이 문서는 도감 탭과 모험 탭의 상세 아이디어를 정리한다.

도감은 플레이어가 “다 모으고 싶다”는 욕구를 느끼게 하는 수집 시스템이고, 모험은 부화한 캐릭터를 활용해 보상을 얻는 확장 콘텐츠다.

## 1. 도감 탭

### 역할

- 발견한 캐릭터를 기록한다.
- 발견한 알, 캐릭터, 진화형, 아이템을 모아 보여준다.
- 미발견 캐릭터는 실루엣 또는 흐린 카드로 표시한다.
- 플레이어가 다음 목표를 자연스럽게 떠올리게 한다.

### 기록할 정보

도감에는 다음 정보를 기록할 수 있다.

- 알 종류
- 캐릭터 종류
- 진화형
- 희귀도
- 발견 조건
- 진화 조건
- 좋아하는 아이템
- 캐릭터 성격
- 짧은 설명

예시:

| 항목 | 예시 |
| --- | --- |
| 이름 | 폭신알 |
| 희귀도 | 기본 |
| 발견 조건 | 첫 부화방 튜토리얼 완료 |
| 진화 조건 | 친밀도 3단계 달성 |
| 성격 | 호기심 많음 |
| 좋아하는 아이템 | 말랑 열매 |
| 설명 | 처음 만나는 포근한 알 친구 |

### 미발견 표시

발견 전에는 모든 정보를 공개하지 않는다.

- 캐릭터 이미지는 실루엣으로 표시
- 이름은 `???` 또는 힌트형 이름으로 표시
- 희귀도와 큰 분류 정도만 보여줄 수 있음
- 발견 조건은 너무 직접적이지 않은 힌트로 제공 가능

목표는 도감을 공략표처럼 딱딱하게 만드는 것이 아니라, 아이가 궁금해하면서 자연스럽게 플레이하게 만드는 것이다.

## 2. 알 카테고리와 랜덤 부화

새로운 공룡은 상점에서 직접 구매하지 않는다.
상점에서는 공룡 대신 알 또는 알 조각을 얻고, 부화가 완료된 뒤에야 실제 공룡이 공개된다.

### 알 획득 원칙

- 상점에서는 공룡 이름을 직접 보여주거나 판매하지 않는다.
- 알을 구매하거나 등록할 때는 `미확인 알`, `일반 알`, `희귀 알`처럼 큰 분류만 표시한다.
- 알 조각을 모아 특정 카테고리의 알을 해금할 수 있다.
- 모험, 미션, 이벤트 보상으로도 알 조각을 얻을 수 있다.
- 도감 정식 해금은 알 구매 시점이 아니라 부화 완료 시점에 일어난다.

### 알 카테고리

| 카테고리 | 설명 | 후보 수 | 공개 정보 |
| --- | --- | ---: | --- |
| 일반 알 | 가장 기본적인 부화 알 | 약 12종 | 일반 알, 기본 무늬 |
| 희귀 알 | 더 적게 얻는 특별한 알 | 약 12종 | 희귀 알, 독특한 무늬 |
| 특별 알 | 미션, 모험, 장기 목표용 알 | 약 12종 | 특별 알, 강한 힌트 |
| 이벤트 알 | 후속 확장용 기간 한정 알 | TODO | 이벤트명 정도 |
| 전설 알 | 후속 확장용 최상위 알 | TODO | 전설 알 정도 |

- 1차 버전에서는 일반 알과 희귀 알 중심으로 시작한다.
- 특별 알은 모험이나 장기 미션과 연결하기 좋다.
- 이벤트 알과 전설 알은 초기 구현 범위에서 제외하고 후속 확장용으로 둔다.

### 랜덤 부화 규칙

부화가 완료되면 알 카테고리 안의 후보 공룡 중 하나가 랜덤으로 등장한다.

```text
일반 알 부화 완료
→ 일반 알 후보 약 12종 중 1종 선택
→ 공룡 공개
→ 도감 정식 해금
```

- 일반 알에서는 일반 알 후보군 안에서만 공룡이 나온다.
- 희귀 알에서는 희귀 알 후보군 안에서만 공룡이 나온다.
- 특별 알에서는 특별 알 후보군 안에서만 공룡이 나온다.
- 알 구매 화면에서는 정확한 공룡 이름을 공개하지 않는다.
- 부화 완료 화면에서 이름, 모습, 성격, 도감 설명을 공개한다.

### 부화 진행 게임성

부화는 단순히 시간이 지나면 완료되는 방식이 아니다.
핵심 진행 조건은 문제 풀이 세트 성공이며, 부화 보조 아이템은 문제 풀이 보상을 강화하는 역할로만 사용한다.

- 알은 부화방에 등록한 뒤 부화 게이지를 가진다.
- 20문제 세트를 완료하고 성공 조건을 만족하면 부화 게이지가 증가한다.
- 정확도와 세트 완료 여부를 우선으로 반영하고, 속도는 부화 진행의 주된 조건으로 쓰지 않는다.
- 먹이는 부화 진행의 핵심 재료가 아니라, 부화 후 공룡 성장이나 친밀도에 사용하는 아이템으로 둔다.
- 부화 보조 아이템은 문제 풀이를 대체하지 않고, 문제 풀이로 얻는 부화 진행량을 조금 늘리거나 특정 알의 조건을 열어준다.

알 종류별 부화 조건 예시:

| 알 종류 | 기본 조건 | 추가 조건 |
| --- | --- | --- |
| 기본 알 | 문제 3세트 성공 | 튜토리얼 또는 첫 부화용 |
| 일반 알 | 문제 10세트 성공 | 없음 또는 낮은 단계 보조 아이템 |
| 희귀 알 | 문제 25세트 성공 | 부화 보조 아이템 필요 |
| 특별 알 | 문제 50세트 성공 | 모험 보상 또는 특정 미션 필요 |
| 전설 알 | 장기 업적 조건 | 후속 확장용, 누적 업적/이벤트 조건 |

- `성공`은 세트 완료와 일정 정확도 이상을 기준으로 한다.
- 기준 정확도는 1차 버전에서는 B 이상을 권장하되, 어린 사용자가 좌절하지 않도록 C도 일부 진행을 줄 수 있다.
- 실패한 세트도 완전히 무효로 만들기보다, 아주 작은 참여 진행도 또는 응원 피드백을 줄 수 있다.
- 희귀 알 이상은 코인만으로 즉시 부화가 끝나지 않도록 문제 세트 조건을 반드시 요구한다.

부화 진행률 단계:

| 진행률 | 알 상태 | 공개되는 단서 |
| ---: | --- | --- |
| 0% | 기본 알 상태 | 카테고리와 기본 무늬만 표시 |
| 25% | 알이 살짝 커짐 | 약한 흔들림, 온기 표현 |
| 50% | 알 무늬가 진해지고 흔들림 효과 | 성격이나 서식지 힌트 |
| 75% | 금이 가기 시작 | 발자국/울음소리 힌트 공개 |
| 90% | 실루엣 또는 꼬리/뿔/날개 힌트 공개 | 형태 단서 강화 |
| 100% | 부화 연출 후 공룡 등장 | 이름, 모습, 도감 카드 공개 |

- 힌트는 공룡 이름을 직접 말하지 않고 추측 가능한 단서로 제공한다.
- 같은 알이라도 진행률에 따라 단서가 조금씩 강해져야 한다.
- 90% 단계에서도 정답을 확정적으로 보여주지 않고, 아이가 기대할 여지를 남긴다.

힌트 문구 예시:

```text
큰 발자국 소리가 들려요.
긴 꼬리가 움직이는 것 같아요.
뿔 모양 그림자가 보여요.
날개 같은 그림자가 보였어요.
물가를 좋아하는 친구일지도 몰라요.
```

### 부화장 저장 방식

부화장은 시간보다 문제풀이 진행도가 핵심이므로, 진행 중인 알은 문제풀이 세트 성공 횟수와 진행률 중심으로 저장한다.

부화 알 저장값:

| 필드 | 의미 |
| --- | --- |
| `eggId` | 부화 알 고유 ID |
| `eggCategory` | 알 카테고리 |
| `candidatePool` | 부화 후보 공룡 목록 |
| `progress` | 현재 부화 진행도 |
| `requiredProgress` | 부화 완료에 필요한 진행도 |
| `hintStage` | 현재 힌트 단계 |
| `createdAt` | 알 등록 시각 |
| `status` | 부화 상태 |

상태:

| 상태 | 의미 |
| --- | --- |
| `incubating` | 부화 진행 중 |
| `ready_to_hatch` | 부화 조건 완료, 부화 연출 대기 |
| `hatched` | 부화 완료 |

문제풀이 세트 성공 시:

```text
progress 증가
→ 특정 진행률에 도달하면 hintStage 증가
→ hintStage에 따라 알 크기, 무늬, 흔들림, 금, 실루엣, 울음소리 힌트 공개
→ progress가 requiredProgress에 도달하면 ready_to_hatch 상태로 변경
```

부화 보조 아이템은 즉시 부화를 끝내는 용도가 아니라, 다음 문제풀이 보상을 강화하는 방식으로 설계한다.

예시:

```text
햇살 램프 사용
→ 다음 3세트 동안 부화 progress +1 보너스
→ 문제풀이 세트 성공 때 보너스 적용
→ 3세트가 지나면 효과 종료
```

- `아이가 인지하기 쉬운 특징`은 도감 설명과 카드 요약에 사용할 수 있다.

- `좋아하는 음식 후보`는 놀이터/먹이 반응 차이에 연결할 수 있다.

### 부화 중 단서

부화 중에는 정답을 바로 알려주지 않고 단서만 제공한다.

- 실루엣
- 알 무늬
- 발자국
- 짧은 울음소리
- 좋아할 것 같은 먹이 힌트
- 서식지나 성격에 대한 짧은 문장

예시:

```text
알 안에서 작은 발자국 소리가 들려요.
둥근 잎사귀 무늬가 반짝여요.
조용한 곳을 좋아하는 친구일지도 몰라요.
```

### 도감 해금 타이밍

도감은 알 구매나 알 등록 시점에 정식 해금되지 않는다.

| 시점 | 도감 표시 |
| --- | --- |
| 알 조각 획득 | 관련 카테고리 힌트 또는 진행도 |
| 알 구매/등록 | 미확인 알, 일반 알, 희귀 알 정도 |
| 부화 진행 중 | 실루엣, 무늬, 발자국, 울음소리 힌트 |
| 부화 완료 | 공룡 이름과 카드 정식 해금 |
| 중복 부화 | 보유 표시, 보상 전환 또는 성장 재료 |

- 도감 카드는 부화 완료 시점에 완전히 열린다.
- 부화 전에는 아이가 기대감을 유지하도록 후보를 직접 나열하지 않는다.
- 도감에는 `아직 만나지 못한 일반 알 친구`처럼 큰 힌트만 줄 수 있다.

### 중복 스트레스 완화

랜덤 부화는 기대감을 만들지만, 같은 공룡이 너무 자주 나오면 스트레스가 될 수 있다.
후속 버전에서는 다음 보정 방식을 고려한다.

- 중복 방지 천장
- 미등록 공룡 우선 확률 보정
- 이미 보유한 공룡의 등장 확률 감소
- 중복 공룡을 성장 재료, 알 조각, 특별 먹이로 전환
- 같은 카테고리에서 일정 횟수 이상 중복되면 다음 부화 확률 보정

1차 버전에서는 확률 보정을 복잡하게 만들기보다, 중복 시 보상 전환 또는 낮은 단계의 보정부터 적용한다.

## 3. 모험 탭

### 역할

- 부화한 캐릭터를 활용하는 콘텐츠
- 캐릭터를 특정 지역으로 보내고 일정 시간 뒤 보상 획득
- 문제 풀이 외에도 캐릭터가 살아 있는 느낌을 주는 장치
- 도감, 상점, 부화방과 연결되는 보상 공급원

### 기본 흐름

```text
캐릭터 선택
→ 지역 선택
→ 모험 시작
→ 일정 시간 대기
→ 보상 획득
→ 도감/아이템/부화방에 반영
```

### 시간형 퀘스트 저장 방식

모험은 시간이 걸리는 퀘스트지만, 앱이 꺼져 있는 동안 실제 타이머가 계속 돌 필요는 없다.
모험 시작 시 시작 시간과 종료 예정 시간을 저장하고, 앱을 다시 열었을 때 현재 시간과 비교해 완료 여부를 판단한다.

모험 시작 시 저장할 값:

| 필드 | 의미 |
| --- | --- |
| `adventureId` | 모험 고유 ID |
| `dinosaurId` | 모험에 보낸 공룡 ID |
| `areaId` | 모험 지역 ID |
| `startedAt` | 시작 시각 |
| `durationMs` | 총 소요 시간 |
| `endsAt` | 종료 예정 시각 |
| `status` | 모험 상태 |

상태:

| 상태 | 의미 |
| --- | --- |
| `idle` | 진행 중인 모험 없음 |
| `in_progress` | 모험 진행 중 |
| `completed` | 시간이 끝났고 보상 수령 가능 |
| `claimed` | 보상 수령 완료 |

앱 재실행 시 흐름:

```text
저장된 activeAdventure 불러오기
→ Date.now()와 endsAt 비교
→ 현재 시간이 endsAt보다 크거나 같으면 completed 상태로 표시
→ 보상 받기 버튼 활성화
```

예를 들어 30분짜리 모험을 시작하고 앱을 꺼도, 2시간 뒤 다시 켜면 현재 시간과 종료 예정 시간을 비교해 모험 완료로 처리한다.
보상은 완료 판정만으로 바로 지급하지 않고, 사용자가 `보상 받기`를 누를 때 지급한다.

### 지역 예시

- 숲길
- 연못
- 구름섬
- 장난감 마을

각 지역은 보상 종류와 어울리는 분위기를 가진다.

| 지역 | 분위기 | 주요 보상 예시 |
| --- | --- | --- |
| 숲길 | 기본 탐험 지역 | 코인, 먹이 |
| 연못 | 차분한 물가 | 먹이, 희귀 알 조각 |
| 구름섬 | 특별한 하늘 지역 | 장난감, 희귀 알 조각 |
| 장난감 마을 | 놀이 중심 지역 | 장난감, 꾸미기 아이템 |

### 보상 예시

- 코인
- 먹이
- 장난감
- 희귀 알 조각
- 도감 힌트
- 낮은 확률의 특별 아이템

### 캐릭터 특성 반영

캐릭터 특성에 따라 성공률이나 보상 차이를 줄 수 있다.

- 활발한 캐릭터: 장난감 마을 보상 증가
- 차분한 캐릭터: 연못 탐험 성공률 증가
- 호기심 많은 캐릭터: 도감 힌트 발견 확률 증가
- 튼튼한 캐릭터: 긴 모험 성공률 증가

단, 1차 버전에서는 능력치가 너무 복잡해지지 않도록 캐릭터별 작은 차이 정도로만 둔다.

## 4. 도감과 모험의 연결

- 모험에서 새로운 알 조각을 얻으면 도감에 힌트가 열린다.
- 특정 지역을 여러 번 탐험하면 미발견 캐릭터 실루엣이 조금 더 명확해질 수 있다.
- 새 캐릭터를 부화시키면 도감 카드가 완전히 열린다.
- 도감 완성도는 아이에게 장기 목표가 된다.
- 모험 보상으로 얻은 알 조각은 특정 공룡을 즉시 해금하지 않고, 알 카테고리 해금이나 부화 재료로 사용한다.
- 새 공룡의 정식 도감 등록은 모험 보상 획득 시점이 아니라 부화 완료 시점에 처리한다.

## 5. 1차 구현 범위 제안

처음에는 다음 정도만 기획해도 충분하다.

- 도감 카드 목록
- 발견/미발견 상태
- 캐릭터 3~5종의 기본 정보
- 일반 알/희귀 알 카테고리
- 알 구매 또는 알 조각 누적 흐름
- 부화 완료 시 랜덤 공룡 해금
- 모험 지역 2~3개
- 보상 종류 3~4개
- 캐릭터 특성은 텍스트 설명 수준

실제 확률, 시간, 보상량은 구현 단계에서 별도 데이터로 관리한다.
