# Remote Work Rules

원격 작업 시 아래 원칙을 따른다.

1. 작업 단위를 작게 유지한다.
2. 기존 기능을 크게 리팩터링하지 않는다.
3. UI/세계관/목업 수정은 가능하지만 파괴적 변경은 피한다.
4. DB 스키마 변경, 대규모 폴더 구조 변경, 핵심 의존성 교체는 원격 작업 중 하지 않는다.
5. 작업 시작 전 현재 Git 상태를 확인한다.
6. 작업 후 변경 파일 목록과 변경 내용을 요약한다.
7. 검증은 프로젝트 루트 `AGENTS.md`의 Verification Policy를 따른다.
8. 다음날 사람이 검수하기 쉽도록 작업 단위를 명확히 구분한다.
9. 확신이 낮은 부분은 임의 확정하지 말고 "검토 필요"로 남긴다.
10. 기존 기능에 영향 가능성이 있으면 먼저 경고하고, 최소 변경으로 처리한다.
