# 오래된 유적지 Sokoban 게임 기획

## 1. 문서 목적

오래된 유적지 미니게임의 주 방향을 미러 퍼즐에서 Sokoban형 푸시 퍼즐로 변경한다. 기존 미러 퍼즐 기획과 구현 자료는 삭제하지 않고 보류 상태로 보존한다.

현재 목표는 보상이나 장기 성장 설계가 아니라 다음 두 가지를 확인하는 것이다.

- 아이가 별도 설명 없이 캐릭터를 움직여 상자를 제단으로 보내는 규칙을 이해하는가?
- 터치 조작과 퍼즐 난이도가 실제로 재미있는가?

Stage 1은 규칙 설명 전용, Stage 2는 실제 퍼즐 테스트용이다. Stage 3, 보상, 유물조각, Final 시스템은 이번 범위에서 제외한다.

## 2. 게임 정체성

- 배경: 오래된 유적지의 봉인된 방
- 장르: Sokoban / Push puzzle
- 목표: 탐험가가 유물 상자를 밀어 모든 목표 제단 위에 배치
- 이동: 상·하·좌·우 한 칸
- 상자: 앞쪽 칸이 비어 있을 때만 밀 수 있고 당길 수 없음
- 벽과 다른 상자를 통과할 수 없음
- 시간제한 없음
- 실패 페널티 없음
- 언제든 Undo와 Reset 사용 가능

핵심 재미는 상자를 어디에 둘지뿐 아니라 탐험가가 다음 밀기 위치로 돌아갈 수 있는지를 함께 생각하는 데 있다.

## 3. 기본 규칙

1. 방향 버튼을 누르면 탐험가가 한 칸 이동한다.
2. 이동할 칸에 상자가 있고 그 뒤가 비어 있으면 탐험가와 상자가 함께 한 칸 이동한다.
3. 상자 뒤가 벽, 봉인문 또는 다른 상자면 밀 수 없다.
4. 상자는 당길 수 없다.
5. 상자를 목표 제단 수만큼 모두 올리면 봉인문이 열린다.
6. 열린 봉인문에 도달하면 미션을 완료한다.
7. 잘못 움직였으면 Undo로 직전 이동을 취소하거나 Reset으로 처음부터 다시 시작한다.

Undo는 이동과 밀기를 모두 한 단계로 취급한다. 움직이지 못한 입력은 Undo 기록에 추가하지 않는다.

## 4. 화면과 조작

iPad Pro 1세대 세로 화면을 기준으로 한다.

- 상단: Stage/Mission, 완료한 목표 수, Undo, Reset
- 중앙: 정사각형 퍼즐 보드
- 하단: 큰 4방향 패드와 한 문장 안내
- 미션 시작: 짧은 설명 패널과 필요한 칸·상자·제단 하이라이트

일반 터치 버튼은 최소 56px, 방향 버튼은 64~72px 이상을 권장한다. 보드는 전체가 한 화면 안에 보이되 칸과 캐릭터가 작아지지 않도록 Stage 1은 5×5~6×6, Stage 2는 6×6~7×7 범위를 사용한다.

키보드 방향키는 개발 보조 입력으로 지원할 수 있지만 기준 조작은 화면 4방향 패드다.

## 5. 목업 그래픽 원칙

기능 검증용 목업이지만 완전한 사각형 placeholder만으로 구성하지 않는다. 실제 제작 에셋은 사용하지 않되 아이가 오브젝트의 역할을 외형으로 추측할 수 있어야 한다.

- 탐험가: 머리·몸·진행 방향이 보이는 간단한 캐릭터 실루엣
- 유물 상자: 손잡이와 금속 테두리가 있는 상자 형태
- 목표 제단: 상자를 올릴 공간과 빛나는 중심 문양
- 유적 벽: 두꺼운 석재 블록과 균열 표현
- 바닥: 이동 가능한 석판 타일
- 봉인문/출구: 잠금 상태와 열린 상태가 분명한 문 형태

목표 제단 위에 상자가 올라가면 상자 테두리, 제단 빛, HUD 체크가 동시에 바뀐다. 텍스트를 읽지 않아도 “이 캐릭터를 움직여 상자를 저기에 넣는 게임”임을 첫 화면에서 이해할 수 있어야 한다.

## 6. Stage 1: 규칙 설명 튜토리얼

Stage 1은 실패시키기 위한 퍼즐이 아니라 한 미션에 한 규칙만 경험시키는 과정이다. 미션 시작 패널은 한두 문장으로 제한하며, 닫은 뒤에도 필요한 대상이 잠시 강조된다.

### Mission 1-1: 탐험가 이동

- 상자 없음
- 목표: 4방향 이동 후 열린 출구 도달
- 안내: “화살표를 눌러 탐험가를 문까지 움직여요.”
- 강조: 탐험가, 방향 패드, 출구
- 학습: 한 칸 이동과 벽 충돌

### Mission 1-2: 상자 밀기

- 상자 1개, 목표 1개
- 직선 또는 한 번 방향을 바꾸는 매우 쉬운 구조
- 안내: “상자 쪽으로 걸어가면 상자가 앞으로 밀려요.”
- 강조: 탐험가 → 상자 → 제단 순서의 화살표
- 학습: 자동 push와 제단 완료 상태

### Mission 1-3: 당길 수 없음, Undo와 Reset

- 상자 1개, 목표 1개
- 일부러 잘못 밀어보는 짧은 시범 구역
- 안내: “상자는 당길 수 없어요. 잘못 밀었다면 되돌리기를 눌러요.”
- 강조: 당기기 금지 표시, Undo 버튼, Reset 버튼
- 학습: 되돌릴 수 없는 위치와 복구 조작

강제 실수 연출은 사용자가 조작권을 잃었다고 느끼지 않도록 한다. 권장 방식은 잘못 밀기 예시를 짧은 그림으로 보여주고, 실제 플레이에서는 스스로 Undo를 누르게 하는 것이다.

### Mission 1-4: 구석 데드락

- 상자 1개, 목표 1개
- 목표가 아닌 구석과 안전 경로를 동시에 보여주는 구조
- 안내: “상자를 구석에 밀면 다시 꺼낼 수 없어요.”
- 강조: 위험 구석의 붉은 표시와 목표 방향의 밝은 표시
- 학습: 목표가 아닌 구석을 피해야 함

자동 실패보다는 상자가 명백한 비목표 구석에 들어갔을 때 “여기서는 꺼낼 수 없어요. 되돌릴까요?” 안내를 보여준다.

### Mission 1-5: 첫 번째 실제 퍼즐

- 상자 2개, 목표 2개
- 두 상자가 서로의 이동 경로를 막을 수 있는 구조
- 안내: “두 상자를 모두 제단에 놓아요. 어느 상자를 먼저 밀까요?”
- 강조: 두 상자와 두 제단, 처음 몇 초 동안만 순서 고민 표시
- 학습: 상자 순서, 탐험가의 밀기 위치 확보, 전체 완료

## 7. Stage 1 완료 기준

- 방향 패드와 캐릭터 이동 관계를 이해한다.
- 상자를 밀 수 있고 당길 수 없음을 안다.
- 목표 제단과 일반 바닥을 구별한다.
- 구석에 넣은 상자를 꺼낼 수 없음을 안다.
- Undo와 Reset을 도움 없이 사용할 수 있다.
- Stage 1-5에서 두 상자의 순서를 생각해 해결한다.

Stage 1을 마친 아이가 Stage 2 첫 화면에서 추가 규칙 설명 없이 움직이기 시작하는 것이 목표다.

## 8. Stage 2: 실제 퍼즐 테스트

Stage 2는 총 3 Mission이며 성인 초급 수준을 목표로 한다. 보드는 6×6 또는 7×7이고, 단순 직선 밀기만으로는 해결되지 않는다.

### Mission 2-1: 기본 순서 사고

- 권장 크기: 6×6
- 상자 2개, 목표 2개
- 한 상자를 먼저 잘못 놓으면 다른 상자의 통로를 막음
- 최소 한 번은 탐험가가 상자 뒤로 우회해야 함
- 목적: 상자 처리 순서를 생각하는지 확인

### Mission 2-2: 우회와 캐릭터 위치

- 권장 크기: 7×7
- 상자 3개, 목표 3개
- 중앙 벽 또는 기둥 때문에 탐험가가 여러 방향으로 돌아가야 함
- 가까운 목표에 가까운 상자를 그대로 넣는 선택이 항상 정답은 아님
- 목적: 상자 위치뿐 아니라 다음 push를 위한 탐험가 위치를 생각하는지 확인

### Mission 2-3: 코너와 통로 데드락

- 권장 크기: 7×7
- 상자 3개, 목표 3개
- 좁은 통로와 목표가 아닌 코너 존재
- 특정 상자를 통로 안쪽에 너무 일찍 넣으면 나머지 상자가 막힘
- Stage 2에서 가장 어려우며 여러 번 Undo할 가능성을 허용
- 목적: 데드락 예측과 여러 단계 계획 확인

모든 Stage 2 퍼즐은 실제 config 확정 시 전체 상태 또는 검증 가능한 solver로 풀이 가능성을 확인한다. 의도한 최소 push 수, 최소 이동 수, 해답 수, 즉시 데드락 위치를 함께 기록한다.

## 9. 튜토리얼 전달 방식

미션 시작 패널은 다음 순서를 사용한다.

1. 행동을 보여주는 작은 그림 또는 보드 위 애니메이션
2. 15자 안팎의 핵심 문장
3. “해보기” 버튼
4. 시작 후 2~3초 동안 관련 오브젝트 하이라이트

아이의 입력을 막는 긴 설명, 여러 규칙을 한 번에 설명하는 문장, 읽어야만 알 수 있는 아이콘은 피한다. 같은 설명은 반복 노출하지 않되 Undo나 Reset을 사용하지 못하고 정체하면 상황형 힌트를 보여준다.

## 10. 검증 우선순위

1. 첫 화면만 보고 상자와 제단의 관계를 이해하는가?
2. 방향 입력이 한 칸씩 정확하고 빠르게 반응하는가?
3. 연속 입력이나 빠른 탭이 의도치 않은 두 칸 이동을 만들지 않는가?
4. 상자를 밀 수 없는 이유가 명확한가?
5. Undo와 Reset의 차이를 이해하는가?
6. Stage 1-5와 Stage 2에서 생각하는 시간이 재미로 느껴지는가?
7. 데드락 안내가 정답을 과도하게 알려주지 않는가?
