# 오래된 유적지 Sokoban 목업 계획

## 1. 목업 범위

- Stage 1: 튜토리얼 5 Mission
- Stage 2: 성인 초급 퍼즐 3 Mission
- Stage 3: 구현·설계 제외
- 보상, 유물조각, Final: 제외
- 그래픽: 역할을 알아볼 수 있는 임시 캐릭터·상자·제단·벽·바닥·봉인문

이번 목업의 성공 기준은 콘텐츠 양이 아니라 규칙 이해, 조작성, 생각하는 재미다.

## 2. Mission 구성표

| Mission | 보드 | 상자/목표 | 핵심 규칙 | 시작 안내 |
|---|---:|---:|---|---|
| 1-1 | 5×5 | 0/0 | 4방향 이동과 벽 | “화살표를 눌러 문까지 가요.” |
| 1-2 | 5×5 | 1/1 | 상자 자동 push | “상자 쪽으로 걸어가면 앞으로 밀려요.” |
| 1-3 | 5×6 | 1/1 | 당길 수 없음, Undo/Reset | “상자는 당길 수 없어요. 잘못 밀면 되돌려요.” |
| 1-4 | 6×6 | 1/1 | 비목표 구석 데드락 | “구석에 밀면 상자를 꺼낼 수 없어요.” |
| 1-5 | 6×6 | 2/2 | 첫 순서 퍼즐 | “두 상자 중 어느 것을 먼저 밀까요?” |
| 2-1 | 6×6 | 2/2 | 상자 순서 | 설명 없이 목표만 표시 |
| 2-2 | 7×7 | 3/3 | 우회와 밀기 위치 | 설명 없이 목표만 표시 |
| 2-3 | 7×7 | 3/3 | 코너·통로 데드락 | 설명 없이 목표만 표시 |

## 3. Stage 1 상세 목업

### 1-1 이동

- 보드 중앙에서 시작해 위·옆 방향을 모두 한 번 이상 사용하도록 ㄱ자 통로를 만든다.
- 출구는 처음부터 열린다.
- 첫 입력 전 방향 패드와 캐릭터에 같은 방향 색을 잠시 표시한다.
- 벽 입력 시 캐릭터가 이동하지 않고 작은 흔들림만 보여준다.

관찰: 첫 이동 시간, 방향 혼동, 벽을 반복해서 누르는지.

### 1-2 밀기

- 탐험가, 상자, 제단을 거의 한 직선에 배치한다.
- 상자를 한두 번 밀면 제단에 올라간다.
- 첫 push 전 상자 뒤쪽 바닥과 제단을 잇는 화살표를 표시한다.
- 완료 시 제단 점등과 봉인문 개방을 함께 보여준다.

관찰: 상자를 터치하려 하는지, 캐릭터로 미는 규칙을 이해하는지.

### 1-3 당기기와 복구

- 한 번 옆으로 밀면 탐험가가 반대편으로 갈 수 없는 짧은 벽 구조를 둔다.
- 미션 시작 그림에서 밀기 가능과 당기기 불가를 나란히 보여준다.
- 진행이 막힌 뒤 Undo를 강조하고, 사용하지 않으면 Reset도 안내한다.

관찰: 막힌 이유를 이해하는지, Undo를 한 번만 눌러 복구하는지, Reset과 혼동하는지.

### 1-4 구석

- 목표가 아닌 구석은 입구에서 보이고, 올바른 제단은 다른 방향에 둔다.
- 위험 구석에 상자가 들어가면 즉시 패배시키지 않는다.
- 구석 타일과 Undo 버튼을 강조하며 짧은 안내를 표시한다.

관찰: 다음 시도에서 구석을 피하는지, 안내가 정답을 그대로 말하지 않는지.

### 1-5 두 상자

- 첫 상자를 가까운 목표에 바로 넣으면 다른 상자 경로가 막히는 기초 순서 구조를 사용한다.
- 완전 데드락 전에도 탐험가가 상자 뒤로 돌아가는 경로를 경험하게 한다.
- 시작 하이라이트는 두 상자와 두 목표만 표시하고 정답 순서는 표시하지 않는다.

관찰: 보드 전체를 먼저 보는지, 첫 상자를 즉시 미는지, Undo 후 전략을 바꾸는지.

## 4. Stage 2 상세 목업

### 2-1 기본 순서 사고

- 6×6, 상자 2개, 목표 2개
- 목표 앞 통로를 공유하게 하여 안쪽 목표를 먼저 채우게 한다.
- 잘못된 순서는 2~4 push 안에 명확한 막힘으로 드러나야 한다.
- 정답은 긴 이동보다 순서 선택이 핵심이어야 한다.

초기 난이도 목표: 정답 push 6~10회, Undo 0~3회.

### 2-2 우회 및 캐릭터 위치

- 7×7, 상자 3개, 목표 3개
- 중앙 기둥을 돌아 상자의 다른 면으로 이동해야 한다.
- 상자 하나는 가장 가까운 목표가 아닌 다른 목표로 보내야 한다.
- 두 상자를 붙여 영구적으로 막는 위치를 한 곳 포함한다.

초기 난이도 목표: 정답 push 10~16회, 방향 전환과 우회가 3회 이상.

### 2-3 코너와 통로

- 7×7, 상자 3개, 목표 3개
- 폭 1칸 통로와 비목표 코너를 포함한다.
- 통로 안쪽 목표부터 처리하지 않으면 나머지 상자를 밀 수 없게 한다.
- 초반 선택의 결과가 너무 늦게 드러나지 않도록 6~8 push 안에 막힘을 인지할 수 있게 한다.

초기 난이도 목표: 정답 push 14~22회, 최소 두 단계 이상의 순서 계획.

## 5. 퍼즐 확정 전 검증 항목

각 config 후보에 대해 다음을 기록한다.

- 모든 상자를 모든 목표에 놓을 수 있는 실제 해답
- 최소 push 수와 최소 전체 이동 수
- 완전 동일하지 않은 해답 경로 수
- 목표가 아닌 모서리와 벽면 데드락 좌표
- 상자끼리 만드는 동적 데드락 사례
- 초기 상태에서 출구·상자·목표가 겹치지 않는지
- 플레이어가 모든 필요한 상자 면으로 이동 가능한지

Stage 1은 해답 유일성보다 규칙 전달을 우선한다. Stage 2는 지나치게 짧은 우회 해답이 없는지 solver 또는 완전탐색으로 확인한다.

## 6. 아이 테스트 관찰 항목

- 캐릭터를 움직여 상자를 제단에 넣는 게임임을 첫 화면에서 말하거나 행동으로 보이는가?
- 상자를 직접 드래그하거나 터치하려 하는가?
- 상자를 당기려고 반복 입력하는가?
- 목표 제단 위 상자의 완료 상태를 알아차리는가?
- 벽, 상자, 제단, 출구를 혼동하지 않는가?
- Undo와 Reset 중 필요한 기능을 선택하는가?
- 연속 탭, 길게 누르기, 빠른 방향 전환이 정확히 처리되는가?
- Stage 1-4 이후 목표가 아닌 구석을 의식하는가?
- Stage 1-5 이후 Stage 2를 추가 설명 없이 시작하는가?
- 정체 시간이 생각하는 시간인지 조작·규칙 혼란인지?

## 7. 수집할 지표

- 첫 유효 이동까지 시간
- 첫 push까지 시간
- Mission별 완료 시간
- 이동 수와 push 수
- Undo와 Reset 사용 횟수
- 벽/상자 때문에 실패한 입력 횟수
- 데드락 진입 횟수와 복구 시간
- 힌트 노출 및 사용 여부
- Stage 2 미션별 완료율

## 8. 난이도 조정 기준

### 너무 쉬운 경우

- 정답 순서가 시작 위치에서 즉시 보인다.
- 상자 뒤로 우회할 필요가 없다.
- 잘못된 순서도 같은 해답으로 합류한다.
- Stage 2를 거의 멈추지 않고 연속 입력으로 완료한다.

조정: 공유 통로, 중앙 기둥, 안쪽 목표 우선 구조를 추가하되 보드 크기부터 늘리지는 않는다.

### 너무 어려운 경우

- 첫 의미 있는 push 전에 오래 정체한다.
- 데드락 결과가 너무 늦게 드러난다.
- Undo를 여러 번 눌러도 어떤 선택이 잘못됐는지 알 수 없다.
- 우회 이동이 퍼즐 사고보다 반복 노동으로 느껴진다.

조정: 벽을 제거해 밀기 위치를 늘리고, 데드락 결과를 앞당기며, 목표와 상자의 시각적 대응을 강화한다.

### Stage 1 합격 기준

- 1-2에서 대부분이 설명 후 첫 시도에 상자를 민다.
- 1-3 또는 1-4에서 Undo를 도움 없이 사용한다.
- 1-5에서 두 상자를 모두 해결하고 자신의 순서를 설명할 수 있다.
- Stage 2 진입 후 규칙 팝업 없이 플레이를 시작한다.

### Stage 2 합격 기준

- 각 미션에 생각을 멈추는 지점이 최소 한 번 있다.
- 막힘을 경험한 뒤 Undo/Reset으로 전략을 바꾼다.
- 조작 실패가 원인이 되어 포기하는 사례가 반복되지 않는다.
- 2-3이 가장 어렵지만 초급 플레이어가 힌트 없이도 반복 시도해 해결 가능하다.
