# 저장 데이터 백업, 초기화, 복구 정책

이 문서는 로컬 웹앱에서 사용하는 저장 데이터의 백업, 초기화, 복구 정책을 정리한다.
초기 버전은 서버 계정 없이 `localStorage`를 사용하므로, 데이터 손상이나 브라우저 데이터 삭제에 대비한 안내와 도구가 필요하다.

## 1. 기본 원칙

- 저장 데이터는 같은 브라우저/같은 프로필 안에서만 유지된다.
- 브라우저 사이트 데이터 삭제 시 게임 데이터가 사라질 수 있다.
- 아이가 실수로 초기화하지 않도록 부모 설정 안에 배치한다.
- 백업과 초기화는 명확한 확인 단계를 둔다.
- 복구 실패가 앱 실행 전체를 막으면 안 된다.
- 손상된 데이터는 즉시 삭제하지 않고 가능한 한 백업 키에 보존한다.

## 2. 저장 대상

백업에 포함할 데이터:

- 보유 코인
- 공룡 목록과 성장 상태
- 보유 음식/코스튬/부화 보조 아이템
- 보유 알/알 조각
- 진행 중인 부화 알
- 도감 해금 상태
- 모험 상태
- 퀘스트/업적/출석 상태
- 문제 난이도 설정
- 오디오/접근성/부모 설정

백업에 포함하지 않아도 되는 데이터:

- 일시적인 화면 상태
- 현재 입력 중인 답안
- 진행 중인 애니메이션 상태
- 오디오 로딩 상태

## 3. 백업 내보내기

부모 설정에서 `백업 내보내기`를 제공한다.

흐름:

```text
부모 설정
→ 저장 데이터 관리
→ 백업 내보내기
→ 현재 GameState JSON 생성
→ 파일 다운로드
```

파일명 예시:

```text
abacus-dino-backup-YYYY-MM-DD.json
```

내보내기 전 문구:

```text
현재 공룡, 코인, 알, 도감 기록을 백업 파일로 저장합니다.
이 파일은 같은 앱에서 다시 불러올 수 있어요.
```

## 4. 백업 불러오기

부모 설정에서 `백업 불러오기`를 제공한다.

흐름:

```text
부모 설정
→ 저장 데이터 관리
→ 백업 불러오기
→ JSON 파일 선택
→ 형식 검증
→ 버전 확인과 migration
→ 현재 데이터 덮어쓰기 확인
→ 복원 완료
```

덮어쓰기 확인 문구:

```text
백업을 불러오면 현재 저장된 공룡, 코인, 알, 도감 기록이 백업 파일 내용으로 바뀝니다.
계속할까요?
```

검증 실패 시:

```text
이 백업 파일을 읽을 수 없어요.
다른 백업 파일을 선택해 주세요.
```

## 5. 초기화 종류

초기화는 범위를 나눠 제공한다.

| 초기화 종류 | 영향 |
| --- | --- |
| 설정만 초기화 | 문제 설정, 소리, 접근성, 부모 설정을 기본값으로 복구 |
| 블루투스 설정 초기화 | 주판 연결 관련 저장 정보만 초기화 |
| 학습 기록 초기화 | 최근 세트 기록, 오늘 학습 기록 초기화 |
| 게임 진행 전체 초기화 | 코인, 공룡, 알, 도감, 상점 보유 상태 전체 초기화 |

1차 구현에서는 `설정만 초기화`, `블루투스 설정 초기화`, `게임 진행 전체 초기화`를 우선 제공한다.

## 6. 전체 초기화 확인

전체 초기화는 가장 위험한 동작이다.

확인 문구:

```text
정말 모든 게임 데이터를 초기화할까요?
공룡, 코인, 알, 도감 기록이 사라집니다.
```

2차 확인 문구:

```text
초기화 전에 백업 파일을 저장하는 것을 권장합니다.
```

버튼:

```text
[백업 먼저 하기] [초기화하기] [취소]
```

아이용 화면에서는 전체 초기화 버튼을 노출하지 않는다.

## 7. 저장 데이터 손상 복구

앱 실행 시 저장 데이터를 읽을 수 없는 경우:

```text
저장된 내용을 읽기 어려워요.
기본 상태로 복구할 수 있어요.
```

처리 순서:

```text
localStorage 읽기
→ JSON parse 시도
→ 실패 시 원본 문자열을 corrupted 키에 저장
→ 기본 GameState 생성
→ 부모 설정에 복구 안내 표시
```

권장 키:

```text
abacus-dino-game-state-corrupted
```

## 8. Migration 실패 복구

저장 데이터 version이 낮아 migration을 시도했지만 실패한 경우:

```text
이전 저장 데이터를 새 버전으로 바꾸는 중 문제가 생겼어요.
기존 데이터는 백업해 두고 기본 상태로 시작할게요.
```

처리:

- 기존 데이터를 `abacus-dino-game-state-backup`에 저장
- 기본 GameState로 시작
- 부모 설정에서 백업 다운로드 버튼 제공

## 9. 복원 후 검증

백업을 불러온 뒤 확인할 항목:

- `version` 존재
- 필수 최상위 필드 존재
- 코인 값이 음수가 아님
- 공룡/아이템 수량이 음수가 아님
- 진행 중인 알 status가 유효함
- 모험 `endsAt`이 숫자임
- settings 기본값 보정 가능

검증은 너무 엄격해서 오래된 백업을 모두 거부하기보다, 기본값 보정으로 복원 가능한 방향을 우선한다.

## 10. 사용자 안내

부모 설정에 짧은 설명을 둔다.

```text
이 게임은 이 노트북의 브라우저에 데이터를 저장합니다.
브라우저 데이터를 지우면 게임 기록이 사라질 수 있어요.
가끔 백업 파일을 저장해 주세요.
```

PWA 설치 후에도 브라우저 저장소 정책의 영향을 받는다는 점을 별도 안내한다.

## 11. 초기 구현 범위

1차 구현:

- 전체 초기화
- 설정만 초기화
- 블루투스 설정 초기화
- 손상 데이터 감지 후 기본 상태 복구

2차 구현:

- 백업 JSON 내보내기
- 백업 JSON 불러오기
- migration 실패 시 backup 키 보존

후속 구현:

- 백업 자동 알림
- IndexedDB 전환
- 클라우드 동기화
- 여러 프로필 지원
