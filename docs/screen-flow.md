# 화면 흐름

## 1. 전체 흐름

시작 화면
→ 20문제 풀이 화면
→ 결과 화면
→ 공룡 키우기 화면
→ 상점 화면
→ 다시 시작 화면 또는 다음 세트

## 2. 화면별 역할

### 시작 화면
- 게임 시작
- 현재 코인 확인
- 대표 공룡 확인

### 문제 풀이 화면
- 20문제 풀이
- 정답 시 코인 획득 예정 표시
- 속도 보너스 표시

### 결과 화면
- 20문제 결과 요약
- 최종 코인 정산
- 성장 결과 확인

### 공룡 키우기 화면
- 먹이 주기
- 경험치 확인
- 레벨 확인

### 상점 화면
- 먹이 구매
- 코스튬 구매
- 새 공룡 구매
