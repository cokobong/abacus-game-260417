# 상점과 아이템 기획

이 문서는 상점과 아이템의 기획 방향을 정리한다.

실제 코드 구현이나 전체 아이템 데이터 목록을 작성하는 문서가 아니라, 아이템의 역할, 카테고리, 밸런스 원칙을 정리하는 문서다.

## 1. 상점의 역할

- 문제 풀이와 모험에서 얻은 코인을 사용할 곳을 제공한다.
- 부화방과 놀이터에서 쓸 아이템을 공급한다.
- 아이가 캐릭터에게 애착을 느끼도록 돕는다.
- 너무 많은 상품으로 화면을 복잡하게 만들지 않는다.

## 2. 초기 아이템 수

처음에는 아이템을 3~5개만 구성한다.

초기 후보:

| 카테고리 | 아이템 예시 | 역할 |
| --- | --- | --- |
| 먹이 | 말랑 열매 | 부화 후 공룡 체력 회복 |
| 먹이 | 반짝 사탕 | 더 큰 체력 회복 |
| 장난감 | 작은 공 | 놀이터 상호작용 |
| 장난감 | 방울 막대 | 캐릭터 기분 회복 |
| 재료 | 희귀 알 조각 | 특별 알 획득 재료 |
| 부화 보조 | 따뜻한 둥지 | 문제 풀이 부화 진행 보조 |

아이템 이름과 수치는 구현 단계에서 바뀔 수 있다.

## 3. 아이템 카테고리

### 먹이

- 주로 우리 공룡 탭에서 체력 회복에 사용한다.
- 경험치나 포만감 아이템으로 쓰지 않는다.
- 행복이 높으면 체력 회복량이 소폭 증가할 수 있다.
- 부화 게이지를 직접 올리는 핵심 수단으로 쓰지 않는다.
- 초기에는 효과를 단순하게 둔다.

### 부화 보조 아이템

- 부화방에서 사용하지만, 문제 풀이를 대체하지 않는다.
- 코인으로 구매할 수 있으나 코인만으로 즉시 부화가 끝나면 안 된다.
- 문제 풀이 세트 성공으로 얻는 부화 진행량을 강화하거나, 희귀 알 이상의 추가 조건을 채우는 역할로 둔다.
- 부화 보조 아이템은 `사용하면 바로 부화`가 아니라 `다음 N세트 동안 부화 진행 보너스`, `특정 알 조건 충족`, `힌트 추가 공개`처럼 제한된 효과를 가진다.
- 아이가 학습을 계속해야 부화가 진행된다는 구조를 유지한다.

### 장난감

- 놀이터에서 캐릭터와 상호작용할 때 사용한다.
- 캐릭터 행복에 영향을 줄 수 있다.
- 캐릭터별 선호 장난감을 둘 수 있다.

### 꾸미기 아이템

- 캐릭터나 공간을 꾸미는 용도다.
- 능력치보다 애착과 소장감 중심으로 둔다.
- 코스튬 효과는 작게 하거나 순수 외형 중심으로 둔다.
- 고가 코스튬은 장기 목표이자 코인 소모처로 기능하게 한다.
- 1차 버전에서는 기획만 하고 구현은 뒤로 미뤄도 된다.

### 재료 아이템

- 희귀 알 조각처럼 장기 목표를 만드는 아이템이다.
- 모험 보상과 연결하기 좋다.
- 너무 자주 지급하면 희귀성이 떨어지므로 보상량을 조심한다.

## 4. 밸런스 원칙

- 아이템 효과는 아이가 바로 이해할 수 있어야 한다.
- 학습 난이도를 대신 해결하는 아이템은 만들지 않는다.
- 초반에는 코인 사용처를 적게 두고, 이후 데이터 추가로 확장한다.
- 비싼 아이템은 장기 목표 역할을 하되, 초반 플레이를 막지 않아야 한다.
- 먹이와 장난감은 자주 쓰는 소모품, 희귀 알 조각은 장기 수집품으로 둔다.
- 대상 연령은 7~8세로 둔다.
- 보상 반응이 강한 아이를 기준으로, 자주 쓰는 소모품은 빠르게 살 수 있게 하되 새 공룡 해금은 너무 빨리 끝나지 않게 한다.
- 하루 1~3세트 플레이로 얻는 코인 수입을 기준으로 가격을 잡는다.
- 공룡 도감 해금은 즉시 구매보다 알 조각 누적 방식을 우선한다.

## 5. 코인 보상과 가격 밸런스

상점 가격은 `docs/game-rule.md`의 20문제 1세트 코인 보상을 기준으로 맞춘다.
초기 기준에서는 보통 1세트에 약 100~130코인, 하루 2세트에 약 200~300코인을 얻는 흐름을 예상한다.

### 가격 단계

| 단계 | 가격 범위 | 역할 | 예상 구매 주기 |
| --- | ---: | --- | --- |
| 저가 소모품 | 30~80코인 | 기본 먹이, 작은 성장 | 1세트 안에 1~3개 |
| 중가 소모품 | 100~180코인 | 좋은 열매, 기본 장난감 | 1~2세트 |
| 활동 아이템 | 200~350코인 | 모험 티켓, 특별 상호작용 | 2~3세트 |
| 고가 소모품 | 400~700코인 | 반짝 먹이, 강한 성장 | 2~5세트 |
| 장기 수집품 | 800코인 이상 | 알 조각, 희귀 해금 | 여러 날 |
| 공룡 해금 | 알 조각 누적 | 새 도감 해금 | 1주 이상 목표 |

### 아이템 가격 예시

| 카테고리 | 아이템 | 가격 예시 | 역할 |
| --- | --- | ---: | --- |
| 먹이 | 기본 먹이 | 40코인 | 체력 회복 소 |
| 먹이 | 말랑 열매 | 80코인 | 체력 회복 중 |
| 장난감 | 작은 장난감 | 150코인 | 놀이터 상호작용, 기분 회복 |
| 모험 | 모험 티켓 | 250코인 | 모험 1회 또는 보상 지역 입장 |
| 먹이 | 반짝 먹이 | 500코인 | 체력 회복 대, 행복 보정 적용 |
| 재료 | 희귀알 조각 | 모험/미션 보상 | 서식지별 희귀알 해금 재료 |
| 알 | 서식지별 희귀알 | 희귀알 조각 5/10/15/20개 | 새 희귀 공룡 도감 해금 |

- 기본 먹이는 아이가 한 세트를 끝낸 뒤 바로 살 수 있는 가격으로 둔다.
- 열매와 장난감은 하루 1~2세트 플레이하면 손에 닿는 가격으로 둔다.
- 모험 티켓은 매 세트마다 무제한으로 쓰기보다, 조금 모아서 선택적으로 쓰는 가격으로 둔다.
- 반짝 먹이는 강한 보상 반응을 주되 매번 살 수 없게 한다.
- 희귀알 조각은 MVP에서 `rare-egg-fragment` 하나만 사용하며, 각 희귀알에 따로 누적되지 않는 공통 재화로 둔다.
- 희귀알은 원하는 서식지를 선택해 열 때 공통 조각을 소비한다.
- 희귀알 요구량은 초록 숲 5개, 반짝 동굴 10개, 화산섬 15개, 비밀의 땅 20개이며 모두 열려면 총 50개가 필요하다.
- 공룡 알은 코인으로 즉시 구매하는 방식보다 알 조각을 모아 해금하는 방식을 우선한다.

### 음식 탭 아이템

음식은 공룡의 체력 회복에 사용한다.
행복이 높을수록 음식으로 회복되는 체력이 소폭 증가한다.
EXP의 주 수입원은 문제 풀이이며, 음식은 EXP 보조가 아니라 행동 자원 회복 수단으로 둔다.

| 아이템 | 가격 | 효과 | 구매 주기 |
| --- | ---: | --- | --- |
| 나뭇잎 | 30코인 | 체력 회복 소 | 매일 여러 개 구매 가능 |
| 기본 고기 | 50코인 | 체력 회복 중 | 매일 구매 가능 |
| 말랑 열매 | 80코인 | 체력 회복 소, 행복 보정 적용 | 매일 구매 가능 |
| 공룡 쿠키 | 150코인 | 체력 회복 대 | 하루 1개 정도 |
| 튼튼 고기 | 220코인 | 체력 회복 중 | 1~2일에 1개 |
| 반짝 간식 | 400코인 | 체력 회복 대 | 며칠 모아 구매 |
| 힘찬 도시락 | 500코인 | 체력 크게 회복 | 며칠 모아 구매 |
| 진화 열매 | 700코인 | 특정 레벨 이후 성장 단계 보조 | 장기 목표 |
| 전설 간식 | 1,000코인 | 특별 성장 보조, 매우 제한적으로 사용 | 장기 목표 |

음식 밸런스 원칙:

- 싼 음식은 매일 구매 가능해야 한다.
- 중간 음식은 하루 1개 정도 구매 가능한 가격으로 둔다.
- 고급 음식은 며칠 코인을 모아야 구매 가능하게 둔다.
- 음식은 EXP가 아니라 체력 회복을 담당한다.
- 문제 풀이가 성장과 EXP 획득의 핵심이어야 한다.
- `진화 열매`와 `전설 간식`은 일반 성장용이 아니라 특정 조건 이후 사용하는 제한 아이템으로 둔다.
- 고급 음식은 일일 구매 제한이나 사용 제한을 둘 수 있다.

공룡 성장, EXP, 레벨업, 행복 보정의 상세 정책은 `docs/dinosaur-growth-system.md`를 기준으로 한다.

### 코스튬 탭 아이템 12개

코스튬은 능력치보다 애착과 수집욕을 높이는 용도로 설계한다.
효과는 순수 외형 중심으로 두고, 보너스가 있더라도 행복, 연출, 테마 변화처럼 작은 효과에 제한한다.

| 아이템 | 가격 | 효과 | 역할 |
| --- | ---: | --- | --- |
| 작은 모자 | 150코인 | 외형 꾸미기 | 첫 코스튬 |
| 빨간 리본 | 180코인 | 외형 꾸미기 | 가벼운 꾸미기 |
| 탐험가 가방 | 250코인 | 모험 분위기 강화 | 모험 테마 |
| 둥근 안경 | 300코인 | 외형 꾸미기 | 캐릭터 개성 |
| 별 목걸이 | 400코인 | 행복 보너스 소 | 작은 보조 효과 |
| 나뭇잎 망토 | 500코인 | 숲 모험 테마 | 지역 테마 |
| 용감한 머리띠 | 700코인 | 연속 성공 응원 연출 강화 | 학습 응원 연출 |
| 반짝 왕관 | 1,000코인 | 특별 외형 | 고가 꾸미기 |
| 공룡 기사 헬멧 | 1,200코인 | 특별 외형 | 고가 꾸미기 |
| 마법사 모자 | 1,500코인 | 특별 외형 | 고가 꾸미기 |
| 우주 헬멧 | 2,000코인 | 특별 외형 | 장기 목표 |
| 전설 망토 | 3,000코인 | 장기 목표 외형 | 최고가 코인 소모처 |

코스튬 밸런스 원칙:

- 코스튬은 계산 난이도, 정답률, 문제 풀이 보상을 직접 올리지 않는다.
- 코스튬 효과는 외형, 짧은 연출, 행복 보너스 소처럼 작은 수준으로 제한한다.
- 저가 코스튬은 며칠 안에 손에 닿아 첫 꾸미기 경험을 만든다.
- 고가 코스튬은 며칠~몇 주 단위의 장기 목표가 되도록 둔다.
- 코스튬은 아이가 공룡에게 애착을 느끼고 “내 공룡”이라고 생각하게 만드는 장치다.
- 전설 망토 같은 최고가 아이템은 반복 플레이 후 남는 코인을 태우는 장기 코인 소모처로 둔다.

### 부화 보조 아이템 예시

부화 보조 아이템은 부화 게이지를 직접 구매하는 아이템이 아니라, 문제 풀이로 얻는 부화 진행을 돕는 아이템이다.

| 아이템 | 가격 예시 | 효과 방향 |
| --- | ---: | --- |
| 따뜻한 둥지 | 120코인 | 다음 3세트의 부화 진행량 소폭 증가 |
| 햇살 램프 | 180코인 | 일반 알 부화 진행 보너스 |
| 포근한 이불 | 220코인 | 세트 성공 시 추가 안정도 또는 작은 진행 보너스 |
| 반짝 조약돌 | 350코인 | 희귀 알 부화 조건 보조 |
| 탐험 지도 조각 | 400코인 | 특별 알 조건에 필요한 모험 단서 |
| 부화 응원 종 | 500코인 | 다음 세트 성공 시 힌트 추가 공개 또는 보너스 진행 |

- 같은 부화 보조 아이템을 과도하게 중첩하지 않도록 제한한다.
- 희귀 알과 특별 알은 보조 아이템이 있어도 정해진 문제 세트 성공 조건을 채워야 한다.
- 부화 보조 아이템 가격은 아이가 1~3세트 플레이 후 선택적으로 살 수 있는 수준에서 시작한다.
- 보조 아이템은 학습 보상을 강화하는 장치이지, 학습을 건너뛰는 지름길이 아니다.

### 공룡 도감 해금 원칙

새 공룡은 `코인 즉시 구매`보다 `알 조각 누적` 방식으로 해금한다.

권장 흐름:

```text
문제 풀이로 코인 획득
→ 먹이, 장난감, 모험 티켓 구매
→ 모험 또는 미션으로 공통 희귀알 조각 획득
→ 원하는 서식지 희귀알을 선택해 조각 소비
→ 부화방에서 새 공룡 획득
→ 도감 등록
```

- 공룡 알은 아이가 며칠 동안 목표를 이어갈 수 있는 장기 보상으로 둔다.
- 코인만 충분하면 새 공룡을 바로 사는 구조는 피한다.
- 코인은 일반알/특수알과 기본 아이템에 사용하고, 희귀알 조각은 모험/미션 보상 중심으로 둔다.
- 이벤트나 첫 플레이 보상으로는 낮은 등급 공룡 알 1개를 제공할 수 있지만, 반복 해금은 알 조각 누적을 기본으로 한다.

### 가격 조정 메모

- 아이가 하루 2~3세트만으로 모든 주요 아이템을 빠르게 사면 가격을 올리거나 구매 제한을 둔다.
- 기본 먹이를 너무 비싸게 두면 첫 세트 보상 만족감이 약해지므로 저가 소모품은 유지한다.
- 알 조각 가격은 실제 모험 보상량과 함께 조정한다.
- 도감 해금 속도는 7~8세 아이가 지루해하지 않으면서도 며칠 이상 기대할 수 있는 수준으로 맞춘다.

## 6. 데이터 관리 원칙

추후 구현에서는 아이템을 문서에 계속 추가하지 않고 TypeScript 데이터 파일에서 관리한다.

예상 방향:

```text
src/data/items.ts
```

이 데이터 파일에는 다음 정보를 둘 수 있다.

- 아이템 ID
- 이름
- 카테고리
- 가격
- 효과 설명
- 밸런스 수치
- 이미지 경로

이미지는 `assets` 폴더에 별도로 두고, TypeScript 데이터에서는 이미지 경로만 참조한다.

## 7. 1차 구현 범위 제안

상점은 처음부터 큰 시스템으로 만들지 않는다.

- 아이템 3~5개
- 코인 가격
- 간단한 설명
- 음식 탭은 처음부터 12개를 모두 구현하지 않아도 되며, 가격 단계와 데이터 구조를 먼저 준비한다.
- 코스튬 탭도 처음부터 12개를 모두 구현하지 않아도 되며, 저가 2~3개와 고가 목표 1개부터 시작할 수 있다.
- 먹이 또는 장난감 사용처 1개 이상
- 이미지 경로를 넣을 수 있는 데이터 구조

아이템 확장은 코드 구조를 바꿔서 하는 것이 아니라, 데이터 파일에 항목을 추가하는 방식으로 준비한다.
