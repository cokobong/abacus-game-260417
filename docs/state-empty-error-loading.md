# 빈 상태, 에러 상태, 로딩 상태

이 문서는 앱 전반에서 데이터가 없거나, 연결/저장/오디오 로딩이 실패하거나, 처리 중일 때 보여줄 상태를 정리한다.
아이용 앱이므로 에러도 무섭지 않고 이해하기 쉬운 표현을 사용한다.

## 1. 기본 원칙

- 아무것도 없는 화면을 만들지 않는다.
- 에러는 아이에게 책임을 돌리는 문구로 표현하지 않는다.
- 가능한 다음 행동을 항상 보여준다.
- 블루투스, 오디오, 저장 실패가 문제풀이 전체를 멈추지 않도록 한다.
- 부모가 조치해야 하는 에러는 설정 화면으로 연결한다.

## 2. 빈 상태

| 위치 | 상황 | 표시 문구 | 행동 |
| --- | --- | --- | --- |
| 우리 공룡 | 보유 공룡 없음 | 아직 만난 공룡이 없어요. 첫 알을 깨워볼까요? | 부화장으로 이동 |
| 부화장 | 등록된 알 없음 | 쉬고 있는 알이 없어요. 상점에서 알을 찾아볼까요? | 상점으로 이동 |
| 도감 | 해금 공룡 없음 | 아직 도감이 비어 있어요. 첫 부화를 기다려요. | 훈련 시작 |
| 모험 | 보낼 공룡 없음 | 모험을 떠날 친구가 아직 없어요. | 부화장으로 이동 |
| 상점 | 구매 가능 아이템 없음 | 지금은 준비 중이에요. | 홈으로 이동 |
| 인벤토리 | 보유 아이템 없음 | 아직 가진 아이템이 없어요. | 상점으로 이동 |

빈 상태는 안내와 행동 버튼을 함께 둔다.

## 3. 로딩 상태

로딩이 필요한 상황:

- 앱 시작 시 GameState 복원
- 블루투스 연결 시도
- 오디오 리소스 준비
- PWA 캐시 또는 화면 리소스 준비
- 모험 완료 상태 계산

문구 예시:

```text
공룡 친구들을 불러오는 중이에요.
주판을 찾는 중이에요.
알 상태를 확인하는 중이에요.
```

로딩 원칙:

- 1초 이내 작업은 과한 로딩 화면을 띄우지 않는다.
- 오래 걸릴 수 있는 작업은 취소 또는 건너뛰기 버튼을 제공한다.
- 블루투스 연결 로딩은 브라우저 권한 창과 함께 혼란스럽지 않게 설명한다.

## 4. 에러 상태

| 에러 | 표시 문구 | 행동 |
| --- | --- | --- |
| 저장 데이터 없음 | 처음 시작하는 상태예요. | 기본 상태로 시작 |
| 저장 데이터 손상 | 저장된 내용을 읽기 어려워요. 기본 상태로 복구할게요. | 복구 시작 |
| 블루투스 권한 거부 | 주판 연결이 취소됐어요. | 다시 연결 / 키패드 사용 |
| 블루투스 연결 실패 | 주판을 찾지 못했어요. | 다시 시도 / 키패드 사용 |
| 블루투스 연결 해제 | 주판 연결이 끊어졌어요. | 다시 연결 / 계속 풀기 |
| 오디오 로드 실패 | 소리 없이 계속할게요. | 계속하기 |
| 알 수 없는 오류 | 잠깐 문제가 생겼어요. 다시 시도해 주세요. | 다시 시도 / 홈으로 |

에러 메시지는 기술 용어를 직접 노출하지 않는다.
상세 원인은 개발자 로그 또는 부모 설정의 상세 정보 영역에서만 다룬다.

## 5. 문제풀이 중 예외 상태

문제풀이 중에는 흐름을 끊지 않는 것이 중요하다.

상황별 처리:

| 상황 | 처리 |
| --- | --- |
| 블루투스 입력 지연 | currentQuestionIndex가 다르면 무시 |
| 제출 중 추가 입력 | `isSubmitting`이면 무시 |
| 오디오 실패 | 사운드 없이 계속 |
| 저장 실패 | 세트 진행은 유지하고 결과 후 재시도 |
| 화면 키패드 오입력 | 지우기/취소 제공 |

문제풀이 로직과 입력 장치 에러는 직접 결합하지 않고, InputController와 상태 계층을 통해 처리한다.

## 6. 저장 복원 실패

저장 데이터가 깨졌을 때:

```text
저장된 내용을 읽기 어려워요.
기본 상태로 다시 시작할 수 있어요.
```

가능한 행동:

- 기본 상태로 시작
- 백업 데이터가 있으면 복원
- 부모 설정으로 이동

마이그레이션 실패 시 기존 데이터는 즉시 삭제하지 않고 백업 키에 보관하는 것을 권장한다.

## 7. 코인 부족/조건 부족 상태

상점과 부화장에서 자주 발생하는 상태다.

코인 부족:

```text
코인이 조금 부족해요.
훈련을 한 세트 더 하면 살 수 있어요.
```

부화 조건 부족:

```text
알이 아직 더 따뜻해져야 해요.
훈련을 완료하면 부화 게이지가 올라가요.
```

모험 조건 부족:

```text
모험을 떠날 공룡이 필요해요.
```

## 8. 위험 동작 확인 상태

다음 행동은 확인 모달이 필요하다.

- 데이터 초기화
- 알 삭제
- 공룡 선택 해제
- 세트 중 나가기
- 블루투스 연결 해제

예시:

```text
정말 나갈까요?
이번 세트는 아직 끝나지 않았어요.
```

버튼은 안전한 행동을 먼저 둔다.

```text
[계속하기] [나가기]
```

## 9. 초기 구현 범위

1차 구현:

- 주요 탭 빈 상태
- 블루투스 연결 실패/해제 상태
- 저장 데이터 없음/손상 상태
- 코인 부족 상태
- 세트 중 나가기 확인
- 오디오 실패 fallback 문구 없이 no-op

후속 구현:

- 백업 복원 UI
- 상세 오류 보기
- 오프라인/PWA 캐시 상태
- 공룡/알 삭제 확인
