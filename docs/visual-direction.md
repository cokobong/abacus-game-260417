# 주산게임 비주얼 방향

## 1. 전체 비주얼 목표

이 게임은 6~8세 아이가 반복적으로 주산 문제를 풀고, 공룡을 키우며 성취감을 느끼는 교육용 게임이다.

비주얼은 아이가 좋아할 만한 공룡 요소를 포함하되, 과하게 유아틱하거나 산만하지 않게 한다.

핵심 목표는 다음과 같다.

- 공룡이 매력적으로 느껴질 것
- 숫자와 문제 화면이 가장 잘 보일 것
- 아이가 오래 봐도 피로하지 않을 것
- 부모가 보기에도 깔끔하고 교육적인 느낌일 것

---

## 2. 공룡 디자인 방향

공룡은 사실적인 스타일보다, 단순화되고 친근한 캐릭터 스타일로 간다.

원칙:

- 무섭지 않게
- 귀엽지만 지나치게 아기자기하지 않게
- 한눈에 구분되는 실루엣
- 색이 너무 복잡하지 않게
- 표정이 명확하게 보이게

추천 방향:

- 둥글고 부드러운 외곽선
- 벡터풍 또는 간단한 2D 일러스트 느낌
- 눈, 입, 표정이 잘 보이는 형태
- 몸통은 단순화하고 특징만 살리기

예시 공룡:

- 기본 공룡: 아기 티라노
- 추가 공룡 후보: 트리케라톱스, 스테고사우루스, 브라키오사우루스, 프테라노돈

---

## 3. 공룡의 분위기

공룡은 “전투 캐릭터”보다 “함께 성장하는 친구” 느낌이 강해야 한다.

원하는 인상:

- 귀엽다
- 든든하다
- 응원해준다
- 성장하는 느낌이 있다
- 학습 파트너처럼 느껴진다

피해야 할 것:

- 너무 공격적임
- 너무 복잡한 갑옷/무기
- 무섭거나 사실적인 표정
- 화면을 너무 많이 차지해서 문제 풀이를 방해하는 것

---

## 4. 전체 UI 분위기

UI는 교육용 앱과 캐주얼 게임의 중간 느낌으로 간다.

원칙:

- 버튼이 크고 명확할 것
- 숫자와 문제 영역이 가장 중요할 것
- 시각 요소가 많더라도 산만하지 않을 것
- 모바일에서도 보기 쉬울 것

원하는 느낌:

- 깔끔함
- 밝음
- 명확함
- 작은 성취감
- 부담 없는 게임성

---

## 5. 색감 방향

전체 색감은 밝고 안정적인 톤으로 구성한다.

추천 팔레트 방향:

- 메인 컬러: 초록 계열 또는 민트 계열
- 포인트 컬러: 노랑, 주황, 하늘색
- 보상 컬러: 코인은 골드/노랑
- 성공 피드백: 밝은 초록, 노랑
- 오답 피드백: 강한 빨강보다 부드러운 주황/핑크 계열

피해야 할 것:

- 너무 강한 원색 남용
- 배경과 버튼이 모두 튀는 구성
- 장시간 보기 피곤한 형광색 위주 화면

---

## 6. 화면별 비주얼 방향

### 시작 화면
- 대표 공룡이 보인다
- "주산 훈련 시작" 버튼이 가장 잘 보여야 한다
- 현재 보유 코인과 대표 공룡 상태가 간단히 보이면 좋다

### 문제 풀이 화면
- 문제 숫자가 가장 크게 보인다
- 입력 영역이 직관적이어야 한다
- 정답 시 코인 획득 그래픽이 나온다
- 공룡은 보조적으로 반응한다

### 결과 화면
- 20문제 완료 성취감이 느껴져야 한다
- 정답 수, 정확도, 보너스 배율, 획득 코인이 잘 보여야 한다
- 공룡 성장 결과가 함께 보이면 좋다

### 공룡 키우기 화면
- 대표 공룡이 크게 보인다
- 공룡 이름, 레벨, 경험치 바가 잘 보여야 한다
- 먹이 주기 버튼이 명확해야 한다

### 상점 화면
- 구매 가능한 먹이, 코스튬, 공룡이 카드 형태로 보이면 좋다
- 가격과 보유 코인이 직관적으로 보여야 한다

---

## 7. 그래픽 피드백 방향

정답을 맞혔을 때는 즉각적이고 기분 좋은 피드백이 필요하다.

예시:

- 코인 아이콘이 튀어나온다
- "+5" 같은 숫자가 잠깐 보인다
- 공룡이 기뻐하는 표정을 짓는다
- 상단 코인 영역으로 코인이 이동하는 느낌

오답일 때는 부드럽게 처리한다.

예시:

- "다시 생각해보자"
- 약한 흔들림
- 과한 실패 연출은 사용하지 않음

---

## 8. 폰트 및 텍스트 방향

- 숫자는 크고 선명하게 보여야 한다
- 버튼 텍스트는 짧고 명확해야 한다
- 설명 텍스트는 최소화한다
- 아이가 읽기 쉽게 복잡한 문장을 피한다

예시 버튼 문구:

- 시작하기
- 다시 하기
- 공룡 보기
- 먹이 주기
- 상점 가기

---

## 9. 1차 버전에서 필요한 핵심 비주얼 요소

- 기본 공룡 1종
- 코인 아이콘
- 먹이 아이콘
- 경험치 바
- 결과 화면용 보상 카드
- 상점 카드 틀
- 간단한 배경

---

## 10. 1차 버전 비주얼 우선순위

1. 문제 화면 가독성
2. 기본 공룡 캐릭터
3. 코인 보상 피드백
4. 결과 화면 정리
5. 공룡 키우기 화면
6. 상점 화면
