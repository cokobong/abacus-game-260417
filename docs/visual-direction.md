# 주산게임 비주얼 방향

## 1. 전체 비주얼 목표

이 게임은 6~8세 아이가 반복적으로 주산 문제를 풀고, 공룡을 키우며 성취감을 느끼는 교육용 게임이다.
초기 사용 환경은 터치 기능이 있는 노트북에서 고정적으로 실행하는 브라우저 기반 로컬 웹앱이다.

비주얼은 아이가 좋아할 만한 공룡 요소를 포함하되, 과하게 유아틱하거나 산만하지 않게 한다.

최근 컨셉에서는 공룡뿐 아니라 알, 캐릭터, 부화, 성장, 놀이 요소를 함께 보여주는 방향으로 확장한다.
초기 컨셉 이미지의 귀엽고 밝은 키즈 게임 감성은 유지한다.

핵심 목표는 다음과 같다.

- 공룡이 매력적으로 느껴질 것
- 알과 캐릭터의 성장 구조가 직관적으로 보일 것
- 숫자와 문제 화면이 가장 잘 보일 것
- 아이가 오래 봐도 피로하지 않을 것
- 부모가 보기에도 깔끔하고 교육적인 느낌일 것
- 터치 노트북 화면에서도 탭 구조가 한눈에 이해될 것
- 손가락으로 직접 누르기 쉬운 버튼 크기와 간격을 가질 것

---

## 2. 공룡 디자인 방향

공룡은 사실적인 스타일보다, 단순화되고 친근한 캐릭터 스타일로 간다.

원칙:

- 무섭지 않게
- 귀엽지만 지나치게 아기자기하지 않게
- 한눈에 구분되는 실루엣
- 색이 너무 복잡하지 않게
- 표정이 명확하게 보이게

추천 방향:

- 둥글고 부드러운 외곽선
- 벡터풍 또는 간단한 2D 일러스트 느낌
- 눈, 입, 표정이 잘 보이는 형태
- 몸통은 단순화하고 특징만 살리기

예시 공룡:

- 기본 공룡: 아기 티라노
- 추가 공룡 후보: 트리케라톱스, 스테고사우루스, 브라키오사우루스, 프테라노돈

---

## 3. 공룡의 분위기

공룡은 “전투 캐릭터”보다 “함께 성장하는 친구” 느낌이 강해야 한다.

원하는 인상:

- 귀엽다
- 든든하다
- 응원해준다
- 성장하는 느낌이 있다
- 학습 파트너처럼 느껴진다

피해야 할 것:

- 너무 공격적임
- 너무 복잡한 갑옷/무기
- 무섭거나 사실적인 표정
- 화면을 너무 많이 차지해서 문제 풀이를 방해하는 것

---

## 4. 전체 UI 분위기

UI는 교육용 앱과 캐주얼 게임의 중간 느낌으로 간다.

원칙:

- 버튼이 크고 명확할 것
- 숫자와 문제 영역이 가장 중요할 것
- 시각 요소가 많더라도 산만하지 않을 것
- 터치 노트북에서도 보기 쉽고 누르기 쉬울 것
- 드래그보다 탭 중심 조작을 우선할 것

원하는 느낌:

- 깔끔함
- 밝음
- 명확함
- 작은 성취감
- 부담 없는 게임성

---

## 5. 색감 방향

전체 색감은 밝고 안정적인 톤으로 구성한다.

추천 팔레트 방향:

- 메인 컬러: 초록 계열 또는 민트 계열
- 포인트 컬러: 노랑, 주황, 하늘색
- 보상 컬러: 코인은 골드/노랑
- 성공 피드백: 밝은 초록, 노랑
- 오답 피드백: 강한 빨강보다 부드러운 주황/핑크 계열

피해야 할 것:

- 너무 강한 원색 남용
- 배경과 버튼이 모두 튀는 구성
- 장시간 보기 피곤한 형광색 위주 화면

---

## 6. 화면별 비주얼 방향

### 시작 화면
- 대표 공룡이 보인다
- "주산 훈련 시작" 버튼이 가장 잘 보여야 한다
- 현재 보유 코인과 대표 공룡 상태가 간단히 보이면 좋다

### 문제 풀이 화면
- 문제 숫자가 가장 크게 보인다
- 입력 영역이 직관적이어야 한다
- 블루투스 주판 입력 상태가 명확하게 보여야 한다
- 블루투스 주판을 사용할 수 없을 때 터치 숫자 키패드를 쉽게 사용할 수 있어야 한다
- 숫자 키패드와 제출 버튼은 오입력을 줄이기 위해 분리한다
- 정답 시 코인 획득 그래픽이 나온다
- 공룡은 보조적으로 반응한다

### 결과 화면
- 20문제 완료 성취감이 느껴져야 한다
- 정답 수, 정확도, 보너스 배율, 획득 코인이 잘 보여야 한다
- 공룡 성장 결과가 함께 보이면 좋다

### 공룡 키우기 화면
- 대표 공룡이 크게 보인다
- 공룡 이름, 레벨, 경험치 바가 잘 보여야 한다
- 먹이 주기 버튼이 명확해야 한다

### 상점 화면
- 구매 가능한 먹이, 코스튬, 알/알 조각이 카드 형태로 보이면 좋다
- 가격과 보유 코인이 직관적으로 보여야 한다

### 부화방 탭
- 알이 화면의 중심에 보여야 한다
- 부화 게이지와 가능한 행동이 한눈에 보여야 한다
- 문제 풀이 세트 성공으로 부화가 진행된다는 점이 보여야 한다
- 부화 보조 아이템은 큰 아이콘으로 표현하되, 즉시 부화 버튼처럼 보이지 않게 한다
- 먹이는 부화보다 부화 후 성장/친밀도 아이템으로 구분해 보여준다
- 알 진행률에 따라 알 크기, 무늬, 흔들림, 금, 실루엣 힌트가 단계적으로 바뀐다

### 놀이터 탭
- 부화한 캐릭터가 가장 잘 보여야 한다
- 먹이, 장난감, 쓰다듬기 같은 상호작용이 직관적이어야 한다
- 캐릭터 반응은 짧고 귀엽게 표현한다

### 도감 탭
- 발견한 캐릭터와 미발견 실루엣이 구분되어야 한다
- 카드 목록은 복잡하지 않게 구성한다
- 희귀도, 발견 조건, 좋아하는 아이템 같은 정보는 짧게 보여준다

### 모험 탭
- 숲길, 연못, 구름섬, 장난감 마을 같은 지역이 작은 썸네일로 구분되어야 한다
- 캐릭터를 보내고 기다린다는 구조가 쉽게 이해되어야 한다
- 보상 아이콘은 작아도 구분 가능해야 한다

---

## 7. 그래픽 피드백 방향

정답을 맞혔을 때는 즉각적이고 기분 좋은 피드백이 필요하다.

예시:

- 코인 아이콘이 튀어나온다
- "+5" 같은 숫자가 잠깐 보인다
- 공룡이 기뻐하는 표정을 짓는다
- 상단 코인 영역으로 코인이 이동하는 느낌

오답일 때는 부드럽게 처리한다.

예시:

- "다시 생각해보자"
- 약한 흔들림
- 과한 실패 연출은 사용하지 않음

---

## 8. 알 부화 단계별 시각 효과

부화는 시간이 지나서 자동으로 끝나는 느낌이 아니라, 문제 풀이 세트 성공이 쌓여 알이 반응하는 느낌이어야 한다.
각 단계는 아이가 “조금 더 가까워졌다”고 느낄 수 있게 분명하지만 과하지 않게 표현한다.

| 진행률 | 시각 효과 | 힌트 표현 |
| ---: | --- | --- |
| 0% | 기본 알 상태, 카테고리별 색/무늬만 표시 | `미확인 알`, `일반 알`, `희귀 알` 정도 |
| 25% | 알이 살짝 커지고 따뜻한 빛이 약하게 나타남 | 작은 흔들림 또는 온기 |
| 50% | 알 무늬가 진해지고 짧은 흔들림 효과 | 서식지나 성격 힌트 |
| 75% | 알에 작은 금이 생김 | 발자국, 울음소리 힌트 공개 |
| 90% | 실루엣 일부 또는 꼬리/뿔/날개 그림자 표시 | 형태 힌트 강화 |
| 100% | 부화 연출 후 공룡 등장 | 이름, 모습, 도감 카드 공개 |

힌트는 공룡 이름을 직접 말하지 않고 추측 가능한 단서로 보여준다.

예시 문구:

- 큰 발자국 소리가 들려요.
- 긴 꼬리가 움직이는 것 같아요.
- 뿔 모양 그림자가 보여요.
- 날개 같은 그림자가 보였어요.
- 물가를 좋아하는 친구일지도 몰라요.

시각 주의사항:

- 90% 단계에서도 공룡 정답을 완전히 공개하지 않는다.
- 알의 흔들림과 금 연출은 짧고 귀엽게 처리한다.
- 부화 보조 아이템 사용 연출은 문제 풀이 성취 연출보다 더 강하면 안 된다.
- 부화 완료 연출은 도감 해금과 자연스럽게 이어져야 한다.

---

## 9. 폰트 및 텍스트 방향

- 숫자는 크고 선명하게 보여야 한다
- 버튼 텍스트는 짧고 명확해야 한다
- 설명 텍스트는 최소화한다
- 아이가 읽기 쉽게 복잡한 문장을 피한다

예시 버튼 문구:

- 시작하기
- 다시 하기
- 공룡 보기
- 먹이 주기
- 상점 가기

---

## 10. 터치 UI 기준

터치 노트북에서 아이가 직접 누르는 것을 기준으로 UI를 설계한다.

터치 UI 원칙:

- 주요 버튼은 손가락으로 누르기 쉽게 충분히 크게 만든다.
- 숫자 키패드는 7~8세 아이가 실수 없이 누를 수 있도록 간격을 둔다.
- 입력, 취소, 나가기, 설정 같은 버튼은 명확하게 구분한다.
- 너무 작은 아이콘만으로 기능을 표현하지 않는다.
- 하단 탭은 터치하기 쉬운 크기와 간격을 확보한다.
- 드래그보다 탭 중심 조작을 우선한다.
- 빠른 문제풀이 중 오입력을 줄이기 위해 숫자 버튼과 제출 버튼을 분리한다.

권장 크기:

| UI 요소 | 권장 최소 크기 |
| --- | ---: |
| 숫자 키패드 버튼 | 56px 이상 |
| 주요 CTA 버튼 | 64px 이상 |
| 하단 탭 터치 영역 | 56px 이상 |
| 작은 보조 버튼 | 44px 이상 |

권장 표현:

- 작은 텍스트 링크보다 카드형 버튼을 선호한다.
- 키패드는 버튼 사이 여백을 충분히 둔다.
- 제출 버튼은 숫자 키패드와 색상/위치/크기로 구분한다.
- 키보드 입력을 전제로 한 작은 폼 UI는 피한다.

## 11. 1차 버전에서 필요한 핵심 비주얼 요소

- 기본 공룡 1종
- 기본 알 1종
- 기본 캐릭터 1종
- 코인 아이콘
- 먹이 아이콘
- 장난감 아이콘
- 희귀 알 조각 아이콘
- 경험치 바
- 부화 게이지
- 결과 화면용 보상 카드
- 상점 카드 틀
- 도감 카드 틀
- 모험 지역 썸네일
- 간단한 배경

## 12. 1차 버전 비주얼 우선순위

1. 문제 화면 가독성
2. 기본 공룡 캐릭터
3. 코인 보상 피드백
4. 결과 화면 정리
5. 공룡 키우기 화면
6. 상점 화면
7. 부화방 탭
8. 도감/모험 탭의 기본 틀
