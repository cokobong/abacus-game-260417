# 비주얼 피드백 메모

초기 컨셉 이미지의 감성은 유지한다.

- 귀엽고 밝은 키즈 게임 느낌
- 너무 복잡하지 않은 UI
- 알, 캐릭터, 성장, 놀이 요소가 직관적으로 보이는 구조
- 터치 노트북 화면에서도 한눈에 이해되는 탭 구조

## 유지할 인상

- 아이가 첫 화면을 보고 바로 “알을 돌보고 캐릭터를 키우는 게임”이라고 이해할 수 있어야 한다.
- 화면이 밝고 부드러워야 하지만, 버튼과 숫자는 선명해야 한다.
- 장식 요소보다 핵심 행동이 먼저 보여야 한다.
- 부화방, 놀이터, 도감, 모험, 상점 탭은 아이콘만 봐도 역할이 예상되어야 한다.

## 피해야 할 방향

- 탭이나 버튼이 너무 많아 보여서 복잡하게 느껴지는 화면
- 캐릭터와 배경 장식이 문제 풀이 영역을 방해하는 구성
- 수집/상점 요소가 학습보다 더 강하게 보이는 구성
- 터치 노트북 화면에서 한 화면에 정보가 과하게 밀집된 구성
